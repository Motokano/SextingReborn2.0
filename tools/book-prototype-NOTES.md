# 书籍正式交互验收

用户已确认接入正式游戏，选择的A背包下方详情已吸收进两套正式UI。旧B独立窗口、C右栏阅读和临时6经验一级代码已删除。正式入口为index.html，验收页没有另一套阅读算法。

运行 `npm run prototype:books`，打开 `http://127.0.0.1:8051/tools/book-prototype.html?no_reload&variant=A`，另一套界面追加 `&ui=svelte-hud`。旧variant参数仅兼容既有链接，已不切换布局。

用户明确每级固定1万解剖学经验，100级累计100万；100潜能兑换1经验、附送10%语言经验。每级纯阅读消耗100万潜能，附送1000语言经验。完整度N/100可学至N级，达到教材上限停止阅读扣费及两种经验。阅读不消耗教材；完整本另可消耗升1级，保留当级经验，不额外发两种经验。

阅读沿用现有专注潜能预算、每刻1精力和公共设施等待（当前3秒），实际推进世界刻。进度条使用真实当级经验，下面只显示本次解剖学经验与阅读经验，不列潜能、精力数值或费用。阅读经验为既有语言经验的显示称呼，没有新增技能。角色经验、语言小数及本次所得保存，读档暂停；保存失败共同回退资源、经验及世界时间。关闭、换书、移动、失能、其他行动和切后台停止／暂停，不补离线。

验收控件只负责准备状态：首次1/100；临近升级9998/10000；差一份99/100；完整100/100；已掌握23级的23/100。点击探索获得1份走正式接收与自动合并，集齐提示只在事务保存成功后显示。临近升级场景只读剩余2经验，附送0.2阅读经验，升至1级后停止；完整本消耗12→13级，书移除；已掌握不能继续刷经验。

游戏脚本加载前隔离localStorage、sessionStorage，禁用跨标签锁与广播。测试角色、教材、潜能和语言10级仅存在本页内存；不读取或写入正式玩家存档。正式游戏未新增赠书，具体掉落地点和概率尚未指定，来源标签dungeon不代表已经投放。

验证：物品与UI构建通过，书籍18项（含两套界面、真实百万经验、零点几语言经验、上下限、存档恢复／失败回退、旧档、移动／切后台、凑齐提示和整本消费）、背包16项、设施世界时间23项回归通过。浏览器使用两套正式界面验收；临近升级用于验证结算边界，绝不缩小正式经验需求。
