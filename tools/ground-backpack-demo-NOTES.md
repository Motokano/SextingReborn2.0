# 地面背包交互 Demo

状态：2026-11-01 可试玩，等待用户操作反馈。用于回答「在棋盘上放包、走近、开包、双向存取和换包是否顺手」。用户要求先做 Demo，本页是独立浏览器试玩，延续既有游戏原型入口；不是正式运行接入，也不新增外观变体。

## 启动

运行 `npm run prototype:ground-backpack`，打开 <http://127.0.0.1:8037/tools/ground-backpack-demo.html?no_reload>。

默认已装备轻便帆布包，携带铁坯、水壶（存水125）、粗面饼和备用空包；地上另有搜集包与搬运包。点「整包放下」，站在包的格子上点击包，直接打开双栏：左侧随身容器，右侧地面背包。在左侧选择口袋／装备背包／可用载具，把物品拖到另一侧格子区域即可存取，也可选物品后用「放入 →」「← 取出」。换包会把原包及内容放在人物脚下。

拖拽支持鼠标与触摸，目标格子区域高亮，浮动标签显示名称和数量。未选物品默认移动整组；已选物品沿用数量栏，可先改数量再拖动。松开后沿现有规则自动堆叠或寻找空格，不指定格位、不交换格子。只有松开在另一侧格子区域才提交；同侧、窗口外、Esc、手势取消或窗口失效均不转移。满容器、收纳限制及模拟保存失败保持整次回退，不自动丢弃余量；按钮入口仍可完成全部操作。

2026-11-01 最新反馈：用户指定同格点击直达、左随身右地面，覆盖此前先选菜单再打开、邻格可存取的演示。默认只保留棋盘与精简入口，没有中间操作菜单或独立拾起目的地。「随身物品」可单独查看携带容器；「脚下物品」仅显示当前格，单件直接打开，多件先选择真实实例。整包放下及切换情境不自动开窗。

窗口可用关闭按钮或Esc收起；成功的存取立即保留。点空地回到行走；只要走离背包所在格、背包被拾起／装备、死亡或清理即关闭。远处点击背包只行走到该格，到达后再次点击直接开包，不在邻格提前停下或远程开包。计重与保存回退保持。

点击空格按合法路线行走，方向键与行走按钮每次走一格。墙为阻挡占位几何，开门按钮用于测试门格通行；可绕两端通过。棋盘默认144px格宽、原主角125%与已定稿背包登记尺寸，窄窗口整体等比适配。背包不阻挡，同格物品可点击具体棋子或从脚下列表选择。

2026-11-01 界面精简：按用户要求去掉全部操作说明和引导文字，包括拖拽提示、未选物品提示、棋盘行走指引、规则／试玩范围段落和属性中的通用规则；空说明区域收起。保留名称、数值、按钮、物品属性和实际操作结果，操作与拖拽规则不变。

## 状态与范围

- 复用正式 `InventoryEquipment`、`BackpackSystem`、物品属性与腐坏模块；新地面转移编排只存在于 `ground-backpack-demo-model.mjs`，正式入口不加载它。
- 六种情境：自由存取、只剩一格、两包交换、空包再利用、即将清理、地牢保留。
- 数量转移采用现有堆叠兼容和模板上限；口袋按现行一格一件，拆分发新身份。批量按整栈逐格尝试，失败格留下，后续格继续。
- 地面内容保留格位，背包本体与子物品只有一个归属。非空包拒绝套包和放入口袋，可整包进入绑定载具；空包须先放地面才能打开。
- 整理0刻，行走每格1刻；物品计重、包内减重、存水与腐坏读取正式数据。地面包不提供减重或保鲜。
- 非地牢100刻清理整包，地牢不走该分支；开包／存取不刷新落地时间。超距或清理自动关闭。死亡沿用随身／载具清空及先前地面保留的既有边界。
- 全部状态只在内存中。依赖读取的 `localStorage` 被替换为页面私有内存；不读取或修改正式存档。刷新重新开始。「重载试玩记录」恢复本页最近提交的内存快照，保持窗口关闭；不代表持久读档已完成。
- 「下次保存失败」撤回整次物品或时间操作，包括一次批量取出。保存失败仅为模拟，不执行正式保存服务。
- 这是简化棋盘，无真实地图感知、敌人、战斗、制作锁、跨图持久化或三型号专属新美术。远程开关门只为试验通路；占位墙门不是场景美术交付。
