# 健身房百分比成长试玩

正式游戏已接入，见本文末尾2026-11-03记录。此页继续作为独立内存玩法原型。问题是：接近设施棋子、选择动作、支付体力、完成后获得百分比成长，再通过补给、睡眠与设施升级继续训练的循环是否直观？

## 用户反馈与场景版（2026-11-03）

用户否定首版常驻总览，认为过于像dashboard；要求健身房有多种设施棋子，玩家与具体棋子互动后选动作或升级，并去掉所有说明文字。现已改为等距房间：点击目标，角色沿可达空格走到相邻格，再打开该设施的训练／升级窗口。未建成设施在同一入口建造，建成后显示正常棋子；没有跨设施切换列表。旧床负责休息／睡眠，物资架负责进食／饮水与配重制作，肌群只从独立按钮打开。

移除主页面板、常驻材料与动作目录、说明段落、成长示例、规则提示、页脚与常驻日志。保留名称、属性／消耗／奖励／进度、按钮、未建造／已满级等状态及真实操作结果。训练中可关闭窗口，回到场景查看当前动作，再点设施继续查看；不会因关窗重复扣费或发奖。

设施已替换为按77号绘制的透明PNG候选稿，床复用藏身处已批准原图。八类设施随1～4级变化，手足三模块独立变更。用户要求参考现实器械后，颈部改为开放压垫式坐姿训练机，腿部改用现实伸屈腿结构，手足改用普通握力器、踏板、弹力带和毛巾用具，撤下原虚构机关。素材和来源见 `assets/map/isometric/gym-facilities-v1/README.md`，四档预览为 `tools/gym-art-review.html?no_reload`。美术仍待评价，未接正式藏身处。

房间使用77号地面轴比例、现有工业地面和125%主角；原图不变形，阴影独立。设施按体积占1×1／1×2／2×1／2×2逻辑格并阻挡通行，保留相邻互动空间；走路只是本页演示，不收正式移动费用，不修改训练经济。窄屏可横向浏览场景，交互窗口适配屏宽。

本轮浏览器检查覆盖走近开窗、设施独立动作、建造、升级、训练后到账、关窗继续、独立肌群窗口及窄屏操作。新布局待用户评价。

用户后续要求床铺窗口直接复用UI状态条，查看饱食、饮水、疲劳、体力的变化。窗口复用顶部HUD同一`resource`渲染与样式，按真实生存状态逐刻更新；删除窗口内计时进度条、剩余秒数和睡眠按钮时长。保留休息／睡眠、进行中状态及普通休息停止，不改变实际等待或结算。

## 疲劳节奏试调（2026-11-03）

用户反馈疲劳累积太慢，先试调10体力产生5疲劳，随后要求「改为+15」。当前Demo每1体力产生1.5疲劳；6／8／10／12／14／16体力的动作分别产生9／12／15／18／21／24疲劳。训练窗口与实际结算共用同一参数。

只覆盖本页内存中的生存配置，仍由原consumeStamina一次结算，不叠加第二笔；正式生存配置与普通行动未改。每组10体力时，第4组结束疲劳60可入睡，之后新组收益减半，第6组结束90不再开始新组。补给与休息仍需正常支付，普通休息不减疲劳；肌肉奖励、等待和睡眠不改。

## 启动

运行 `npm run prototype:gym`，打开 http://127.0.0.1:8049/tools/gym-prototype.html?no_reload 。所有状态只在本页内存中；刷新重置，不加载 SaveSystem，不读写正式存档。

藏身处交互预览：`tools/gym-hideout-review.html?no_reload`，支持平面、全景、健身房近景与四级器械情境。用户选区为x=0～8、y=0～9（9×10格），布局正本`tools/gym-hideout-layout.json`；右侧（8,7）经（9,7）接入原木桩房，床留在旧位置。该页已共用本Demo模型，可步行、训练、建设、升级和使用原床；正式地图和存档未写入。8类器械占19格、3件新陈设占4格，无交叠，所有设施邻格、旧床和两个原出口均可达。

2026-11-03房间改用旧混凝土／橄榄绿漆、橡胶地垫，加入两组管线、灯和训练图以及旧铁柜、长凳、用具箱，参考塔科夫健身房氛围。七项内置image_gen素材的原图、精确提示和来源登记在`assets/map/isometric/gym-room-v1/`。新家具没有额外容量或奖励；器械等级外观仍读既有41张素材。

两处试玩的八种器械均通过真实`NPCSystem.openMenu`与`GymFacility`宿主适配。NPC已分别登记，菜单提供训练／升级或建造；相邻四向、当前地图、未失能与陈旧点击校验在共用适配器中执行。NPC菜单不另收费用，不新增聊天。正式游戏尚未绑定该预览宿主，不能通过NPC注册项获得试玩资源或操作。原型脚本在加载NPC前隔离localStorage，不触碰玩家存档。

布局第二版采用用户选定的紧凑地下室感觉：后侧引体／滑轮、右后杠铃／哑铃／工具箱、左侧专项和垫上训练，入口旁更衣凳与铁柜成组。橡胶区域和挂件位置也写入布局配置，中间复用旧水泥地连通入口。NPC位置同步、23格占用及原床通路保持；四项NPC／通路回归通过，1／4级实景见`reference/gym-room-v1/room-compact-v2*.png`。

## 已实现

- 2026-11-04：解剖学每级+2%锻炼效率，「营养充沛」「营养极境」均+10%且不叠加。公式为基础奖励×器械效率×（1＋等级×0.02＋营养加成）×疲劳系数，与正式版共用`GymData.trainingEfficiency`。试玩设置可改本页解剖学等级与营养值；来源数字随实际奖励显示，每组开始锁定。此条覆盖旧版只有器械／疲劳倍率的参数记录。

- 直接读取现有 `data/muscles.json`，展示22个肌群、478条肌肉；52个动作映射244条既有肌肉ID。其余显示「专项待开放」，不是获得新训练来源。
- 每块肌肉独立0%～100%。动作开始扣一次体力并产生既有疲劳，完整结束后才给目标清单发奖；相同肌肉跨动作合并，不给全肌群发奖。
- 达到100%调用正式 `Muscles.unlock`，保留原永久属性与整群被动槽、装配规则；已满不重复领奖，也不把溢出转给其他目标。
- 八类设施可建造和逐级改进，效率1.00／1.15／1.30／1.50倍。改进不改变目标清单或动作费用；手足台按手部、足踝、足趾三个模块分别改进。
- 配重片先制作再投入，安装后扣除库存，不能重复用于别的器械。材料、建设配方均是试玩占位池。
- 普通休息与睡眠使用真实 Survival 结算。普通休息保留疲劳；睡眠完整48刻，每刻等待1秒。满体力或零疲劳仍支付，缺补给不提前结束。隐藏页面暂停，刷新重置本次试玩。
- 试玩设置可切换从零开始、器械齐备、器械满级、肩带即将练满、疲劳65及低体力情境；器械情境只预置本页等级，肩带情境只预置本页肌肉进度，正式角色不获得器械或进度。

## 本版试调参数和简化

- 主练每组基础+0.15～0.25个百分点，辅助+0.03～0.05个百分点。具体值见动作配置。例：12.00%加0.20个百分点得到12.20%。基础主练从零到满约400～667组，不计辅助、升级或疲劳减益。
- 每组2刻，沿当前普通节奏每刻3秒，共6秒；用户仅确认了睡眠1秒/刻，训练时长仍待评价。
- 疲劳≤50为100%成长、50＜疲劳＜80为50%、疲劳≥80不开始新组；每组开始锁定本组收益。基础动作体力6～16，实际体力支出经现有管线只累积一次疲劳，当前Demo为支出的1.5倍。
- 可连续1／4／8组，每组独立校验与付费，资源不足自动停下；主动停止在当前组结束后生效。暂停页面不结算离线时间。
- 为便于对照，本页展示全部设施和项目；建造视为装好该设施的基础附件套装。正式版的逐附件解锁、知识、所需肢体、地图摆放与正式制造配方没有接入。
- 食物、饮水按钮使用试玩库存，每份补25相应资源；领取试玩物资用于比较建设路线，未接探索或正式物品消费。
- 本页只核对生存资源与肌肉奖励，未接正式睡眠最终属性经验、保存重试、战斗、伤病与死亡演出。
