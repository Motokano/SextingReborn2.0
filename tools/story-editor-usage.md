# 林经理事件编排器

启动：`npm run editor:story`，打开 <http://127.0.0.1:8044/>。端口被占用时可运行 `npm run editor:story -- 8045`。

## 编排

- 事件关系总览读取林经理现有六个事件（2026-11-02用户改写定稿后共41句）。连线表示 `requires` 前置关系，不表示事件自动连续播放；排除关系用虚线表示。除首次见面外，仍沿原闲聊条件筛选与随机选择。
- 点开任意事件，每句是一张卡片。点击即可直接修改台词和说话人，支持插入、复制、删除、拖动排序及上下移；保持至少一句。
- 「从此句预览」从选中句播放至事件结尾，复用正式 `DialogueUI.playLinesRich` 的逐字显示和补全／推进。预览不执行效果、不创角、不读写玩家存档。可以随时关闭预览回到编辑。
- 「事件设置」编辑显示标题、条件、是否重复、前置／排除事件及结束效果。保存时检查不存在引用、依赖循环、空台词、重复编号及必要开场标记。
- 创角前的首次事件只能增设剧情标记，物品／技能效果放在创角后的事件，以免被现有创角初始化覆盖。
- 日常闲聊另列陌生、熟悉两个台词池及合并引用。单池内各句独立随机抽取，图中不伪装为连续剧情；预览只播选中一句。
- 本版支持当前逐句队列和事件条件关系，不提供拖线创建选项分支、镜头或走位指令。台词以用户保存的配置为准。

## 保存

血腥开关可在事件结束效果中配置：`{"type":"setFlag","params":{"flag":"血腥开关","value":true}}`。`false` 关闭，默认关闭；只影响死亡棋子外观并随剧情标记保存。当前尚未绑定事件。规则见[血腥开关](../docs/design/corpse-gore-switch.md)。

对话事件与日常闲聊分文件保存，按钮会显示当前目标；事件文件内所有事件草稿一起保存。分别写入：

- `data/npc/npc_supervisor_manager_triggers.json`
- `data/npc/npc_supervisor_manager_dialogue_pools.json`

保留稳定事件编号、现有条件、效果、依赖与其他元数据。修改富文本台词后同步更新旧 `lines`；编辑标题放在运行时可忽略的 `editorTitle`。已保存的事件编号不可删除，以保持旧存档及引用有效；首次事件的一次性完成标记不可移除。

草稿支持按文件撤销／重做、导出以及本页会话恢复。重新读取会询问是否放弃未保存草稿。服务器校验读取版本，拒绝覆盖外部修改；冲突时草稿仍可导出。写入采用同目录临时文件替换，只监听本机，并校验来源与编辑令牌。编辑器不提供玩家存档接口。

保存后刷新游戏加载新配置；不会重置已有角色、已触发事件或玩家知识。要看完整新开场，应使用游戏已有的新游戏入口；无需清除存档也可以在编辑器预览任意段落。

## 正式开场衔接（2026-11-02）

用户已确认实装在编辑器中保存的新版台词。首次见面以「……你说你是突然就来到这里的？」开始；六事件句数为9／5／10／4／8／5，陌生和熟悉闲聊池分别3／1句。正式NPC注册表与开场均读取上述两份配置，不维护另一份发布台词副本。

新游戏完成地图和存档初始化后，定向播放 `supervisor.firstTalk_01`，无需寻找林经理、打开菜单或点击闲聊。自动开场不受普通闲聊的上班时段与位置筛选影响。播放仍使用正式共用对话界面；首次对话结束才执行效果、保存完成标记并进入创角。

已创角旧档不重播；尚未完成对话的进度重新进入时从该事件开头播放；首次对话已完成但未创角则直接恢复创角。结束保存失败停留重试，不重播台词、不提前创角。创角提交同样立即保存，失败回退角色和物品状态并保留表单。两个提交为必要保存，不受普通保存开关禁用。死亡或另一个窗口持有运行权时不抢占其界面。

## 验证

`npm run test:story` 覆盖两套正式界面的自动开场、移动阻断、重复调用、未完／已完恢复、保存失败重试、创角提交与回退，以及隔离临时目录中的配置保存、台词排序、字段保留、冲突拒绝、来源校验。测试不写正式NPC配置或玩家存档。

配套回归：`node --test tools/test-npc-interaction-checks.mjs tools/test-svelte-interactions.mjs tools/test-dialogue-pawn.mjs`。浏览器实操检查任意中段选句、预览、改写、顺序调整和撤销。
