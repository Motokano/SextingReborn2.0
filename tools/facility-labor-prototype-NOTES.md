# 消耗体力的设施解锁试作

2026-09-26：用户批准后已吸收进正式游戏，见 `docs/design/facility-unlock-implementation.md`。以下保留原型阶段说明；本试用页仍独立、不保存，正式实现不使用其演示时钟或补体力控制。

问题：已认可的分步修复界面，加入清理劳动后，开始、暂停、体力不足与转入材料修复是否清楚？用户要求一版，沿用原 C 方案，不另做风格变体。

启动：`node tools/serve-live.mjs 8016`，打开 `/tools/facility-labor-prototype.html`。已有服务器时直接打开地址。

独立试用页遵循现有 tools 原型路径；复用实际修复面板、选材与结算，用内存替身承接场景、标记、库存、保存。不会载入或修改真实存档。刷新会清空试用状态。

农业、牧场各清理 1000 tick，每 tick 3 体力。演示每秒一个 tick，模拟游戏内十分钟，不决定正式劳动的驱动时机。暂停、离开、切换设施、页面隐藏均停止计时；已做劳动保留。体力不足自动停工，恢复体力后须主动继续。

清理完成解锁材料步骤；农业土石 6/木作 4，牧场金属 8/木作 8/机件 4。玩家不见点数和完成百分比。体力直接显示沿用生存资源可见性的假定；正式接入时复核对应显示权限。

试用控制可模拟体力不足、休息、重置。加速演示每次推进至多 250 个劳动 tick，每 tick 仍扣 3 体力；不足时显式模拟补满体力，显示补充次数。劳动时钟仅统计劳动时间，不计模拟休息时长。清理随阶段显示不同描述，无百分比。每处总劳动成本 3000 体力，累计劳动时间约 6.94 游戏日。正式流程没有这些调试按钮。尚未接入世界 tick、实际生存体力、农业/牧场生产门控及正式存档。

待用户体验后决定是否吸收此交互；本页不是正式上线实现。
