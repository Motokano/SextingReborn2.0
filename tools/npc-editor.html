关系约束

requires / blocks 仅填事件条目 id（依赖/屏蔽的是「已触发」记录），不要填 flag 名；旗标条件请写在上方「触发条件」。

对话（dialogue）

每句可选择说话人（NPC / 主角 / 旁白），并可上下移动调整顺序。

勾选后可在 options 中配置选项（当前版本可于导出 JSON 中手写）

效果（effects）

物品语义：条件里的 hasItem / 多物品检测只判断背包是否够，不扣。效果里 removeItem 在对话播完后的 applyEffects 中扣除；giveItem 发放物品。常见组合：条件 and（旗标 + hasItem）→ 对话 → effects 依次 removeItem → setFlag（与 js/npc-system.js 一致）。注意：当前 runtime 对 effects 为顺序执行，removeItem 短少时不会自动中止后续 setFlag；若需原子维修需另行改代码。

effects 类型以运行时为准：setFlag、modifySkillLevel、modifySkillMaxLevelBonus、removeItem、giveItem、setCookingStationWater（params.unlimited 布尔，仅主灶台料理水）；其它字符串会被静默跳过。

一次性与作用域

与本列「事件」同级：编辑当前 NPC 的摸鱼台词池文件（data/npc/<npc_id 点改下划线>_dialogue_pools.json；运行时另与共用 dialogue_pools.json 按池 id 合并，专用覆盖同名池），以及按 flag/技能等分部解锁（fallbackPoolRules）。规则自上而下匹配，同一轮仅第一条命中的规则生效；分部规则卡片左侧「⠿」标题栏可拖到另一条上排序。默认池 id 在左侧 NPC 表单的「无触发时的台词池 ID」。规则内 poolPickMode：pick_one 在多个池里随机选一个再抽一句；merge_pools 把所列池的台词合并后等权随机一句（如 A+B）。
