NPC 基础数据

出现时间与位置
地图形象

渲染地图上的 NPC 形象用。导出后由游戏读取 sprite 字段加载对应图片。

仅用于编辑器预览，不会把图片内容写进 JSON；你可以手动把文件放到 assets 目录并在上面的 sprite 中填相对路径。

主菜单
行为描述
默认台词池

闲聊无命中条目时，从此池随机一句（摸鱼/嚼槟榔等）

标签

如 supervisor, guide_hidden, base_npc, non_combat

触发事件列表

暂无事件，点击「新增事件」添加；或导入事件 JSON。
在左侧选中一条事件进行编辑，或新增事件。

编辑事件

触发条件（condition）

建议先点工具栏「载入技能表」，这里会自动变成完整技能下拉。

不会写 JSON 就不用勾。自定义条件时会强制显示。

关系约束
对话（dialogue）

每句可选择说话人（林经理/主角/旁白），并可上下移动调整顺序。

勾选后可在 options 中配置选项（当前版本可于导出 JSON 中手写）

效果（effects）

常见：setFlag, modifySkillLevel, unlockTask；每条 effect 含 type 与 params（见导出 JSON）
