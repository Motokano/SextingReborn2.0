# 水壶基底与构筑逻辑试玩

2026-10-31。独立、可丢弃原型，含耗材料改造、独立保存、死亡丢失与按已有配方重制；本轮增加青竹从水源装水时入壶量+60%，以及40点有限水源对照。其余配方与数值等待试玩评价，没有接入正式游戏。

要回答的问题：一只200容量、占独立装备槽的水壶，能否用同一份存水支持基础饮用与型号／词条／改造构筑，并让玩家清楚看到每次扣水、恢复、持续效果和装卸之间的关系？

本轮追加问题：改装随具体水壶保存、跨刷新延续，死亡丢失整只随身壶以后，能否保留家中材料和知识，再付费制作一只不继承旧配置的新壶？

采用 prototype 技能的逻辑分支，状态转换保存在纯模块中，提供终端入口；另用项目已有独立试玩页面惯例提供浏览器操作界面，便于用户直接点击。这里检验的是装备与恢复逻辑，不是让用户挑选三个界面布局。

## 启动

项目根目录运行 `npm run prototype:water-flask`，打开：

`http://127.0.0.1:8024/tools/water-flask-prototype.html?no_reload`

终端入口：`npm run prototype:water-flask:logic`。输入快捷键后回车；`q`退出。浏览器和终端共用同一模型，状态各自独立；浏览器自动保存试玩进度，终端只在本进程内保存快照。

## 当前两种基底对照

默认仍为现有“铁皮水壶”，新青竹通过试玩样例进入。基础200容量、一个独立装备槽及青竹入壶量+60%来自用户确认；下列其他数值和规则全部为试玩初值。两者暂共用饮用与重量参数，专门比较取水收益，不表示最终型号数值相同。

| 项目 | 试玩配置 |
|---|---|
| 首次默认状态 | 家中水源已修复，水壶已装备但为空，饮水35／100、底气40／100、体力100／100；之后打开恢复上次进度 |
| 基础饮用 | 耗水25，立即恢复25饮水，消耗1刻 |
| 装满 | 在家中补至200，消耗1刻；空壶和半壶都可补满 |
| 地牢水源 | 一处40点示例补水点；装壶与直接喝共享余量，均暂耗1刻 |
| 青竹固有 | 从水源装水时，取水×1.6转成存水；40→64，上限仍为200 |
| 装备／卸下 | 每次1刻，存水保留；仅装备时可饮用 |
| 本体重量 | 暂沿用旧模板的0.7kg；200点水暂按1kg计 |
| 词条选择 | 无词条／节流（耗水−20%）／润泽（补水量+20%），一次一个候选 |
| 改造选择 | 预览普通／缓释／调息方案，点击改造后扣料并生效，一次保留一个候选 |
| 缓释内胆 | 重0.1kg，补水量+60%，随后5刻均分；基础配置每刻8、总量40 |
| 调息内胆 | 重0.15kg，保留即时补水，随后3刻共恢复15底气 |

润泽与缓释乘算时总补水48、每刻9.6；节流将默认耗水降至20而不改变恢复量。展示的恢复量是理论总量，使用记录显示实际恢复及满值截去的部分。

一格候选词条、一个当前改造状态仅为本页比较入口，不代表正式词条挂载位置、槽数或附魔方式已经定稿。改造已增加试玩材料配方，尚未建立真实内胆物品或正式制造配方。

## 材料改造

在家中选择方案、查看预览与“需要／持有”清单后，点击“改造”才实际扣料并生效。材料不足、已经是同一方案或外出时不会扣材料、耗时或改动水壶。选择方案本身不改当前饮用效果。更换方案重新支付全部材料，旧材料不返还；这些替换细则和工时仍为试玩规则。

| 方案 | 材料 | 工时 |
|---|---|---|
| 缓释内胆改造 | 普通铁坯×1、分层过滤片×1、软木塞×1 | 3刻 |
| 调息内胆改造 | 钢丝料×1、硅叶×1、软木塞×1 | 3刻 |
| 恢复普通内胆 | 软木塞×1 | 1刻 |

以下为家中试玩材料初始供给，死亡保留，与正式库存无关；使用已有物品ID，仅改造配方和供给数量为本轮新试值。

| 材料 | 现有ID | 初始持有 |
|---|---|---|
| 青竹杆（制作青竹壶） | `wood_bamboo_green` | 3；旧进度迁移时为0 |
| 普通铁坯 | `material_iron_blank_common` | 3 |
| 软木塞 | `wood_cork` | 6 |
| 分层过滤片 | `tool_layer_filter_sheet_pharmacy` | 2 |
| 钢丝料 | `material_steel_wire` | 3 |
| 硅叶 | `silica_leaf` | 2 |

加工保留水壶身份、存水、词条；工时推进已有持续恢复，不修改其快照。本轮直接在水壶上加工，未产出独立可拆装改造件，也未连接正式材料库存、工具、台级、技能、制造队列或附魔。终端中`0/1/2`预览普通／缓释／调息，`m`加工，`x/z`清空／补充试玩材料。

## 操作与边界

- 初次点“装满水壶”，随后可外出饮用；“回家／外出”只切换试验情境，未模拟真实路径及路程时间。
- 外出情境现在位于有限补水点旁，允许选择倒入壶或直接喝。青竹只有装入壶时增加60%，角色直接饮水及从壶饮用不会重复触发这项特性。水源耗尽禁用；满壶不再扣水。
- 家中仍可免费调整候选词条用于效果比较；改造须使用上方材料配方。外出可预览改造，但不能加工或调整词条。
- 每次固定扣完整费用；剩余水量不足则禁用，不做部分饮用。无有效恢复目标时也禁用，饮水满但底气未满的调息壶仍可使用。
- 持续效果在饮用完成后的下一刻开始，每推进一刻结算一次；饮用、装水、装卸和改造均推进时间。持续期间禁止再次饮用，不叠加、刷新或延长。
- 已饮用效果记录当时的总量与时序；卸下、切换词条或改造不会修改这次效果。每刻若属性已满，该刻溢出的恢复舍去，不延期或返还水。
- 使用记录显示已过刻数、扣水、即时恢复及逐刻恢复；当前存水、重量、角色属性与剩余效果始终可见。
- “试玩设置”的家中空壶、缺水外出、饮水已满、余水不足重置使用状态，保留原壶身份与配置、待选方案、材料和水源余量，不恢复丢失水壶。新增三个“40点水源”样例明确替换为新的青竹／铁皮示例壶，并重置水源、角色和时间，保留材料、知识及基础参数；不属于正式获得途径。“恢复初始状态”覆盖本页试玩存档并重发初始铁皮。
- “补充试玩材料”将六种材料恢复到初始数量，“清空试玩材料”归零；两者不改水壶、词条、时间和角色。这是比较入口，不属于正式获取渠道。
- 可单独填写角色饮水／底气后应用，不改水壶存水，便于试连续饮用。基础耗水和基础补水也分别填写并应用，限定在家中调整。

浏览器把整份试玩状态保存到专用 localStorage 键 `water-flask-prototype:save:v1`，每次操作后整体写入，刷新继续；不访问正式存档或真实物品实例。存档含版本、壶实例及序号、基底型号、水源余量、已掌握配方、家中材料、当前资源、持续效果剩余量与日志。当前封套为版本3；旧版本1先补齐型号与40点示例水源，再按版本2迁移配方选择和竹材字段。保留原铁皮或空实例，不补壶、不重置旧水量／词条／改造；新增竹材初值0。保存失败明确提示；无法读取的进度不自动覆盖，需用恢复初始状态重新开始。

没有自然代谢、真实战斗、地狱对话、技能死亡惩罚、投保、自动喝水、自动补水、多壶换装或冷却共享。水壶轮廓复用已有地牢图标作示意，不是新美术定稿。

## 保存、死亡与重制

- 改装、词条和存水属于壶实例。持续恢复保存已经喝下的那次效果及剩余刻数，刷新不复制恢复量，不按当前内胆重算。
- “模拟死亡并回家”丢失整只随身水壶，包括装备着或卸到背包的情况；清空持续效果，将演示饮水／底气／体力设为50，不推进额外演示刻数。保留家中材料、配方知识与实例序号。
- 丢失状态显式保存为 `flask: null`，刷新、切换情境不会重发初始壶。只有明确重置试玩才回到初始示例。
- 制作复用79号 `manufacturing.tool_flask_iron_water`：普通铁坯×1、软木塞×1，8刻、8体力，产出一个新身份的普通空壶，放入背包。需要自行装备、装水和重新改造，无旧词条继承。
- 默认制造5级，预设已通过研究学会配方，家中有2级制作台、金工工位及修理锤。学过后不再重复按等级拦截。原型只演示成功制作，未接制造成功率、工具占用、完整队列与库存交付。
- 缺料、缺体力或外出时不允许制作；本页已有壶时不重复造壶，不代表正式持有数量上限为一只。
- 终端 `k`模拟死亡、`g`制作，`S/L`保存／读取本进程内快照；终端退出后快照丢弃。浏览器试玩存档与终端快照不互通。

本模型的1刻对应原型中的一个离散时间步；正式接入必须使用统一世界tick、角色上限、装备/装配、负重和原子存档机制，不能照搬本页的角色数值或按钮模拟。

## 青竹水源特性与待定边界

青竹的“取水入壶量+60%”替代此前回气建议，不是额外词条或改造；既有润泽与缓释仍只作用于饮用效果。家中取水也使用相同倍率，但受200容量限制，空青竹装满取125点原水，不会变成320容量。原型没有水壶互倒或回灌动作。

满壶边界暂用只取所需、余水留源：190存水的青竹只取6.25点、增加10点，40点水源剩33.75。按最多四位小数计算，正式整数化／溢出规则尚待用户评价。有限水源随整体保存，回家、再外出、装卸、死亡或刷新不重置；只有明确样例／重置入口补回示例供给。

青竹现已注册为 `tool_flask_bamboo_water` 并加入制作配表，水壶页可选择两种配方，见下文制作接入检查。专用美术、铁皮快饮与粗陶持续恢复仍为讨论提案。终端`B/I`载入青竹／铁皮空壶与40水，`N`载入青竹190与40水，`f`装壶、`u`直接喝水源；`[`选择铁皮配方、`]`选择青竹，`g`制作。正式接入时须按每个恢复点身份保存供给，不能复用原型单点状态。
