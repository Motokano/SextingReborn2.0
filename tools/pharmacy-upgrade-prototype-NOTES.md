共用规则依木作→金属→机件顺序手动滑条选择，每次从0起，不自动预选。允许分次投入，扣料、进度、材料用途记录与保存失败回退均走原管线；当前类缺料不能提交，缺少后续类仍可完成先前部件。关闭重开时保留投入、扣除及当前部件，选择量清零；全部完成后点击「完成」进入药品页。基础材料默认显示，高级替代材料仅持有或实际投入后显示；混投、整件退回、溢出贡献规则保持。

关闭建造窗口后，底栏提供材料齐备、未修复、缺少机件与替代材料四种情境；未修复情境提供原基础修复及首次升级的足额材料，替代情境使用青竹杆×4、铸铁×2、机械零件×1支付。完成升级前可切换；重置制药台回到当前情境的修复状态及未升级状态、恢复材料，药品库存和历史保留。重置药品不会重置设施。共用窗口打开时隐藏底栏并将焦点、键盘管理交给原面板。

启动：`npm run prototype:pharmacy-upgrade`。

入口：`http://127.0.0.1:8052/tools/pharmacy-upgrade-prototype.html?no_reload&variant=A`。A为左侧药品、右侧操作；B为顶部药品、居中操作；C为库存清单内展开。底栏箭头或输入框外的左右键切换，更新URL并共用本次库存与结果；刷新重置试玩。

加载正式游戏场景和现有墨绿暖金主题、药品图标。加载游戏前将localStorage、sessionStorage替换为内存对象，隔离运行锁与广播；仅本页创建试玩角色。升级库存为本页内存栈，按正式物品的100件上限补齐或分堆，界面显示各版本库存总量，不占用正式角色背包。每种通常版赠500件、初回版和完全生产限定版各100件，末档初始0件；底栏可重置库存。

名称、版本、相邻档产物及概率读取`data/items.json`的`innate_medicine_profile`，目录读取`data/innate-medicines.json`。每批同种同档、整数1至100件，`P=min(1,(N/100)^1.5×(1+L×0.01))`；底栏可将制药等级调为0至100。判定用完整精度；满级62件约97.6%，63件起必成。成功、失败均扣料，仅成功获得下一档1件。连续10次逐次独立判定，须有完整10批材料；最高版本不提供升级操作。

设施和药品升级均即时结算。正式设施材料数量、施工工时与体力，及药品升级工时、体力、设备要求、损坏、经验和失败副产物仍未定，本页除临时设施材料外不模拟这些费用，不把普通制药满级必成或其他修正带入。没有服用、先天成长或次数存档；本页的库存、设施状态与制药等级只供试玩，不写回正式角色数据。共用制药台整理了模式按钮及名称，强化视图只在试玩注册，正式强化操作未接入。
