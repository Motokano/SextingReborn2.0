0. 战斗设计总览

本作战斗是格子地图上的回合制近战：玩家与敌人各占一格、不可叠格；「相碰」指邻接交战而非走入敌格。一次完整交战消耗玩家本回合行动份额，并按西林式节奏推进——玩家动一次，场上敌人各动一次。

格战与输入8 向移动/攻击；朝敌格移动意图可转普攻；正前方 1 格单体
先后手取整速度比决定先手；同速双段演算后同时提交
命中 → 招架 → 减伤速度参与命中；柔韧参与招架与基础防御
肢上技能四肢各装主动+招架；招式槽/变式槽/成数分槽
资源气力（战斗中）；底气（生存+催发）；无「气劲」
构筑层后遗症、变式、Buff 经统一事件管线触发

属性口径：战斗公式使用「先天 + 后天」实际值；经脉/穴位间接影响底气与五维，不改变本节流程骨架（见 12-meridians-and-acupoints.md）。

1. 节奏、格战与回合消耗

占格与「相碰」

  • 玩家与敌人不得共占同一格；朝敌人格发出移动意图时，若在攻击范围内则不入敌格，改为邻侧触发攻击。
  • 一次由玩家发起、进入完整战斗流程的交战 = 消耗一次行动份额 + 跑完该回合战斗结算链路。

消耗回合的动作

  • 耗回合移动一格、普攻、使用技能、使用道具、等待
  • 不耗回合纯查看等（后续定义）

战斗节奏

风来的西林式：玩家每行动一次 → 所有敌人各行动一次。方向与范围：8 向；普攻默认正前方 1 格单体。

2. 战斗资源与出力成数

气力值（QiLi）

  • 仅战斗中启用；快耗、快消。
  • 施展依赖气力的招式扣 qi_li_current。
  • 本回合未发生气力消耗时，回合末恢复 qi_li_max × qi_li_regen_pct_per_turn（默认约 25%）。
  • 基本呼吸法「吐纳」可战斗中固定回复 50 点（有冷却），与回合末回气不互斥。

底气（DiQi）

  • 生存向资源；自然恢复、行气、呼吸法护体等见 06-survival.md。
  • 部分招式在 10 成（或按配置）除气力外还可扣底气。
  • 可参与底气催发伤害乘区（与成数挂钩）。

无「气劲」：战斗消耗仅由气力与/或底气组成；不存在第三条同名资源。

出力成数（1～12 成）

  • 伤害与资源消耗与成数挂钩：\(F_{\text{出力}} = \text{成数}/10\)；10 成基准消耗 × 成数/10。
  • 模板提供 default_power_level、power_level_min/max。
  • 生效成数来自当前招式槽位存档的 power_level（分槽配置，每槽可不同）。

资源不足仍出手（已定）

  • 应扣量始终按槽位成数 \(k\) 计算；实际扣除 min(应扣, 当前)，扣至 0、不记负。
  • 本击仍走完整命中/招架/伤害流程。
  • 当前实现约束：气力或底气任一不足以覆盖应扣量时，本击最终伤害强制为 0（保留流程反馈，禁止资源透支打伤害）。

头顶气力条（反馈 HUD）

  • 仅 inCombat=true 且气力未满时显示玩家条；需特殊技能 special_battle_sense ≥ 1。
  • 敌人气力条：玩家 special_battle_sense ≥ 3 时可见。

3. 战斗速度、先手、连击与同速

速度公式（玩家）

V_base ← hubs.footwork 当前步法的 combat_speed_base（无步法 → base_speed_no_footwork，默认 1） 速度(浮点) = V_base × (1 + 0.005×身手 + Σ装备等%) 速度(取整) = max(1, floor(浮点) + ⌊步法等级/10⌋ × combat_speed_per_10_levels)

敌人速度为配置表直接整数，不走身手/步法公式（见 §16）。

先手语义（一次交换内）

  • 先手方先完整跑完本侧：命中 roll → 招架 → 减伤 → 扣血/损毁/资源/Buff/即时效果。
  • 后手方在先手全部结束后才开始；若先手已击杀/失能，后手不再还击。
  • 速度高者先手（取整后比较）。

同速：同时结算

  1. 以交换起始快照先演算玩家侧待提交变更集（不写 HP）。
  2. 在同一快照上演算敌人侧变更集。
  3. 同时提交两侧结果——允许互中、同归。

先手例外（后遗症）

攻击方本击 move_id 在出招肢已装配 initiative_always_first 后遗症时，在速度结构之后强制攻击方严格先手；双方均有则互抵回退速度结构。连击段数仍仅由速度倍率决定。

连击

速度倍率连击段数（先手方）
≥ 2× 对方2 段
≥ 3×3 段
≥ 4×4 段

每段独立命中/招架/伤害/扣费；慢速方在对方连击全部结束后还手一次。

4. 地图普攻：肢序、互斥与敌先还击

出手顺序（取代旧 priority）

  • 存档 limb_strike_order：四肢各出现一次的排列 + limb_strike_order_cursor 游标。
  • 自动普攻按顺序扫描，跳过空槽/标签不符/损毁肢。

同一次交换内：普攻肢 vs 招架肢互斥

  • 某肢已用于普攻出手，则本 tick 不可再作 guard_limb 承担招架。
  • 躯干受击时在剩余候选肢中按 lhand → rhand → lfoot → rfoot 取首条未损毁肢。

敌速更高时的二次选肢

地图普攻且非显式三件套（未同时指定 skill_id + limb_id + move_id）时：若敌方取整速度更高，须先结算敌方还击，再按肢序二次选定本击实际出手肢与招式，并重新解析成数/后遗症。不回滚已发生的还击；与终稿「强制玩家先手」冲突时仅打提示日志。

6. 命中率

由攻防双方取整后速度参与；同速基础约 80%～85%；无法达到 100%（有硬上限）。

r = V_攻 / max(V_防, ε) r ≥ 1：P_base = P_eq + (P_max - P_eq) × ln(r) / (L + ln(r))，clamp 到 [P_eq, P_max] r < 1：P_base = P_eq × r + P_min × (1 - r)，clamp 到 [P_min, P_eq] P_命中 = min(P_base + B_命中, C_命中) （C_命中 < 1，如 0.99）
配置字段含义
hit_base_at_equal_speed同速基础命中率 \(P_{\text{eq}}\)
hit_base_max仅速度侧基础上限
hit_base_min攻方更慢时下限
hit_final_cap最终上限 \(C_{\text{命中}}\)
hit_curve_L、hit_epsilon曲线常数、防除零

7. 原始伤害（减伤前）

玩家近战 raw（地图 resolve 口径）

raw = max(0, B_底 × 增伤 × (1 + R_技能总熟) × F_实战经验 × k/10) 资源门闸：气力或底气任一不足应扣量 → raw = 0（流程仍走）

底数 B_底

技能类型底数来源
徒手 unarmed筋骨实际值 / fist_jingu_divisor（默认除数 5）
兵器 weapon对应手持槽武器 weapon_attack_power

增伤（加性块，含招式熟练度）

增伤 = 1 + Σ(x-1) + R_move = 1 + (Base(L)-1) + (呼吸法威力-1) + (M_move-1) + (G-1) + (K_试探-1) + (惯用肢-1) + R_move
  • Base(L)：技能等级曲线；R_move：该招式使用次数 / 50000，满 100%。
  • G：手套/鞋或武器 skill_coef；惯用肢出招 ±10%。
  • K_试探：仅摆拳且持有 buff_probe 时 = 1 + 0.05×层数。
  • 1+R_技能总熟：该技能所有招式熟练度算术平均（独立乘区）。
  • F_实战经验：每 1 亿实战经验 +5% 全局伤害，上限 1000 亿（见 §16 旁注）。

文档层原始伤害（08 广义口径）

rawDamage = 武器基础伤害 × W_coef × 实战经验 × 环境 × 暴击 × 底气催发 W_coef = W_skill × M_move × G × K_试探 武器基础伤害：徒手=筋骨；兵器=武器表基础伤害

8. 三类型伤害后处理

主公式产出 rawDamage 与初始 damageType 后，注入三类型池 { blunt, slash, pierce }。全程保留小数，仅最终扣血 floor。

注入 typed[damageType] → 前置注入 add_flat / add_from_pct → 首轮 increase_pct 增伤 → 单向转换 blunt→slash、slash→pierce → 转换后二次增伤（仅新增分量） → 进入减伤链（分类型结算后汇总）

禁止反向转换（如 slash→blunt），防止结算递归。配置字段：damage_type_effects（招式/物品/词条）。

对账示例

输入：20 blunt，增伤 blunt +20%，slash +20%，转换 blunt→slash 20% → 首轮：24 blunt → 转换：19.2 blunt + 4.8 slash → 二次增伤 slash：5.76 slash 结果：19.2 blunt + 5.76 slash（落地前不取整）

9. 招架段（命中成功后）

解析承担招架肢 guard_limb

受击部位guard_limb 规则
四肢（left_arm 等）固定对应该肢；已损毁则跳过整段招架
头 / 胸 / 腹按 lhand → rhand → lfoot → rfoot 取首条未损毁肢
四肢均已损毁跳过招架段

招架数值

  • 等级 = 招架槽所挂战斗技能等级（不单独计招架等级）。
  • raw = 基础值 × (1 + 系数 × 柔韧)；默认硬顶：招架率 75%、卸力 50%（可被效果突破）。
  • 再叠加 Buff 百分点修正（如失衡每层 −5%），clamp 到合法区间。
  • 敌人不享受柔韧加成，直接用配置基础值。

结果

招架成功 → 伤害记 0；可叠 debuff（命中已成功项仍生效）
招架失败 → 硬减伤 ×(1−卸力比) → 进入减伤链

行气时被攻击：招架判定自动失败。本段不消耗气力/底气（基本招架无消耗）。

10. 减伤链（招架失败且卸力后）

底气护体 % → 防具减伤（头/衣分部位，三类型各一档） → 基础防御 DR = S_柔/(S_柔+3D) → 伤害类型微调 M_部位,类型 → floor → 扣 HP / 损毁 Q
  • 防具基础减伤与词条 armor_bonus：乘算剩余比例。
  • 敌人用配置内功减伤与身体减伤替代玩家柔韧动态防御。
  • 链内保留小数传递；仅最终扣血与损毁增加值向下取整。

撞墙加伤（与击退联动）

tick 末击退未跑满格数时，在减伤链全部完成后、写 HP 前，最终伤害 × wall_slam_final_damage_multiplier（默认 1.3）再 floor。

11. 命中部位与肢体损毁

七部位

头、胸、腹、左手、右手、左脚、右脚。命中部位按招式权重随机（躯干偏高、头偏低等由招式表配置）。

部位效果（摘要）

部位效果要点损毁满值
头眩晕无法行动（可自恢）50
胸仅算伤害100
腹一次性降低饱食/饮水80
手命中/招架下降；几率骨折100
脚暂时无法移动；几率骨折100

损毁累积与重分配

  • 损毁增加值 \(Q = \lfloor\)最终伤害\(\rfloor\)（与扣血同源）。
  • 命中部位未损毁：\(Q\) 全部加在该部位（受上限封顶）。
  • 命中部位已损毁：\(Q\) 均分到其余未损毁部位（余数按 头→胸→腹→四肢 顺序 +1）。
  • 七部位均已损毁：本次 \(Q\) 作废。
  • 损毁满后失去功能（四肢无法出招/招架等）。

12. 战斗技能五分类

类别挂载招式槽要点
徒手四肢主动槽有筋骨为武器基础伤害；肢上招式循环

步法hubs.footwork无熟练度提供 V_base；仅间接影响命中（速度）

肢上布局（主动链）

  • 每肢：1 主动战斗技能 + 1 招架技能。
  • 招式槽与变式槽共用：同槽二选一；每肢至少保留 1 个主动招式。
  • 每槽可存 power_level（1～12）；变式不参与招式指针轮转。
  • 招架变式槽：每肢最多 5 槽，招架等级每 200 级开 1 槽。
  • 出招顺序：limb_strike_order 排列 + 游标（非旧 priority）。

技能 id：combat_basic_unarmed。四招：刺拳、正蹬（1 级）；摆拳、鞭腿（50 级）。

试探（buff_probe）速记

  • 刺拳命中 roll 成功叠层（最多 3）；摆拳算伤时 K = 1 + 0.05×层数。
  • 摆拳命中成功且伤害结算完成（含 0 伤）→ 整实例清空（非逐层扣）。
  • 多 sub-hit：全部段结算完后统一判定是否清空。

14. 后遗症（构式）与变式

后遗症 Post Effects

  • 由技能总熟练度或单招式熟练度解锁；须装配才生效。
  • 装配在出招肢；同肢同 id 唯一（四肢可各一份）。
  • 可改规则：如 initiative_always_first、驱散增益、伤害类型改写等。
  • 数据：data/post-effects.json + 招式 post_effect_unlocks。

变式 Variants

  • 与主动招式共用槽位；全局解锁后可装任意合法槽。
  • 不参与招式轮转；target_filters 只约束结算是否生效。
  • 独立 effect 体系（不复用 Buff effect 目录）。
  • 可辅助主动招式或招架（assist_scope）。
  • 数据：data/move-variants.json。

伤害修饰分两类：加性增伤区（Increased/Decreased）与独立总增乘区（More/Less，多条相加后一次乘算）。

15. Buff 系统与战斗事件

命中语义（强制）

  • consume_mode = on_hit_roll_success：只看命中 roll 是否成功。
  • 招架致 0 伤仍算命中成功，消耗/叠层照常（试探、失衡、驱散等）。

推荐战斗事件名

阶段event_kindevent_name
命中判定已出combatattack_hit_roll_resolved
伤害已写入（含 0）combatattack_damage_applied
单 sub-hit 结束combatattack_subhit_resolved

每 sub-hit 须唯一 event_id；新增事件/tag 须先登记 buff_event_registry.json。

命中方位（Hit Arc）

相对夹角 ≤45° 为正面、45°～120° 侧面、>120° 背面；事件 payload 带 defender_hit_arc / attacker_strike_arc，供 Buff/NPC 条件过滤，默认不直接改命中公式。

实战经验值（玩家）

F_实战经验 = 1 + clamp(combat_experience) / 1e8 × 0.05 上限 1000 亿；战斗胜利获得，永不回退；碾压弱敌不再获得

17. tick 末击退队列

  • 时机：本 tick 全部命中/招架/伤害/连击结束后执行；伤害中途不改坐标。
  • 同 tick 至多一条：先取 cells 最大子集 → 攻击方筋骨低者优先 → 速度低者优先 → event_id 字典序最小。
  • 入队条件：命中成功且招架失败（未完全免伤），如正蹬 on_parry_failed_at_tick_end_displace_target。
  • 方向：away_from_actor → 八邻域中与攻击向量夹角最小的可走格。
  • 阻挡：地形/边界/占格实体均阻挡，不挤开；未跑满格数触发撞墙加伤。
  • 不消耗目标移动权；不默认触发借机/陷阱。
