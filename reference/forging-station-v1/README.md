## 造型

大铁砧作为首要识别点，前部木墩用铁箍加固；后方小锻炉、短烟管形成次要轮廓。锤、钳与低矮淬火桶辅助表达敲打、加热与淬火操作，不增加人物、武器陈列、招牌或大建筑。

少量铁箍、铆钉和炉体结构表现现有背景中的工业能力。本图只表达设施外观，不新增燃料管理、独立水量消耗或其他操作条件。
