基于《堆肥/沤肥 UI/UX 设计方案》的动态演示

信息架构与业务流程

本区块展示了设施界面的核心布局逻辑与状态机约束。根据设计方案，UI必须采用“三段式”纵向布局，并严格遵循“文本呈现为主、隐藏数值化熟练度”的硬约束。此架构确保玩家能在一个视图内完成从投料、监控到收取的全周期操作，且关键阻断（如未清空产物禁止开始）具有极强的可见性。

📥 左侧：投入与感知

  • 展示当前投入的物料清单条目。
  • 提供基于 C/N (碳氮比) 的盲投感知反馈文案。
  • 5档颜色语义实时变化，指导玩家配比。

⚙️ 中央：过程与记录

  • 显示发酵总进度与当前状态描述。
  • 滚动显示系统日志与环境事件记录。
  • 在特定 Tick 窗口弹出交互按钮（翻堆/放气）。

🎁 右侧：产出与结算

  • 发酵结束后展示生成的产物列表。
  • 提供全部收取与放弃残渣功能。
  • 若槽内有遗留物，将触发全局互斥，阻止新批次开始。

发酵时间轴与交互频率分析

此动态图表直观对比了“堆肥（288 Tick）”与“沤肥（1008 Tick）”的底层数学模型。图中的峰值波段代表系统判定的“交互窗口期”。玩家必须在此波段内点击界面上的操作按钮。错失窗口将导致隐藏的 score 变量扣减，最终影响产出质量。

UI 组件与色彩语义映射

由于核心约束要求“去图标化”并“以文本为主”，界面颜色的语义传递变得至关重要。以下展示了方案中定义的5个色彩基准，这些颜色通过纯粹的十六进制代码应用于文本和边框，替代了传统的图标警告系统。

#E0E0E0

#B8860B

#6B8E23

#CD5C5C
