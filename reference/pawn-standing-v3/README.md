# 完整部件站姿 v3

按用户确认改用完整部件：头、完整上衣、左右完整袖子与手、左右完整裤腿与鞋、底座，共7块。游戏七部位损毁逻辑与美术切片不一一对应：胸腹共享整件上衣，在各自区域叠加伤效；臂腿按对应组隐藏。

补全原则：肩根、腰部和颈部等被遮挡区域仍需完整绘制，放到相邻部件后面形成重叠。取消胸腹、肘部、膝部人为切口。弯臂、扶胸、扶腹、撑地、屈膝、前伸分别制作完整轮廓变体，不能靠大幅拉伸直部件实现。

本版完成的是正常站姿的完整部件草稿与装配对照；动作变体尚未制作，不能宣称已适配128状态。生成的部件与原图可能存在笔触及形状差异，待视觉验收。原始骨架未修改、未用来决定外观比例；游戏未替换。

standing-bind.json保存外观空间内的裁切、位置、尺寸、层级。完整PNG与生成记录同时留存。下一步先验收站姿，再按已保存动作的支撑需求制作完整部件变体，记录各状态选用的部件及姿态适配参数。
