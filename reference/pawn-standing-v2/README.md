外观参考：`original.png`。部件草稿：`parts.png`。站姿装配记录：`standing-bind.json`。裁切、位置与尺寸属于1215×1295外观图空间，独立于共用骨架。

部件图由主角外观草稿经imagegen清理连接处整理，保留真实alpha；不是原图的逐像素无损拆分，局部纹理和形状可能变化。原图一直保留在对照左侧，不宣称已经完全一致。生成记录见`generation-record.json`。

验收先看头身比例、手脚位置、身体外轮廓，然后看胸腹、肩肘、膝部接缝。此记录尚未成为NPC模板。用户确认后再保存正式外观绑定，借用原姿势参考做独立适配，不能拿旧骨长改变主角。
