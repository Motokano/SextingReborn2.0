# 作物配套设施插画 · 第一版

2026-11-07。沿用农业 A 原型与作物图鉴的柔和矢量画风，补齐正式目录中的 7 类作物专用设施及 16 种所需组合。

支架：黄瓜、扁豆、大白芸豆、白扁豆；保护笼：番茄、绿番茄；捆绑带：甘蔗、大蕉；蓄水田埂：四种稻米；深水池：莲子、芡实；遮光罩：豆芽；顶棚：生姜。

每张 100×100 透明 SVG。绘制顺序为设施后层、适配尺寸的原作物、设施前层；前后层是绘图源中的独立片段，导出文件为完整静态插画。保持作物辨识形态，池内水面仅为插画表达，不表示新增供水或蓄水规则。

- `manifest.json`：正式设施 ID、名称、适用作物及素材文件对应。
- `<设施ID>.svg`：空设施。
- `<作物ID>--<设施ID>.svg`：种植组合，共 16 份。

源文件：`tools/agriculture-structure-art.mjs`。运行 `node tools/build-agriculture-structure-art.mjs` 导出并检查正式目录完整覆盖。

图鉴：`http://127.0.0.1:8053/tools/agriculture-crop-art-review.html?no_reload&tab=structures`。
