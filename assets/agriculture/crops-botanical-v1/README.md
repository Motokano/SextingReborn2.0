# 农业作物插画 · 第一版

2026-11-07。按用户认可的农业 A 原型画风，覆盖正式目录 `data/agriculture-crop-defs.json` 的全部 50 种作物。当前供原型与图鉴评审，尚未替换正式农业面板。

每种作物一份透明 SVG，100×100 画布，接地点约为 (50,88)。柔和绿、暖黄与果实色，无粗黑描边；同科植物共享视觉语言，以叶形、果穗、根茎或果实区分。玉米与樱桃保留已认可的造型。插画表现成熟辨识形态，地下根茎与籽实为识别而露出，不是逐阶段生长动画或现实植物图谱。

- `manifest.json`：正式 ID、中文名称、分类与文件对应。
- `contact-sheet.svg`：全部 50 种的总览。
- 其他 SVG：对应 ID 的独立素材。

绘图源：`tools/agriculture-crop-art.mjs`。运行 `node tools/build-agriculture-crop-art.mjs` 重新导出，并校验正式目录无漏项、无额外项、无完全重复图形。

预览：`http://127.0.0.1:8053/tools/agriculture-crop-art-review.html?no_reload`。可分类、搜索、切换底色、查看 32/48/64 px 尺寸并下载单张素材。

种植数量、类别、名字、门槛和生长规则仍由原数据提供；此轮未改变农业数值和正式存档。
