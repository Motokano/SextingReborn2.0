# 藏身处设施重画 v2

2026-11-01。用户要求自行查阅最新标准并重画藏身处设施。本轮依照 [77号场景美术标准](../../../../docs/design/77-grid-scene-art-standard.md)，实际引用一档地痞、已认可旧装置、v6家具与逐件几何模板，使用内置 **image_gen** 生成。用户查看全套对照后确认“可以实装了”，本版已正式定稿并接入地图及对话头像；批准范围与文件校验见 [approval.json](approval.json)。

11类设施共20张原始透明PNG：灶台、制药台、铸造台、制肥桶、卫生间、农场、牧场各有修复前后；缝纫台、工具台各有装配前后；床、仓库仅正常态。第12类制作台已按77号制作且破损v2获得用户确认，本轮沿用 `manufacturing-bench-v1/unrepaired-v2.png`，不重画其三级升级预览。

## 风格与结构

取消旧装置的圆展示底座、烘焙地面与地面投影；深色轮廓、成块手绘明暗、左上光，磨损集中在台面、接头、炉口、柜门和布料补丁。桌架加入旧金属、替换件和局部修补。牧场保留中央机械轴与四个区域，去除固定画在场景里的羊与土台；农场泥土仅留在真实种植箱内。它们仍是设施入口外观，不代替作物或动物实例的动态显示。

完整原图无裁改、剪切或非等比拉伸。`generation.json` 包含20次精确提示、引用路径、生成源和最终文件；`manifest.json` 包含原件SHA256、alpha、显示裁切、接地点、底面跨度、原生等比比例、工作面高度取样与状态登记。两态使用同一套脚点及比例，未完成状态只改变相应损坏或装配内容。

## 棋格登记

生成前的 [几何模板](../../../../reference/hideout-facilities-v2/geometry.json) 为144px格宽、144/√2格高、地面轴±1/√2；几何参考不作为成品。实际显示按人物旁的实物高度及脚点重新登记，模板尺寸是绘制目标，不能直接当作生成结果的精确尺寸。

`calibration.json` 保存人工估测的三个可见脚点和沿竖边取得的高度；后脚按平行四边形推定。圆桶以支架脚点登记，铸造台和卫生间为组合物件边界，不把这些点误当成一整块矩形箱身。所有脚点是展示定位数据，不是人物骨架数据。

144px棋格下：灶台工作面约40px、制药台37px、铸造砧面45px、缝纫台38px、工具台40px、仓库上层搁板59px、洗手盆41px、种植箱边21px、牧栏32px、床面26px。人物继续使用原图册及125%倍率，家具不乘人物倍率。生成图的局部原生角度仍有偏差，矩形样本残差逐件记在清单中（灶台最大约9.5px）；未用拉伸强行消除，也不宣称逐像素符合几何模板。

床逻辑占格1×2：原入口（11,15）保留，向（11,14）延伸；接地中心偏移到两格中点，新增格同步不可通行且按家具下方木地面绘制，不生成墙。其他设施位置与逻辑占格保持。全部设施仍可从出口到达相邻操作位置，两个传送点保持可达。

复现登记：`node tools/register-hideout-facilities-v2.mjs`。它只生成清单与 `tile-renderer-v2.js` 中标记的登记块，不改PNG。新素材仅匹配基地设施NPC ID，临时设施与其他地图沿用原登记。地图、对话头像、部分修复、存档读回与原来的9套完成条件一致，不新增完成标记，不补发材料或重置进度。
