# 地面背包棋子 · 第一版定稿

2026-11-01正式接入更新：用户授权物品栏改造接入后，本素材已替换正式已识别地面背包标记，原图不变。`js/core/tile-renderer-v2.js`复用下文的裁切、锚点、接触轮廓及等比尺寸；同格脚边25／7px偏移与最多3只错位绘制已部署，更多实例通过同格列表选择。正常地图与地牢都遵守原感知规则，人物125%倍率不变。正式双栏存取与时间规则见[81号第17节](../../../../docs/design/81-backpack-equipment.md)，浏览器验收见`tools/check-inventory-grid.cjs`。以下保留美术交付时的范围记录；`approval.json`仍记录当时的美术确认，不追溯扩大其批准范围。

2026-11-01。用户要求制作放在地上的背包棋子，并遵守已定规范。本版依照[77号场景美术标准](../../../../docs/design/77-grid-scene-art-standard.md)制作一张闭合的地面背包。用户查看后答复“可以，给我看看完整的地面交互逻辑”，确认这版外观；[批准记录](approval.json)记录范围与文件校验。**美术已定稿，尚未替换正式地面物品标记。**

本轮只制作一只共用外观，不据此确认三种型号永久共用外观。没有重画人物、扩展装备随穿戴换装或接入81号第11节存取窗口。地面包的空／满由真实内容决定，本图不表示「未搜」或「搜空」，打开交互窗口也不等于把包搜空；本轮仅交付用户所要求的一张闭合落地图。

- [closed.png](closed.png)：1312×1199，原始RGBA PNG，保持内置生成工具输出的全部像素及alpha，不烘焙背景、棋盘、地板、展示底座或地面投影。
- 使用内置 **image_gen**，完整精确提示、引用顺序、角色说明及生成源路径见[generation.json](generation.json)。生成原件保留在工具输出目录，项目中的文件与其字节一致。
- 实际查看并输入的参考：`reference/street-thugs-v1/tier-1.png`、已认可旧装置`interactive-devices-v1/warehouse.png`、v6的`stolen-basket.png`、本次预先绘制的[几何模板](../../../../reference/ground-backpack-v1/geometry.png)。
- 画风保持深色外轮廓、成块手绘明暗、左上光。旧橄榄色帆布、深色包底与扣带，局部磨损、一个侧补丁；肩带自然松垂，末端接地，无展示台、额外道具或散落内容。

## 尺寸与接地登记

[manifest.json](manifest.json)登记裁切、接地中心、人工估测接触轮廓、原生朝向、等比比例及SHA256。这里只登记显示，不改动原图或人物骨架。

- 生成前目标：144px格宽、144/√2格高、地面轴±1/√2；袋身底面0.36×0.22格，竖向包体高度32px，主要取用面朝+Y。模板是软袋包络，不要求生成物成为硬矩形箱体。
- 实际人物旁检查后，按袋身底部原图跨度723px等比登记为32px，缩放系数`32/723`。肩带算在完整可见轮廓内，不用肩带或透明留白宽度反推袋身尺寸。含肩带可见宽约45.1px、可见高度约45.9px。
- 显示裁切`[227,61,1034,1052]`；接地中心`[618,938]`。接触轮廓估测为`[500,780]`、`[980,949]`、`[736,1094]`、`[257,925]`，后侧点为推定；袋身是软弧底，不将这些点当成精确矩形脚点拟合仿射变换。
- 原生视角完整保留，仅等比缩放和定位；未剪切、横纵拉伸或随机旋转。近似竖向高度取样约27.6px，软布弯折使其只作为尺度参照，不宣称所有布边严格贴合投影模板。
- 逻辑上归属一个地面格，无移动／视线阻挡。阴影通过现有`TileRendererV2.makeGroundShadow`按接触轮廓单独绘制。
- 棋格检视页为精确144px参考；当前正式藏身处渲染格宽实测142.8356px，素材随实际格宽等比为31.7412px袋身底宽。人物始终用原图册及正式125%倍率，标准对照底座57.5px。
