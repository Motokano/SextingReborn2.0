# 普通地面物品 · 散落杂物第一版

2026-11-01。用户查看首版后明确“直接接入吧”，并强调地面清空时消失。本版已定稿并接入正式等距地图与地牢，批准范围与原图校验见[approval.json](approval.json)。

## 外观与含义

蓝灰旧衣、赭色小铁盒、少量金属零件与绳圈形成一枚扁平、松散的轮廓。布料局部修补、金属边角磨损；与已定稿立式背包和扎口尸体袋区分。画内零件是通用外观，不额外生成物品，不新增袋子或容器。

正式规则：同格普通散物共用一枚棋子；背包保留自己的外观；同格点击沿已有左随身／右脚下交换窗口；部分拾取保留杂物堆，普通散物全部取完即移除杂物堆和阴影。地上仍有空或满背包时，背包本体继续显示；所有地面物品都移走或清理后，该格不再显示掉落棋子与阴影。不阻挡移动，原拾取和清理规则保持。

渲染直接读取通过感知过滤的`groundCount`与`groundBackpackCount`，两者之差大于零才画一枚杂物堆。不保存独立标记，不补发物品；读档后从真实物品重新绘制，保存失败回退后棋子随物品保留。模糊位置沿用问号，不可见和身后剥离位置隐藏；原正交回退视图继续使用符号。

## 几何与显示登记

- 生成前包络：144px格宽、144/√2格高、地面轴斜率±1/√2，物体底面0.34×0.24格、实体高度目标10px，朝向+Y。包络不是硬矩形箱子。
- 原图alpha>16边界为`[285,234,1210,802]`；显示裁切`[277,226,941,584]`，接地锚点`[746,641]`。
- 按925px物体横向轮廓等比缩放至40px，倍率`40/925`；可见总高约24.56px。实体高度人工探针约9px。人物使用现有图册及125%倍率，参考底座57.5px；已定稿背包同时对照。
- 软布轮廓、后方遮挡接点和高度探针为人工估测，小铁盒边线近似原生地面投影。保留原图角度，不将估测点用于仿射校正，不宣称PNG生成了精确碰撞体或骨骼。
- 正式同格脚边为右36px／下18px，随格宽等比；同格还有背包时，杂物堆改放左36px／下18px，与背包分开。不改背包原25／7px偏移。其他格只有散物时居中，有背包时同样移到其左前方。
- 单格视觉归属，不阻挡移动或视线。只画一张有物品状态；捡空后的不显示规则无需空态图。
