### 底座阴影贴合修正

用户指出制肥桶投影像与底座分离。第一轮内收3px并补窄接触暗部的修正仍被用户否定，已由 footprint3 替代。

按用户提供的实物棋子照片，底座使用完整的地面椭圆占地形状，向右5px、向下2.5px连续扫出短影；上方装置的alpha轮廓从底座占地中心投影。两者先合并成一张遮罩，再统一着色，避免两层暗影叠加出分离的黑边。七种装置分别配置底座半径，制肥桶不把侧面把手计入底座宽度；这些椭圆是视觉近似，并非三维几何还原。根部较实，远端较淡，先画影子再画本体。源图片、尺寸和主体接地点不变。

已在144px格宽独立预览页检查七枚装置，当前底座与右下投影连续；仍待用户视觉确认。测试覆盖完整底座占地、连续延伸、中心投影和单层合并绘制。脚本版本为 `devices-20260915-footprint3`。

## 行为

- 可识别的设施NPC显示装置；普通人形NPC与敌人仍走原绘制逻辑。
- 床补入场景元数据，服从可见、可识别及背后遮挡三个分支；其他六类继续沿用现有可见性字段。
- 不可见的装置不显示本体或阴影，未知存在仍显示原来的问号。
- 加载中或图片失败时显示设施名称；原俯视模式仍使用原有文字表现。
- 点击坐标、NPC对话、设施面板、碰撞、存档与游戏规则未修改。
