## 规则与参考

新家具采用[77号场景标准](../../../../docs/design/77-grid-scene-art-standard.md)，优先于59号旧装置的展示底座处理。深色外轮廓、成块手绘明暗、左上光；现代旧物修补、局部使用痕迹，保留工作面。透明背景，无地板、圆台或烘焙地面投影。主角继续使用原图册及125%显示，不改人物比例。

实际查看了一档地痞、v6收账桌和既有制药台／工具台。基础台出图直接引用一档地痞、v6收账桌、既有工具台以及先画好的几何模板；升级在同一工作台上编辑，并继续引用原始画风图。人物和旧装置的底座只属于参考图，不复制到新家具。全部生成采用内置 **image_gen**，未使用CLI。逐次精确提示、参考路径和生成源见 [PROMPTS.json](PROMPTS.json)。

## 占格、锚点与高度

本轮提案为单格1×1，原生长轴+X、操作面+Y。升级不增加占格。生成前[几何模板](../../../../reference/manufacturing-bench-v1/geometry.json)按144px格宽、144/√2格高、地面轴斜率±1/√2绘制，台面目标高度42px。模板图是几何约束，不能作为美术成品。

[manifest.json](manifest.json)独立登记各图的显示裁切、三个可见脚点、接地中心、等比缩放和高度取样。按脚点左右跨度统一到104.4px，不按PNG外框决定大小；投影在预览渲染层绘制。三图工作面高度估测分别41.8、43.4、42.4px，参照现有主角约88px可见高度、57.5px底座宽。家具不乘人物的125%倍率。

脚点为人工估测；后脚位置按对角推定，未独立精确测量。生成图原生地面轴相对目标仍有约1.6～4.3px的取样残差，已记录而未通过非等比变形强行消除。本轮是可供评价的原生画面，不宣称与几何模板逐像素一致。

未修复v2四脚与保留的台面角位置延续v1的人工取样，沿用其登记值：工作面估测40.5px，地面轴残差约−0.8／+3.8px。生成图相对基础台在原画布上的位置与大小有少量变化，由独立脚点、锚点及等比缩放对齐；没有把“同一台体”解释成逐像素固定。原有三级登记值与原图不变。
