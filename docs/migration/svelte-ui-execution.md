P0 已完成，2026-10-14 用户要求开始执行后进入 P1。实现说明见 [Svelte 主 HUD](../../ui/README.md)。任务可以进一步拆小，但不能绕过前置条件或删除验收项目。每阶段先验证一个完整的真实数据交互，再扩大覆盖；阶段结束后游戏应能继续游玩。
