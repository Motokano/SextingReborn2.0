## 验收样本表

所有数据样本使用隔离浏览器存储或测试专用存档副本。不得清空用户正在游玩的进度来制造测试条件。先保存旧实现样本，再用同一份数据验证新实现。

| 样本 | 内容 | 用途 |
| --- | --- | --- |
| F01 新档 | 序章未完成、创角尚未出现、有限认知 | 启动闪屏、剧情锁、对话后创角 |
| F02 常规旧档 | 有已知技能、物品、配方、基地与工具标记 | 读档兼容、主 HUD、核心菜单 |

| F04 异常状态 | 七部位不同伤态、疼痛/眩晕/药瘾/毒性、交战/脱战、昏迷等 | 异常面板、动作守卫、恢复和动态显隐 |
| F05 物品边界 | 满包、空包、重名不同实例、堆叠、使用次数、模块装备、连接部件、超重 | 身份、消耗、溢出、携行、选择失效 |
| F06 作业与设施 | 已修/未修、投入部分材料、作业进行中、资源不足、结果待领取 | 全设施状态转换及存读档 |

| F08 存档失败 | 无效代码、错误凭据、旧世代、存储不可写、专业玩法 busy | 明确失败、无部分恢复/重复提交 |
| F09 专业玩法 | 钓鱼各作业阶段与知识、狩猎遭遇/结果/收容、缝纫作业与人台 | 状态机、离开代价、计时、知识披露 |

## 退路与停止条件

| 情况 | 处理 | 禁止做法 |
| --- | --- | --- |
| 某个切片尚未通过 | 默认仍用该切片的旧实现；测试入口只启用一个所有者；修好再切换 | 新旧界面同时接收事件，或隐藏旧 UI 却继续让它计时/扣料 |
| 切换后业务语义变化 | 回退该切片的入口与代码，保留用户存档；用隔离样本定位 | 清空用户进度“解决”不兼容，或篡改规则迎合新 UI |
| 布局解析异常 | 保持现有校验/回退到默认布局逻辑；不要扩大删除范围 | 连带删除角色存档、音乐设置或旧布局键 |
| 视觉不一致 | 对照原材质 CSS/标记结构与层叠规则修复 | 用更简单的框、去掉阴影/纹理、删信息来通过布局检查 |
| 旧脚本仍写新子树 | 暂停该切片切换，拆出真正的业务与视图边界 | 叠加更多 MutationObserver 互相纠正 |
| 全量收尾 | 对照全部 U 行、V 项和清理条件 | 仅主 HUD 或对话迁移就宣布“全部完成” |
