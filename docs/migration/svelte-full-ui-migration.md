## 迁移边界

| 范围 | 决定 | 完成标准 |
| --- | --- | --- |
| 玩家可操作的界面 | 全部迁移，包括 HUD、弹窗、创角、对话、菜单、提示、所有已接入设施 | 界面清单所有正式行都有 Svelte 所有者，旧渲染和绑定退出 |
| 当前 C 版外观 | 保留当前本体的紧凑 C/reference 版 | 材质、边框、纹理、阴影、配色、文字层级、交互和信息不缩减 |
| 信息分类 | 身体、生存、成长、携行、状态、战斗、事件记录；环境整合顶栏 | 不恢复无有效信息的人物介绍或身体小人 |
| 窗口交互 | 独立拖动、关闭、恢复、收起、锁定、布局记忆与重置 | 保留现有设备布局与认知门控的组合语义 |
| 认知规则 | 类别、字段、选项、提示等都接受业务规则控制 | 玩家未知的信息不会通过隐藏栏、管理菜单、提示或读档闪屏暴露 |
| 游戏业务 | 继续由现有模块拥有 | UI 不复制生存、战斗、物品、配方、时间和存档状态作为第二套事实来源 |
| 地图、棋子与特效 | Svelte 管理场景宿主的挂载；现有渲染器继续绘制 | 保留 Canvas 与地图 DOM fallback；不重绘棋子，不改战斗动画或投影算法 |
| 独立缝纫页面 | 属于本体功能，纳入全量迁移 | 主游戏入口与原独立 URL 的明确兼容策略均验收；不能只换 iframe 外框 |
| 调试与预览 | 正式入口中的调试 UI 迁移或明确移出生产入口；独立原型保留 | 不把演示页计入正式完成率，不为迁移删除美术参考或玩法原型 |
| 玩法与美术变更 | 不随本次迁移调整 | 并行的战斗、农业、锻造工作单独保留；迁移接入它们的最新接口 |

## 迁移前实现与历史方案

| 项目 | P0 盘点基线 | 迁移处理 |
| --- | --- | --- |
| 主入口 | [index.html](../../index.html) 加载全局 JavaScript 脚本和静态 HTML | 分阶段用 Svelte 接管指定子树，最后收敛为场景宿主与应用入口 |
| 构建 | [package.json](../../package.json) 尚无 Svelte 依赖；dev 使用 [serve-live.mjs](../../tools/serve-live.mjs) | P1 增加编译和构建验证，保留当前端口、资源路径及 no_reload 行为 |
| 主 HUD | [ui-moss-game.js](../../js/ui-moss-game.js) 改造既有 DOM，包装 SceneHud.refresh，监听 DOM 变化 | 将展示模型与窗口规则移入新层，移除对 Svelte 节点的旧写入 |
| 刷新通道 | [scene-hud.js](../../js/scene-hud.js) 的 register 每个 kind 只保存一个回调 | 过渡期由一个路由协调新旧刷新，不把它当成已有多订阅事件总线 |
| 对话 | [dialogue-ui.js](../../js/dialogue-ui.js) 混合直接 DOM 和 [dialogue-react-view.js](../../js/dialogue-react-view.js) | 对话正文、名字、头像、按钮、选项整体迁移后删除正式入口的 React |
| 启动就绪 | [bootstrap.js](../../js/bootstrap.js) afterStart 不等待 SceneApp.init 内的异步加载 | 新增明确的就绪边界，覆盖配置、地图、存档恢复及动作接线完成 |
| 历史 Svelte | 对话试作与 game-state-core 已放入 [_archive-js](../../_archive-js/README.md)，未接入本体 | 仅参考；不直接启用旧状态核心，也不引入通用 HP 替换七部位损毁 |
| 混合职责 | 部分 Panel 文件包含扣料、计时、领取和业务守卫 | 先提取可调用的控制器，再替换渲染；不能删掉文件时一起删掉玩法 |

## 视觉与尺寸基准

正式基准是 [71 号接入记录](../design/71-moss-hud-runtime.md) 中的**后续紧凑尺寸**。原型保留材质来源作用，但原型早期的大尺寸不再覆盖用户后续缩小要求。

| 项目 | 基准 |
| --- | --- |
| 样式来源 | [ui-moss-prototype.css](../../css/ui-moss-prototype.css) → [build-moss-runtime-css.mjs](../../tools/build-moss-runtime-css.mjs) → [ui-moss-runtime.css](../../css/ui-moss-runtime.css)，叠加 [ui-moss-game.css](../../css/ui-moss-game.css) |
| 1440px 桌面 | 底部四窗 272×280，居中、底部 18px；顶栏 54px |
| 1024px 桌面 | 底部四窗 240×280；保留紧凑字号 |
| 附加窗口 | 事件记录 300×200，状态宽 230，战斗宽 220 |
| 390px 窄屏 | 顶栏自适应高度，面板纵向滚动，所有按钮及面板可达 |
| 默认信息 | 七部位、六项主要生存指标无需内部滚动；情绪/清洁及研习/属性经验保留在补充入口 |
| 用户布局 | 优先保留自定义坐标和显隐；旧宽高不能把窗口撑回早期大尺寸 |
| 对照方式 | P1 开工前，以同一存档、分辨率、缩放、字体、资源加载状态录制本体截图和样式值；历史 tmp 截图不作为唯一证据 |
