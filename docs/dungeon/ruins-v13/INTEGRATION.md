# 村外废墟正式游戏接入

确认日期：2026-10-26。新探险使用内容配置 V13。

## 已接入

- 当前废墟街区生成；约一半林地、稀疏的独立装饰植被，植被只在自然地面落点。
- 土匪据点、废弃修理车间、废弃诊疗所、废弃食堂；大型房按完整使用／少量使用／废弃布置，默认权重 40／40／20，不额外增加整层敌人、容器和资源预算。参数读取 `data/dungeon-config.json` 的 `content`，门票可覆盖。
- 室内绕行障碍、隔墙、预留通路及操作邻格；正式玩家和敌人使用同一套碰撞和视线遮挡。八向移动不可穿墙角，门只能开启。
- 模块地板、多款墙面、场景装饰和已确认的容器尺寸、落点、缩放。地图与玩家保持同一相机中心，前后景排序包含地牢物件与敌人；未见地形先遮蔽，再绘制可见物件，避免将高物件按地格切断。
- 容器投放分类与内容偏好。食材筐是普通容器，空率、额外判定、逐项揭晓、领取沿用普通容器流程；实际抽取权重为可掉落库存乘以类别偏好。
- 搜索技能 `survival_search` 每级降低容器空率 0.2 个百分点，最低为 0；额外数量判定使用同一空率。内容在首次开箱完成时锁定，升级与读档不重抽。尸体空率不受此技能影响。
- 正式背包、体力、伤势、潜能、时间、战斗、回收抽成和存档继续使用游戏已有服务。

## 种子

新建探险时读取当前电脑时间 `Date.now()`，以毫秒时间戳加同毫秒内的序号组成种子；无固定种子、无随机 UUID。种子在确认进入时生成一次，保存在探险记录中。

后续层按本次种子、楼层、生成重试序号派生。读档直接恢复已存地图和内容状态，不读取当前时间重抽；重新发起探险才读取新时间。V2 旧探险保存的地图和旧内容配置继续保留，深入也不自动升级成新配置；新探险开始使用 V13。

## 存档与边界

结构阻挡、遮挡、隔墙集合和房间地板映射以数组保存，读档后恢复集合与映射类型。关闭的门、容器揭晓/领取、资源采收状态、探索记忆与有限掉落库存均保留。沿用原有原子提交，写入失败回滚。

掉落池仍以已确认的有限库存批次为唯一来源。本次不把原型演示物品、食材示例自动放进正式池；当前 `pool.batches` 为空，具体物品名单与库存需后续配置。类别权重机制已接通，资源采收等既有直接产出不受此限制。

特别楼层内容、门票/线索的具体条目及保险依旧按既定范围单独设计。

## 验证

- `tools/dungeon/test-generation.mjs`：16 张随机地图，房间、资源比例、无门房与门票覆盖。
- `tools/dungeon/test-ruins-v13.mjs`：电脑时间种子、同毫秒防重复、正式阻挡、存档恢复、地板映射、搜索空率、分类权重、跨层种子。
- 原地牢功能、边界、AI、事务、UI 和检查站回归测试。
- 隔离的正式游戏页面检查大型房、林地、开门、前后景和读档，测试页不安装到正式游戏，也不修改玩家原有存档。
