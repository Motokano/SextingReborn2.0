# 废弃诊疗所

> **V13 当前分配方式：** 采用[大型房间三态规则](LARGE-ROOM-STATES.md)，完整占用／零散占用／废弃目标 40%／40%／20%。主题先布置地形，再分配本层已有敌人与容器；零散和废弃房可保留同主题结构。下文 1～2 间总名额、单主题每层上限与主题抽选概率属于 V12 及以前，新探险由 `largeRooms` 配置替代；原主题空间、素材、交互规则继续适用。


日期：2026-10-26。内容配置 V9，已接入废墟原型。用户已确认当前隔间、双通路、敌人与恢复点分布及视线遮挡版本，作为后续制作基准；数值仍通过配置调整。本次范围为废墟原型，未改动正式游戏。

## 空间与两条通路

- 使用既有建筑中 70～100 格连续室内地板，不扩墙、不挪门、不改变街道。前厅为候诊区，中部与后侧设置两个 2×2 诊疗隔间；靠外墙放一组两人候诊长椅，较深隔间放破旧病床及急救推车。
- 两个隔间共用分隔墙，内部缺口始终敞开，不生成额外收费门。另一隔间安排一个容器和一名守卫。主体可随实际建筑沿两个地图轴旋转、改变纵深方向。
- 形成一条穿过前侧隔间的内侧路线，以及绕过背侧隔墙的外侧路线。两路有共同分岔点和汇合点，中间不共用格子；标准模块分别为 7 步和 11 步。它们是局部通路长度，不等于门口到恢复点的总距离。
- 两侧各预留两格宽固定通道，两条路线、缺口及门内落脚格禁止放固定家具、容器和初始敌人。敌人战斗中仍可正常进入通道，不能把“预留通路”当作战斗时无敌人占位的保证。
- 实体结构包含 11 格高隔墙、两格病床和两格候诊长椅，共 15 个固定阻挡格。病床和长椅各整件绘制一次，不能用放大单格图冒充多格结构。辅助家具最后沿墙放置，以破椅子、暖气片为主。
- 地面为旧混凝土叠加低对比的浅灰绿方砖接缝，外墙和隔墙沿用灰绿脱落涂层；不使用完整崭新的医疗设施。

## 敌人与功能点

默认 3～4 名敌人，按入口、中部隔间、较深处错开。84 格以上优先尝试 4 人，站位或额度不足时尝试 3 人。至少一名守卫位于前侧隔间，初始站位不堵两个通路；沿用未激活静止、敌我同一视野、直接共享不接力、丢失超过 3 tick 回位恢复的规则。

默认 1 个急救推车和 1 个原有容器。急救推车在后侧病床旁，可从至少两个正交格操作；使用原有治疗规则：1 次、4 tick，合计减少目标部位上限 20% 的损毁，中断保留已完成进度，续用不重复结算；用尽后保持已使用棋子并保存。容器沿用 40% 基础空率、数量加成、逐项搜索与领取，不保底出货、不提高稀有度。

诊疗所与普通据点、修理车间共用大型房间目标（默认每层 1～2 间），不新增独立房间配额。敌人从本层既有室内敌人额度转移，容器从本层既有室外容器额度转移。急救推车占用本层唯一的室内恢复点名额，计入整层 2～3 处恢复点上限；已有室内恢复点时不再生成诊疗所。资源、领悟及预留空房规则不变。

这是专门定义的大型房型，允许恢复点与容器共同出现；普通五类小型混合房仍维持原有单类功能内容规则。

## 避免卡位与视线

先完整规划墙体、病床、长椅、通路及功能点，再排敌人，最后放辅助装饰。全部验证通过才提交，失败时回退其他房型，不留下半套障碍或消耗失败额度。

- 所有固定物件、初始敌人和功能点不重叠；合计占用后至少保留 60% 可走地板，所有自由格正交连通。
- 两条通路中任意一条的中段被移除后，另一条仍能连通分岔与汇合点。不可把一条共同瓶颈算成两条路线。
- 每个功能点至少保留两个可达正交操作格；每名初始敌人都有可达相邻格，门外到门内、楼层入口到撤离点仍可通行。
- 高隔墙同时阻挡移动和敌我视线。病床、候诊长椅及低矮装饰只挡移动，不额外挡视线；八向移动禁止穿墙角。
- 隔墙按格判定可见性，床和长椅按整个足迹判定；墙后地板、敌人及功能点各自受真实视野限制，不因显示家具而提前揭晓。小地图记录实际探明的阻挡。
- 关闭可选装饰开关仍保留隔墙、病床和长椅这些玩法结构。外门沿用现有木／铁门扣费与只能打开规则；无门诊疗所直接通行。

## 配置与兼容

参数位于 `content-config.js` 的 `clinic`，由既有地牢／门票覆盖流程解析并保存到本次探险，不写入玩家界面。

| 字段 | 默认 | 含义 |
| --- | ---: | --- |
| `enabled` | true | 启用候选 |
| `chance` | 0.45 | 合适建筑优先尝试诊疗所的概率，并非最终出现占比 |
| `maxPerFloor` | 1 | 每层最多一间，允许为零 |
| `minArea` / `maxArea` | 70 / 100 | 室内面积 |
| `minEnemies` / `maxEnemies` | 3 / 4 | 敌人数范围 |
| `largeArea` | 84 | 优先尝试四人的面积阈值 |
| `doorBuffer` | 3 | 结构与功能点距入口缓冲 |
| `freeRatio` | 0.60 | 最低自由地板比例，同时受大型房公共下限约束 |
| `maxBlockedRatio` | 0.30 | 隔墙、床、长椅合计面积上限 |
| `maxCandidates` / `layoutAttempts` | 90 / 1600 | 布局候选及敌人站位尝试上限 |

实际候选还须符合大型房公共面积范围及本层可用额度。空间不足允许不生成，不能为了必出而减少通道、增加奖励或改门墙。新探险使用 V9；V1～V8 的历史配置保持原样，刷新旧探险不会额外生成诊疗所。

## 验证与预览

[生成及玩法检查](clinic-qa.json)：32 张地图中验证 9 间诊疗所，含 6 间有门、3 间无门，覆盖两个地图朝向及 3／4 人配置。共执行 458 步通行、9 次完整恢复、198 项隔墙视线检查；验证双方通路、配额不增加、操作位、开门、搜刮、治疗中断续用、用尽保存、V1～V9 存档兼容和配置回退。

[绘制检查](clinic-art-qa.json)：8 张地图、32 次昼夜／观察模式渲染，检查图片裁切范围、两种家具朝向、隔墙隐藏、统一墙面及绘制不改玩法数据。既有敌我视野、直接支援、回位恢复和开门 16 项检查通过。

实际浏览器验证自然生成样例 `clinic-033` 第 3 层第 8 房（86 格、木门）和 `clinic-027` 第 3 层第 2 房（70 格、铁门）。木门开启体力 100 → 92，进入后能发现局部守卫，后方隔间保持遮挡；转过隔墙后显露相应内容。急救推车在 4 tick 后将胸部损毁从 36 降到 16，剩余次数归零。390 像素窗口无水平溢出，控制台无错误或警告。

房间筛选增加“诊疗所”；既有“通路”按钮在选中诊疗所的总览模式下显示两条路线，试走时隐藏。房间信息只显示名称、面积、敌人数、门和可用操作，没有新增玩家说明段落。
