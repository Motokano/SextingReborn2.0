# 四十、战斗场景与可互动元素（设计正本 · 起步）

> **状态**：起步（仅"简单类可互动元素"范式 + 酒瓶实例；复杂类、场地陷阱、机关等后续补充）。
> **动机**：战斗场景不只是"空地"，而是"有东西可用的环境"——可互动元素是**操作流玩家的武器库**（呼应「注意力平衡」：配装差的玩家靠利用环境补足），也贴合末世街头世界观（酒瓶/木箱/油桶都是随手可得的武器）。

## 1. 简单类可互动元素（一次性动作范式）

**核心概念：可互动元素 = 环境给予的一次性战斗动作**——不是"临时武器"，不是"装备"，而是一个"踩上去就白得、用完就消失"的动作。

```
踩上元素格 → 自动获得「一次性动作」
   ↓ 不耗 tick，可立刻使用
命中/生效 → 效果（如眩晕）
   ↓
动作消失、元素格清空
```

- **不耗 tick**：元素是"顺路捡的福利"，不打断战斗节奏（移动→踩元素→白得动作→仍可正常出招）。
- **稀缺兜底**：因为"免费且不耗 tick"很强，平衡完全靠**稀缺**——固定关卡手写少量、位置刁钻；随机地牢低概率刷。**稀缺是它成立的前提**（泛滥则战斗变"踩元素大赛"）。

## 2. 首个实例：酒瓶

```
踩上酒瓶格 → 获得一次性动作「扔酒瓶」
   ↓ 不耗 tick，立刻甩出
命中敌人 → 眩晕 2 回合（独立强控，不接入眩晕累积系统）
   ↓
动作消失、酒瓶格清空
```

- **眩晕 2 回合**是独立于「眩晕累积系统」（累积 100 → 晕 1 回合）的一次性强控——酒瓶作为稀缺、位置固定/随机的一次性资源，强控是它的卖点。

## 3. 位置规则

- **固定关卡**：可互动元素在 `data/maps/*.json` 手写实体（固定位置，像采集点那样）。
- **随机地牢**：可互动元素在随机生成地牢的实体池里低概率刷。
- 两种场景共用同一套"实体 + 互动逻辑"，仅位置来源不同（与采集点实现同构）。

## 4. 可互动元素的分类（后续扩展）

| 类别 | 例子 | 状态 |
|------|------|------|
| 简单类（一次性动作） | 酒瓶（扔→晕2回合）、砖头（砸→伤害/破防）、木棍（挥→钝击+击退） | 酒瓶已定范式，其余待补 |
| 场地伤害（状态流转） | 玻璃渣（打碎后地面伤害区）、油渍→火区 | 后做（需实体状态机） |
| 掩体/阻挡 | 翻倒的桌子、货架 | 后做 |
| 机关/连锁 | 油桶（引爆）、煤气罐（爆炸） | 后做 |

## 5. 未来扩展（后话，预留）

- **生成流派的预留**：未来可设计"满足条件后身边刷一个可互动元素"的流派/被动（如某种技能/后遗症/改造件让玩家能生成酒瓶）——本质是"**让玩家能生成一次性动作的来源**"。「一次性动作」范式天然兼容这个扩展（生成元素 = 复用同一套实体 + 互动逻辑）。
