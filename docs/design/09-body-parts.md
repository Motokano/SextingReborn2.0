## 八、身体部位与状态效果

- **部位**：头、胸、腹、左手、右手、左脚、右脚；命中部位按权重随机（躯干高、头低、四肢中等）。
- **效果**：
  - **头**：命中头大幅累积**眩晕值**（0~100，≥100 触发眩晕 1 回合；-1/tick 衰减；抗眩晕为头防具专属，见 [37-equipment-modular-armor.md](37-equipment-modular-armor.md) §9.2）。
  - **胸**：只算伤害。
  - **腹**：一次性降低饱食度与饮水度。
  - **手 / 脚（旧层已废，以本文件「肢体损毁」模型为准）**：下面「手」「脚」两条来自**旧后果模型**（暂时失能且自行恢复、有几率骨折、须特殊手段解除），已由现行**「肢体损毁」**模型取代——部位只按损毁值累积，满值即损毁并失去功能（四肢含无法出招/移动等），无独立的「骨折」「暂时失能自行恢复」通道；**以下文字仅保留作历史对照，不再作为现行规则引用**：
  - **手**：命中/招架下降会自己恢复；有几率骨折，骨折与脚同，须特殊手段解除。
  - **脚**：暂时无法移动会自己恢复；有几率骨折 → 脚部技能失效、移动一格需两回合，须特殊手段解除。
- **肢体损毁**：每个部位有**损毁值**；损毁值满后该部位标记为**损毁**、失去功能（四肢还包括无法出招等，见技能篇）。损毁值**可回落**，两条通道见下「损毁恢复」；此外可通过**手术用品**暂时扣除部分损毁值上限以恢复功能（**待实现**），**手术**技能等级影响可恢复的损毁值上限比例。
- **损毁恢复（2026-09 定稿，已实现）**：损毁值只降不升以外还需有出口，否则一残到底没法玩。恢复分两通道，均写入 `CharacterAttributes.recoverPartDestroy`：
  - **自然自愈（基础通道，无成本）**：吃损毁后进入**宽限** `body_part_destroy_recover_grace_ticks`（40 tick）——期间该角色损毁值不回落（战斗中/刚挨打不给回血）；宽限结束后，每部位按
    \[
    \text{每 tick 恢复量} = \frac{1}{\texttt{body\_part\_destroy\_recover\_interval\_ticks}} \times \text{部位系数} \times (\text{休息时} \times \texttt{rest\_multiplier})
    \]
    累进（默认间隔 6 tick / 点，休息 ×3），小数进度进存档、满 1 点才落地。**部位系数**越大恢复越快：四肢 1.0 / 腹 0.7 / 胸 0.6 / 头 0.5（要害最慢）。损毁归零即停，不留残余进度。
  - **外敷活络药（消耗品通道，47 §9.6）**：`pharmacy_part_recovery` 效果按 `recovery_per_tick` **逐 tick** 降低**外敷目标部位**的损毁值，**不受宽限限制**（边打边治）；外敷目标部位随存档持久化，登记缺失时兜底落在「损毁/上限比最高」的部位。强效外敷药 90 tick 约 29 点、纯品约 36 点。
  - 两条通道**并行**且都受该部位损毁上限封顶（只降到 0，不会变成负值）；恢复**不回补疼痛条**（疼痛另有自己的衰减，见 k229）。
  - 数值来源 `data/survival-config.json`：`body_part_destroy_recover_grace_ticks` / `_interval_ticks` / `_rest_multiplier` / `_part_multiplier`；外敷药数值来源 `data/pharmacy-buff-matrix.json` 的 `mobility` 族（生成进 `data/buffs.json`）。
  - **仍未实现**：复活后损毁值恢复至上限 50%（03，等死亡/复活链）；手术用品临时降上限恢复功能（本节旧条款，等 `survival_surgery` 系统）。
- **已损毁部位再受击时的损毁重分配**：
  - 命中某一部位且照常走完减伤链后，得到该次**最终伤害**，并按既有规则向下取整得到本次**损毁增加值** \(Q\)（与 5.6.3 一致，与用于扣血的数值同源）。
  - 若**命中部位当前尚未损毁**：\(Q\) **全部**加在该部位损毁值上（仍受该部位损毁上限封顶，超出部分作废）。
  - 若**命中部位已经损毁**：**不得**再把 \(Q\) 加在该部位；将 **\(Q\) 整体**分摊到当前**尚未损毁**的全部部位上（七部位里损毁值未满、未标记损毁者）。**分摊方式**：设未损毁部位数为 \(n\)；每部位先加 \(\lfloor Q/n \rfloor\)，余数 \(R = Q \bmod n\) 按固定顺序 **头 → 胸 → 腹 → 左手 → 右手 → 左脚 → 右脚** 只计入「未损毁」部位，从顺序上最靠前者开始，依次多 **+1** 共 \(R\) 次，保证各部位本次增量之和恰为 \(Q\)。每部位加完后照常判定是否顶满损毁。
  - **扣血**：仍按本次**最终伤害**与命中部位常规结算（不因目标部位已损毁而改为 0 伤害），除非别处另有规则。
  - **全无未损毁部位**：若 \(n = 0\)（七部位均已损毁），则本次 **\(Q\) 作废**，不累加到任何部位。
  - 敌人与玩家共用本规则（七部位与损毁逻辑一致，见敌人篇）。
- **各部位损毁值上限**：

  | 部位 | 损毁值上限 | 说明 |
  |------|-----------|------|
  | **头** | 50 | 头部耐受度最低，少量损毁积累即可导致功能丧失。 |
  | **胸** | 100 | 标准上限，有肌肉与肋骨支撑，较能承受累积伤害。 |
  | **腹** | 80 | 软组织与空腔器官集中，耐受度低于胸部。 |
  | **左手/右手** | 100 | 标准上限；骨折等会更早触发，但损毁积累速度较快。 |
  | **左脚/右脚** | 100 | 标准上限；骨折与行动失能早于损毁满值触发。 |

- **上限表注（旧层已废）**：上表「左手/右手：骨折等会更早触发」「左脚/右脚：骨折与行动失能早于损毁满值触发」两句沿自上面已标注**已废**的旧后果模型（骨折/暂时失能自行恢复）——现行以本文件「肢体损毁」模型为准：损毁值满即该部位损毁失能，不存在更早的独立「骨折」触发阈值；两格说明保留作历史对照。
