# 分区轮牧数值第一版

最终校准：当前 schema 5 参数和验证结果以 [畜牧最终校准](31-livestock-final-calibration.md) 为准。本文保留历史阶段记录。

日期：2026-09-13。已接入运行代码，物种配置 schema 4。本阶段目标是用生态与饲料成本引导分区，验证启动、成年群体的重复运行和失衡恢复；不是整个畜牧系统或最终经济平衡的验收。

## 本次调整

负载系数为 `max(0.25, sqrt(体重 / 参考体重))`，计算体重不超过物种育肥上限。参考体重：牛 150 kg、羊 20 kg、猪 30 kg、鸡 2.5 kg。幼崽负载至少为参考负载的 25%，满重牛羊猪为 2 倍，满重鸡为 1 倍。

维护营养、最大饲料吞吐、采草吞吐、踩踏、污染、猪松土与翻草、鸡清污均乘负载系数。营养守恒、草高门槛及物品营养成本保持原结算口径。饱腹储备容量没有随体重扩大，避免长大时凭空增加已储营养；相同饱腹百分比下，重动物能坚持的时间更短。HP 为原来的 100 点，饥饿扣血仍按实际维护缺口比例计算。

牛在 150–300 kg、羊在 20–40 kg 之间，由幼体增重速度线性过渡至原有最大育肥速度，避免跨过体重门槛时口粮需求突然跳升。原 `graze_cap_kg` 在此作为速度过渡起点，不再把一次增重截在门槛上。成长与生产仍各自支付营养。

| 生态量 | 参考负载下每 tick | 满重时每 tick |
| --- | ---: | ---: |
| 牛踩踏 | +0.045 板结 | +0.09 |
| 羊踩踏 | +0.005 板结 | +0.01 |
| 羊污染 | +0.008 污染百分点 | +0.016 |
| 猪松土 | −0.045 板结 | −0.09 |
| 猪翻草 | 最多消耗 0.001 米草高 | 最多 0.002 米 |
| 鸡清污 | 最多清除 0.007 污染百分点 | 同左 |

猪常规清污改为 0。翻草按实际草量扣除，幼猪不再一 tick 抹掉整区草地。羊污染由旧参考值 0.02 调为 0.008，使合理规模的鸡笼能够承接成年羊群：两只满重羊排污 0.032/tick，五只满重鸡最多清除 0.035/tick。这个余量有限，鸡笼放错位置、增加羊群或鸡未长大都可能产生缺口。

自然长草仍为每 tick `0.0008 × (1 − 0.009 × 板结)`，草高上限 1.5 米。空区不自动松土。板结为 0 时，休养 1000 tick 能从 0 长到 0.8 米；板结为 100 时只能长到 0.08 米。羊高于 0.8 米完全不能采食，最低吃到 0.1 米；牛最低吃到 0.4 米。猪翻土后无须重新播种。

界面详情新增草高阻碍说明与长大后负载提醒，不提前开放被技能限制的精确营养账目。完整牧场预测、污染趋势与交接预警仍属于后续 UI 迭代。

## 对照方式

默认组合为 2 牛、2 羊、2 猪、5 鸡。分区初始布局：牛在 z1，羊在 z4，猪在 z3，z2 空置；arm3 鸡笼覆盖羊与猪所在的相邻区域。所有动物与臂每 1000 tick 同步旋转，固定区域依次经历牛、羊、猪、休养。这里是一个验证通过的组合，不是唯一允许的配比。

分区与混养使用相同动物数量和体重、同样的八个侧面饲料槽和一个五鸡笼。混养将牛羊猪集中于 z4，鸡笼仍能覆盖该区。没有诊疗、自动松土或机械清污装置。为了比较同等产量的成本，饲料槽持续由外部补满，实际扣料逐 tick 累计；没有把外部补料当成游戏内已完成的作物供应链。两组立即领取已形成的奶蛋毛，不抽血，采集操作时间不计。

启动组沿用四区统一 1.5 米草高，没有预设梯度或额外割草。玩家准备的是动物分群、位置和补料：第一阶段羊确实不能吃高草，由饲料度过交接；后续才进入循环。另设人工预处理草高的对照，不将该合成初态当成已经验证的割草操作流程。

## 最终运行结果

每组 12000 tick，13 组共 156000 tick；共核对 1461404 份个体账目，营养最大误差 1.39×10⁻¹⁶。所有实际槽扣料都与动物摄入核对。

| 情景 | 饲料单位 | 结果 |
| --- | ---: | --- |
| 分区启动组 | 6347.69 | 全部存活、最终 HP 100，无手动松土/清污；54 奶、4 毛、205 蛋 |
| 相同群体集中混养 | 8368.45 | 相同产量、全部存活；分区省料 24.15% |
| 少一头牛 | 3375.92 | 能稳定运行，但羊因高草无法采食的累计时长更长 |
| 少一只羊 | 4668.63 | 能稳定运行，羊毛产量相应减少 |
| 羊增加到四只，仍只有五鸡 | 8437.45 | 清污能力不足，8 只地面动物最终病死，不能用总耗料低估这种失败的成本 |
| 不养猪、不松土 | 6909.28 | 动物可由持续补料维持；后期每阶段实际采草仅 0.32 米，草地收益显著退化 |
| 不养猪、持续手动松土 | 2255.23 | 同一无猪群体全部健康，手动松土 226 次 |
| 不养鸡、不清污 | 4820.84 | 六只地面动物最终病死 |
| 不养鸡、手动清污 | 6347.69 | 地面动物全部健康，手动清污 32 次 |

成年分区组最后四个阶段每阶段饲料消耗均约 547.74，采草均约 1.06036 米，显示阶段收支已重复。混养最后四阶段每阶段耗料约 700.71，仍能在新进入的高草区域短暂采草，不能将混养描述为完全不能吃草。

无猪手动组的维护策略为板结高于 40 时每 tick 最多松土一次；无鸡手动组为污染高于 20 时清污。每次状态动作减 10 点，对应 UI 支出 10 体力。因此上述两种情况分别需 2260 与 320 体力；这不是换算后的真实游玩分钟数，其他游戏时间和体力恢复机制未模拟。

## 成长与恢复

同样的分区组合从出生体重开始，12000 tick 后全部健康：牛约 200.16 kg，羊约 70.33 kg，猪 120 kg，鸡 2.5 kg。随着体重和育肥速度提升，需求持续上升；此时牛羊尚未全部满重，不能拿该组代替成年稳态验收。幼体羊在前序牛还小的时候会遇到更长的高草禁食阶段，需要补料。

恢复组从所有区域草量 0、板结 100、污染 80 开始。仅在前 1000 tick 内进行人工处理，合计松土 44 次、清污 26 次，之后停止所有人工生态维护。最终全部动物健康，后四阶段的耗料与采草恢复为成年分区组的重复值。相同坏初态不干预时，六只地面动物最终病死。因此修复路径存在，不能据此宣称失衡无需代价。

## 明确保留的边界

- 不养猪仍可以用大量饲料替代草地收益，代码没有强制玩家点击松土。若要继续利用草地，就需要承担明显的维护劳动；“猪默认参与轮牧”不等于“没有猪动物必死”。
- 现有机械松土/清污模块的替代成本尚未重调，本实验明确排除它们。与动物分工的关系需在基础装置设计中处理。
- 成年组运行窗口为 12000 tick，即三次完整四阶段循环。没有覆盖鸡在 15000 tick 寿命后的补群，也没有繁殖、售卖、屠宰、遗传随机性或饲料作物成本。固定随机值用于隔离布局影响，不是全概率压力测试。
- 存在充足档未利用摄入，且本轮体重负载改变了满重维护成本。直接产品营养成本不等于完整饲料成本；此前营养文档的满重算例是历史值，不能继续当作现价。
