# 自配注射液的配方身份

状态：用户已确认，待部署时核对并接入续药与来源计时。

## 同一种药的判断

完整配方中成分ID及份数完全相同，视为同一种注射液。包括主药、辅助粉、溶媒和助剂；任一成分或剂量改变即为不同配方。投料顺序和自定义名称不影响身份。

构造身份时按物品ID归并重复行、累加份数，再以稳定顺序排序。两行同一原料各1份与一行2份身份一致。使用稳定ID，不使用显示名称；不将不同精制等级的物品ID合并，也不按剂量比例约分。

## 与药效规则衔接

- 相同配方重复成功使用：刷新原来源持续窗口，沿用已定起效衔接，不叠加剩余时长。
- 不同配方：保留各自来源和计时；同类具体效果取最高，不因不同配方而叠加增强。
- 多效果注射液按各效果自己的时序运行，不能用一个最长窗口覆盖全部效果。
- 每次成功注射照常结算消耗、依赖和毒性，不因身份相同、效果较弱或被压过而免除。

例如单方镇痛针和镇痛加醒神复方针为不同来源；镇痛取最高，醒神独立生效，两次注射均承担各自代价。

## 与堆叠和版本分离

配方身份相同不代表实例必然可合并。背包还需检查腐败进度及其他需要保留的实例状态，不能因合并刷新期限。

规则版本记录计算结果来源，不将版本号或自定义名称当作玩家可制造不同药效来源的途径。未来升级版本后的重算或保留策略遵循迭代流程，当前不要求旧存档迁移。

参见[续药](47-pharmacy-redosing.md)、[效果混用](47-pharmacy-effect-stacking.md)、[保存](47-pharmacy-preservation.md)及[后续迭代](47-pharmacy-iteration-workflow.md)。部署需验证换顺序、重复行、改名身份一致，改变剂量或溶媒身份不同，以及不同来源同类效果不相加。
