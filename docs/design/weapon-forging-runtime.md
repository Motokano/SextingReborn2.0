# 铸造运行接入

2026-10-17，按用户授权沿用制药台的设施入口，接入正式背包、认知、体力、时间、技能和存档。2026-10-18续接单手模块武器的实际战斗、部件与矿材效果；获取投放继续暂缓。

## 地图与操作入口

- 基地 `M0_Base_Inside_lv_1` 的（5,11）为铸造台，位于缝纫台左侧；南侧（5,12）可接近。棋子采用用户认可的 `reference/forging-station-v1/forging.png`，复用设施透明素材及贴地阴影体系。
- 未修复时从设施菜单进入修复；首轮沿用制药台的10石材、8木材方案，通过共用设施缴料系统处理。修复后，相邻才能打开铸造台。
- 面板分材料、图纸、装配、维修四页。携带工具卷时，玩家行动菜单另有“维修武器”，战斗外可用，不要求站在铸造台旁。
- 不增加独立燃料、水量或工具耐久；不向新档背包、矿点、商店自动发放新材料或工具。获取途径仍待配置。

## 已接入流程

1. **材料**：只列实际持有或基地仓库里已有的材料。辨认身份与检查加工用途分开；检查不耗样本、时间、体力或经验。原矿按既定路线一件加工成一份坯料，不留边角料。
2. **图纸**：研究消耗一个真实部件样本，完成才解锁该结构；不自动认识原配方。投料按加工料整数份、容量和四项30%下限验证，开炉前同时检查材料及整次工作所需体力。
3. **打造**：开炉扣料并锁定随机种子，先结算固定12个世界tick，再进入格子小游戏。83件盘面直接复用最新试玩规则、目标和视觉效果；盘面操作不追加世界tick。收工按完成度生成一个正式部件实例，不能重复领取。
4. **装配**：在台旁按部件成本安装或卸下，沿用真实子物品连接存储。跨位置部件只保存一个实例、一份重量和一个耐久池；安装前校验覆盖位置，无旋转，拒绝重叠。未装全的组合可保存，不能视为完整武器。更换位置的招式先回到兜底招式。普通背包连接按钮不能绕过铸造台工序。
5. **维修**：工具卷使用共用装配系统；只需对应的一款工具。维修能力从1级50%线性增长到100级100%，当前耐久达到能力上限就不允许开工。一次成功修到上限，结算时间、体力与经验；中断不恢复部分耐久、不发经验，已付出的时间与体力不退。

材料可合并消耗身上与基地仓库的库存。样本研究、部件装卸与维修目前从随身实物选择，仓库部件先取出。维修包含已安装在组合里的真实部件。

## 成品与认知

112条正式物品模板通过游戏初始化加载，数据源仍是 `data/forging/` 和既有设计表；生成器输出 `js/forging-config.js`，不维护第二套数值。

每件成品保存配料、完成度、最终位置威力、重量、筋骨要求、耐久及扣量、单条矿材特性和归零状态。实际负重读取成品重量。负面最大耐久特性在制成时只结算一次；其余矿材特性由战斗执行器按实际出招或承担格挡的部件读取，不泄露未知材料身份。

身份、加工路线、部件结构、实例配方和效果认识独立存储。语言等级或铸造等级不会自动鉴定。10级开放已知路线材性；25级且结构、实例配方和材料路线均已知，才显示该件性能；效果认识仍等待实战观察入口。未知材料不补问号目录，不列出全目录数量，不输出内部ID。

铸造经验写入现有 `life_forging` 技能记录。加工、研究、收工和成功维修给经验；装卸不给经验，也不会凭零经验凭空获得技能等级。锤数按技能为8／9／10，可收取效果格为2／3／4；轻锤3次、十字锤1次不变。使用既定技能体力折扣及环境修正，整次保留一位体力精度，再按进度扣除，避免每tick重复取整放大费用。

## 存档和中断

- 工序、配方、进度、已扣体力、盘面、随机状态与特性抽取值保存进正式存档；读档不重抽同一炉。
- 打造和研究可暂停后继续。加工当前一份若中断则退回已保留原矿；维修及装卸中断后须重新开始，不自动恢复动作。
- 维修读取统一战斗状态事件，战斗一触发立即停止；最后一个工作tick触发战斗也不结算维修。保存失败不能把已中断维修变回可继续状态。
- 物品、仓库与认知的领取／扣除操作保存失败会回滚。已经推进的世界时间和体力不会因最终保存失败而免费恢复。读档时关闭旧面板，再恢复对应存档中的工作。
- 进行维修或装卸的部件、宿主及工具卷会锁定，普通取物、拆装或卸装不能搬走正在使用的实例。

## 单手武器战斗

- 完整装配后可从背包或地面选择左手／右手持用；缺位置、另一手已持武器、筋骨不足半门槛或正在维修时拒绝装备，不挤掉原装备。其他武器原型没有在此版擅自开放。
- 四位置默认前端→侧一→侧二→手柄，战斗配置面板可以调整顺序和各位置1～12成出力，战斗中每次有效修改消耗一次行动。每位置根据攻击属性使用直刺、顶击、劈砍、横击、啄刺、柄击或尾刺；它们是部件自带招式，不获得招式熟练度、不进可学习技能列表、不装变式。换武器重置默认招式与轮换。
- 持械手损毁自动退回可用四肢的徒手循环，恢复后回到武器；主动指定的徒手模式不被错误拉回。两个循环分别记进度，攻击与格挡分别轮换。格挡优先按侧一→侧二循环，解锁格挡的手柄进入候选；条件接口可以改选，之后从实际选中位置继续。
- 威力读取成品当前位置的最终威力，整把武器按最大筋骨门槛统一降效。速度汇总真实部件一次，与普通百分比速度修正相加，最终下限1；距离基础1，普通距离增幅取最高。气力、底气由当前呼吸法按动作标签供给。
- 接入83件的钝击侧、手柄、跨位联动与归零效果，以及矿材命中、伤害、格挡、卸力、速度和耐久特性。一次性强化按实际攻击消耗，未打出的招式不产生效果；震荡只作用下一tick，同一tick取最高降低值。部件默认招式附加效果沿用资源失败禁用规则。
- 普通接触、被格挡和成功格挡按各部件成品扣量记账，未命中不扣，耐久保留0.01精度。跨位部件只有一份池，归零只抽一次损坏状态，维修恢复后清除；有护手的手柄归零失去格挡资格及新增增益。
- 速度连击重复本次位置的招式，每次独立处理资源、效果与接触，整串只推进一次位置。先手打坏持械手会取消尚未执行的武器攻击，并从保留的徒手进度选择可用肢体还击；本次交换的先后手与连击次数不回算。同速双方按共同快照结算，再合并耐久损耗和归零，避免一方先结算改变另一方本tick效果。
- 实例保存武器循环、模式、归零结果与待生效强化。卸下／换武器和脱战清理临时强化；装卸某部件清理该来源强化。2026-10-18已接入metaskill触发、排队、替换／追加、来源追踪及存档，详见[元技能运行接入](combat-metaskill-runtime.md)。

核心执行器为 `js/modular-weapon-combat.js`，接入既有 `CombatMeleeResolve`、`CombatPipeline`、`CombatParry`、`CombatInitiative` 与正式场景攻击入口，不维护另一套伤害公式。

## 验证与范围

自动检查覆盖正式主页面初始化、地图与NPC入口、锁定设施、真实面板点击、身上与仓库混合扣料、世界tick、小游戏零额外tick、特殊格收取、正式存档往返、唯一物品所有权、跨位覆盖、费用、技能经验和战斗中断。另回归通用连接、仓库、制药台、缝纫台与设施棋子。

战斗专项检查为 `tools/test-modular-weapon-combat.mjs` 与 `tools/test-modular-weapon-scene.mjs`：在正式页面模块中覆盖左右手装备、独立循环、实际场景速度连击、同速快照、先手损毁取消、83件归零参数、强化与资源失败、震荡跨tick、地面装备、正式存档往返及战斗面板操作。

`tools/forging-runtime-review.html` 仅用于独立界面验收，加载同一套正式模块，测试物品和存档都在该页内存中。正式主游戏不导入此页的测试初始化。

尚未完成：正式可学习武器招式与具体metaskill条目、双持／双手／长柄原型、效果观察认知、新物品获取投放。元技能框架已接入，但正式变式表仍为空，不添加未经确认的触发条件。旧武器仍保留兼容数据，后续单独迁移；不能把这一版单手武器接入写成全部持械设计已完成。
