## 入口和配置

当前在「前往金木镇的路」和「金木镇」放置单格检查站，通过邻格看守互动进入「村外废墟」。村庄场景尚未独立设计，入口地图通过 `data/dungeon-config.json` 的 `entryMaps` 调整。第一层免费；较深起始层只显示玩家实际持有的已配置门票。线索只显示任务服务确认拥有的条目，不能凭空选择任务。主题暂不开放，保险为未启用入口，特别楼层保留后续独立设计。

主配置包含资源房比例、领悟点概率及奖励、随机空房和无门房概率、开门体力、技能与工具减耗、搜索空率、数量分布、五档搜索时间、恢复效果、探索倍率和入池批次。门票可覆盖内容配置、物品数量加成与动作耗费系数。本次的房间配置、数量加成和费用系数在入场时确定，继续深入沿用；具体物品的搜索耗时在该条开始搜索时锁定。门票完整属性通过 `attributes` 展示，线索仅在指定层调用内容提供者，不会在第一层提前生成。保险和主题尚未开放，入口不显示无效的保险选项。

## 搜刮与回收

尸体基础空率 20%；非空抽取 1～4 次，权重 30%／45%／20%／5%。容器基础空率 40%；非空抽取 1～3 次，权重 60%／30%／10%。数量加成 B 提供 `floor(B)` 次完整额外判定，加上小数部分概率的一次判定。每轮独立判空，因此基础空尸体或空容器也可能在额外判定得到物品。

掉落池使用有限库存，不放回抽取；通过唯一批次 ID 追加库存，同一存档不因重载重复补货。生活产物不纳入此池。2026-10-26 用户要求补齐手套和鞋子的特殊材料获取渠道，正式配置新增 `sewing-accessory-supplies-v1` 原料/回收配件批次：编织草料60、橡胶片料120、鞋钉40、金属鞋包头24；详见[缝纫第17节](sewing-material-defense-draft.md#17-手套与鞋子接入2026-10-26)。其余入池内容仍待设计，不加入原型演示掉落或生活制作成品；采收产物有完整真实物品映射。

容器首次点击「搜索」自动花 1 tick 开盖，非空时停下，点击「开始搜索」才逐条翻找。空容器开盖即确认，不额外判空。查看和关闭已开容器免费。尸体在死亡时确定内容；非空直接按物品搜索，空尸体搜索 1 tick 后才揭晓为空。尸体打开窗口、关闭窗口、切换同格尸体、标记，各收 1 tick；容器与尸体成功领取一条完整堆叠均收 1 tick，满包失败不扣 tick、不拿走部分堆叠。

白／青绿／紫／金／红分别为 1／2／3／5／8 tick，颜色统一为 `#DDE6D7`、`#72D8B5`、`#BE99FF`、`#FFCC73`、`#FF5158`。搜索条显示整条物品进度，揭晓后短停 420ms 再搜下一条。领取暂停搜索，550ms 的领取过程未结束就关闭或移动则取消；暂停、关闭、切换及后台标签页都不会追赶世界时间。保存保留完整 tick 和 tick 内进度，正在搜索的条目不因配置变化重新定价。领取与重看不重播奖励，后续 tick 更新也不截断上一条仍在播放的光效。携行物品保留静态淡光晕。

尸体不阻挡移动，站在同格时列出每具尸体的搜刮和标记操作。只打开窗口不影响标记；消耗第一个搜索 tick 后不能再标记，搜索或领取过程中也不能标记。标记时锁定整袋内容和 NPC 分配，换层、撤离或死亡时交接到本趟回收批次；不能在地牢里直接领取回收袋。

每袋 NPC 抽走 `max(1,floor(物品件数×30%))` 件，空袋为零，从实际件数中等概率不放回抽取。开袋、读档、配置变更都不重抽。开袋进度可暂停及保存；玩家所得与 NPC 抽成并排展示，窄窗口仍为两栏。全部开袋逐袋播放，等待本袋启用的视听反馈结束再继续；全部领取只覆盖所选批次已经开封的袋子。入口回收不消耗地牢 tick，按正式携行容量逐件入包，余货和已领回执保留。未开封袋不能通过领取接口提前取物。

## 战斗和探索结算

敌我使用同样的视野、方向和遮挡。房间敌人待机，路上敌人游荡；看到玩家后追击。仅向自己可见的友军直接取视野，不能接力传播。丢失超过 3 tick 尝试返回生成点附近，回位期间每 tick 恢复 8 点实际部位损毁，适用正式战斗的晕眩和腿部限制。死亡使用正式战斗击杀回调生成尸体，不再同时发放旧的即时演示战利品。

小地图复用原型 C／45° 投影，提供拖动、缩放、已探索范围和跟随；箭头随朝向旋转，北向固定。区分当前视野、历史地形、打开／拿空的容器和耗尽资源，只显示当前识别的敌人。地牢内 Shift 加方向键免费转向。打开操作窗口或背包时隐藏小地图，关闭后恢复。跨层归档地图记忆和统计；普通楼层不能回退。缺失或损坏的可选探索记忆仅重建当前实际视野，不丢弃世界物品，也不补全地图。

第 n 层每个有效探开格基础潜能为 n；开门每次 +10%、击杀 +5%、首次有效使用兴趣点 +5%，同一对象去重；各层汇总后统一四舍五入。容器首次开盖即计兴趣点倍率，空容器也计；尸体搜索不另计兴趣点倍率。抵达通行口自动弹出选择，关闭后留在原格，再次走入才再次自动弹窗。可以继续深入或撤离，最深层只显示撤离，当前普通层上限为 4。

撤离自动交图，依次呈现交图中、结算中和已到账，潜能只发一次。门票扣除、换层、行动结果、入包与领取记录、地图奖励与结算凭据写进同一份游戏存档；保存失败恢复操作前的完整状态，防止扣票、丢物品和重复发奖。死亡取消尚未结算的地图报酬并遵循原有携行物损失流程；属性中已经获得的潜能保留，已标记尸体可回收。保险补偿尚未接入。

采收提供单次和连续操作，成功时显示实际产物与扣费前后值，始终不显示资源余量。未满级采收减耗曲线、工具叠加方式、伴生概率及采矿／伐木成长参数仍属未定内容，不借本次审查补定。特别楼层、保险、主题、正式门票词条和正式入池名单继续留待独立设计。

### 2026-10-26 固定兴趣点的未辨认显示

采收点、可搜索容器、恢复点、潜能点和撤离点共用三态显示：当前地形不可见时隐藏；地形可见但未辨认时显示居中的“？”；辨认后显示当前状态的棋子。转向时三态立即按当前视野重新计算，不因已探索记录而提前显示类型或使用状态。

身后三邻格的可见地形对这些固定兴趣点保留“？”占位。这是固定兴趣点的显示例外，覆盖此前整类剥离动态符号的做法；敌人、NPC、尸体及其他动态目标仍使用原规则。问号不说明容器种类、采收次数或是否用完，不增加玩家界面说明文字。

墙体、关闭的门和视野距离继续阻止兴趣点显露；转身不允许透视，也不修改敌我感知、支援、可走规则或小地图记忆。使用前后状态均遵守相同显示规则。

回归检查：`tools/dungeon/test-poi-visibility.mjs` 覆盖五类固定兴趣点、八向转身、前后视野切换、昼夜、墙和关闭的门遮挡、远距离隐藏，以及使用后的未知状态。
