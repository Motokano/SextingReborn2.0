# 四眼之城：可行走格图草案

日期：2026-09-14。讨论用布局，未接入游戏。世界背景见 [城市运作底稿](city-guangzhou-working-notes.md)。

看板参考：k276「四眼之城：街区格图与城市关系设计参考」，Todo；用于后续设计，不代表批准直接实施。

现有 town.json 为16×16；本稿用可配置的12×12小图表达街道与建筑占地，每个字符是一格，建筑规模为示意。实际制作可增大地图、拉长巷道并改变建筑形状。

符号：# 地图边界或墙；. 可走地面；~ 水面不可走；数字为建筑或设施占地（不可走）；+ 为可站立的门前交互格；小写字母为街区出口。NPC 暂未摆放，后续不得占住唯一通路和出口。

连接：a=A南口↔B北口；b=A西口↔C东口；c=A东口↔D西口；d=B西口↔C南口。n=A北口预留至田庄与村路；e=C北口预留至废城区；f=D北口预留至墓地。三个外接区域尚未绘制，当前不是已接通出口。

室外出口表现为街口、道路尽头等自然衔接。跨街区使用明确目标地图及落点；落点在目标出口内侧可走格，不落在传送触发格上。建筑入口先预留服务或室内地图入口，不必每间屋都建独立内景。四眼终局所在赌城顶楼可从A区赌场继续衔接，暂不改写主线布置。
