# 基础口服解毒药

状态：清毒丸用途、配方与削弱后的数值已确认；保存期暂拟，运行时尚未实现。下方最新定稿覆盖早期“待核对”项目。

## 已确认用途

- 配药辅粉仅在配置时降低本配方毒性，不清除角色体内已有毒性。
- 基础口服解毒药在药效期间加快体内毒性代谢，不直接清空毒性，不降低成瘾。
- 解毒期间继续服药或注射，本次新增毒性仍按既定规则完整加入；解毒不赋予毒性免疫或额外的入体减免。
- 重复服用只刷新持续时间，不叠加代谢速度；起效衔接沿用续药规则。
- 先仅保留一种基础口服解毒药，优先复用已有合适成品或原料，不机械新增多档，不额外开放解毒注射路线。

## 数值与物品待核对

实际代谢速度、起效等待、持续时间需结合现有自然代谢和中毒危险倒计时核算。应能帮助处理毒性积累并有救急价值，但不保证任何毒性水平都能救回，不让连续用药失去代价。

优先核对现有解毒消费者及药品目录，再决定复用或新增；确认实际承担效果的物品后，补齐配方、成本、堆叠、保存与分级信息。未确定前不把抵消辅粉直接标记为可口服解毒。

本条只确认解毒不降低成瘾；解毒药自身的毒性和依赖参数需在具体原料选择后明确，不能凭药名自动推断。配置中的减毒与服用后的解毒使用独立规则，不直接复用负毒性数值作为代谢速率。

参见[续药规则](47-pharmacy-redosing.md)、[效果混用](47-pharmacy-effect-stacking.md)和[配置边界](47-pharmacy-compounding-failure.md)。
