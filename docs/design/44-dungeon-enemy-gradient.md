# 44 · 地牢敌人完成度梯度（16 层 × 4 档）

> 配合 [10-enemies.md](10-enemies.md)（敌人模型）、[42-dungeon-material-allocation.md](42-dungeon-material-allocation.md)（七座主题地牢 16 层材料档）、[03-death-and-insurance.md](03-death-and-insurance.md)（投保）、[04-combat-exp.md](04-combat-exp.md)（实战经验）、[30-story-outline-blackout.md](30-story-outline-blackout.md)（六劫）。
>
> 本文定义「敌人完成度」：同一敌人从地牢第 1 层到第 16 层逐步完整化的框架、档位划分、教学顺序、数值标定规则，以及与上述系统的挂钩。

---

## 一、设计目标与核心原则

1. **敌人 = 成长标尺**：敌人不是「难度单位」，是测量玩家成长的尺子。成长感 = **可比较性 + 反超时刻**——玩家在第 N 层面对同一个敌人的完整版时，能对照第 1 层的记忆，感知自己的实力已经反超。
2. **完成度落在可见维度，而非数值**：数值梯度玩家看不见；完成度通过 10 的敌人模型各轴（动作集 / 气力 / 机制层 / 部位 / 行为）逐层补齐表达。每层只动一个「看得见」的变化。
3. **设计顺序 = 先完整、后剥离**：每个敌人先写成**完整版模板（full kit）**，各档通过「剥离清单」生成残缺版——与「先设计完整体、再逐步拿掉」一致，避免逐层凑数值导致后半程崩坏。
4. **每档改变威胁画像**：完成度不单调递增数值；每档改变「威胁画像」（笨重但疼 → 快 → 硬+盾 → 聪明+完整），维持新鲜感与教学节奏（详见 §5）。
5. **与 01 哲学对齐**：浅层残缺版 = 深层完整版的**世界内预告片**（知道就是奖励）；死亡只惩罚可再生资源，成长标尺永久可比；战斗非强制，梯度服务于「想打的人」。

---

## 二、完成度模型（Completeness Model）

### 2.1 完成度阶段

- `completion_stage`：**1～4 四档**，与 42 的层数档位一一对应（1-4 层 / 5-8 层 / 9-12 层 / 13-16 层）。
- 每座地牢的敌人设计时给定**完整版模板**（stage 4 = full kit），stage 1/2/3 为剥离版。

### 2.2 完成度六轴

| 轴 | 说明（对应 10 字段） | stage 1（残缺） | stage 4（完整） |
|---|---|---|---|
| 动作集 | 攻击动作列表（含装备肢体、威力范围、气耗、部位权重） | 1～2 个基础动作 | 3～4 个动作跨多肢体，含专属技 |
| 资源 | 气力条 `qi_li_max` / `qi_li_regen_per_turn` | 0，无特殊技 | 有气力条，专属技扣气、有耗尽惩罚 |
| 机制层 | `parry_rate` / `parry_damage_reduce` / `has_shield` / `inner_damage_reduce` | 全 0 | 逐层补齐（补齐顺序见 §5） |
| 部位 | `body_part_destroy_max`、部位抗性（头/胸伤害分流） | 脆皮，可爆头速杀 | 部位抗性高，逼玩家换部位策略 |
| 行为 | AI 追击/攻击节奏、数量（`aggro_radius` 等 + 生成数量） | 独行、慢 | 成对/成队、提速、脱战回血 |
| 环境（可选） | 房间地形配合（掩体/毒池/机关，见 40） | 平地 | 地形联动，构成「场地考试」 |

### 2.3 配置结构（建议）

```text
EnemyFullKit {
  id, name_key, ...            // 10-enemies 全部字段（stage 4 完整值）
  completion: {
    stages: [                  // 每档覆盖字段；缺省 = 继承上一档
      { stage: 1, actions: [...], body_part_destroy_max: {...}, ... },
      { stage: 2, ... },
      { stage: 3, ... },
      { stage: 4 }             // 空覆盖 = 完整版
    ],
    exp_value: { 1..4 },       // 各档实战经验值（见 §6.2 经验阶梯）
  }
}
```

- **实现**：地牢生成器按层数档位选 `completion.stages[N]` 实例化；未配置 `completion` 的敌人（如野外敌人）不受影响。
- **运行时**：`combat-enemies.js` 读实例化后的动作/气力/部位上限；与 10 现有实现状态对齐（`pickEnemyAction` / 气力追踪 / 「损毁即血」均按实例化结果工作，`body_part_destroy_max` 已有脆皮化支持）。

## 三、16 层 × 4 档框架（对齐 42）

| 档 | 层数 | 材料档（42） | 完成度阶段 | 威胁画像 | 教学目标 |
|---|---|---|---|---|---|
| 一 | 1～4 | 主题基础款 | stage 1 | 笨重但疼 | 认识敌人、读前摇、学会尊重 |
| 二 | 5～8 | 进阶 | stage 2 | 快 | 速度 / 先手 / 连击的应对 |
| 三 | 9～12 | 稀有 | stage 3 | 硬 + 有盾 | 破防、资源管理、部位打击 |
| 四 | 13～16 | 独有 | stage 4 | 聪明 + 完整 | 读招、知识制胜 |

- **亮相层**：每档第 1 层——该档完成度第一次出现，给玩家「看清它」的机会（数量少、地形友好、可先观察后绕）。
- **考核层**：每档第 4 层——该档完成度的「考试」，通关给该档独有材料（与 42 档位收益绑定）。
- **里程碑撤离点**：每档底部（4 / 8 / 12 层末）设撤离点——16 层单程 + 全掉落死亡（03）需留「阶段性收获退出」出口；深入下一档是**可选**的冒险决策（符合 02「生存并撤离」）。

## 四、旗舰敌人与轮换 roster

- **旗舰敌人**：每座地牢 **1 个**，全程 16 层逐步完成（本设计核心），是该地牢的身份象征。其「完整形态」应长成该地牢主题的样子：D3 瘸子的炉卫完整版 = 板甲 + 火伤；D5 卷毛的信徒完整版 = 成群出现；D2 哑巴的守田卫完整版 = 毒伤 + 减益。**完成度即世界观**：敌人越完整，越接近该阀核心力量。
- **轮换敌人**：每座地牢另配 **3～5 个**，错峰出现、错峰完成，保证每层有新面孔，旗舰敌人始终是那把「尺子」。
- **roster 表模板**：

```text
DungeonRoster {
  dungeonId, flagshipEnemyId,   // 旗舰：completion 全程 4 档
  rotating: [ { enemyId, floors: [1,8], completionStages: [1,2] }, ... ]
}
```

## 五、教学顺序与威胁画像（每档剥 / 补什么）

### 档一（1-4 层）：笨重但疼 —— 教「它是谁」

- 剥离：只剩基础动作；招架 / 护体 / 内功减伤全 0；脆皮（`body_part_destroy_max` 低）；独行、仇恨短。
- 补一个惩罚：单发伤害偏高，让玩家学会「不能站着对撸」。
- 教学：认识敌人、读它的前摇、什么时候该绕开（战斗非强制在本档被第一次体验）。

### 档二（5-8 层）：快 —— 教「节奏」

- 补：速度数值 +1 档；第二个动作（装另一肢体）；气力条与第一个扣气专属技。
- 教学：速度 / 先手 / 连击的应对——玩家开始需要步法与节奏，而不是硬吃。

### 档三（9-12 层）：硬 + 有盾 —— 教「破防与部位」

- 补：护体（`has_shield` / `shield_damage_reduce`）、内功减伤、招架率与卸力；AI 提速；成对出现。
- 教学：破盾、资源管理、部位打击——**毁手断它的新技、断腿控它的移动**（10 的「损毁即血」肢体联动正反馈在此档成为主要打法）。

### 档四（13-16 层）：聪明 + 完整 —— 教「读招」

- 补：全部剩余机制 + **招牌后遗症**（如 `initiative_always_first` 强制先手、tick 末击退、驱散，见 `post-effects.json`）+ 部位抗性（头/胸伤害分流）。
- 教学：用知识而不是数值赢——玩家需用自己的招式维度（部位策略、成数、呼吸法、招架时机）打「完整考试」。

## 六、成长标尺机制

### 6.1 经验阶梯（与 04 联动）

- 每档敌人配置 `exp_value`（随完成度递增）；04 规定「实战经验远高于某敌人时，再打该弱敌不再获得实战经验」。
- 效果：浅层残缺版后期自动「不给你经验」——一句无声的「你成长了，这里对你没有意义了」；梯度本身成为**经验阶梯**，逼玩家下潜。
- 标定：`exp_value` 与「击败该档敌人所需玩家进度」匹配，防止浅层刷经验。

### 6.2 标定规则（防呆）

1. **按玩家进度标定，不按层数线性拉**：第 N 层敌人 = 针对「正常进度能到达第 N 层的玩家」校准，胜率目标约 **60～70%（略舒适）**，而非 50/50 或「勉强打赢」——让反超时刻存在。玩家成长是周/月级且死亡扣技能等级（03），梯度应「跟在玩家后面一点」，不在前面堵玩家。
2. **每层只动一个可见变化**；每档第 1 层是质变点（亮相），档内其余层是微调（补数值 / 补第二个同类变化）。
3. **完成度 ≠ 单调递增数值**：每档换威胁画像（§5），否则 16 层后段会麻木。

## 七、与世界观钩子

1. **情报（知道就是奖励）**：瞎子（D1 之外的信息源，见 30）卖「第 N 层敌人情报」——花钱/以物易物得知该层敌人多了什么。敌人完整 kit 也是「信息」，必须满足 01 的承诺「每个关键信息至少一条世界内线索链」：**深层新招永远被预告过，玩家不会死在完全没见过的东西上**（公平性红线）。
2. **六劫（30）**：六个零件分别藏在六座主题地牢深层——回火管→D3 主锻炉核心、冷沉罐→D2 毒王池底、陈浆罐→D5 渡口祖缸、聚光筒→D4 矿坑隧道、扼流圈→D7 地听站、蒸馏釜→D6 赌城顶楼。**零件房间 = 该地牢旗舰敌人完整版（stage 4）守门**，六劫 = 「必须通过完整版考验」的叙事锚点。
3. **完成度即世界观**：深层的「完整标本」作为各阀核心设施的看门人；你越深，越接近权力核心——完成度同时承担叙事。

## 八、验收用例

1. **旗舰敌人 16 层展开示例**（以现有 `enemy.street_thug` 为原型）：

| 档 | 动作集 | 气力 | 机制层 | 部位（body_part_destroy_max） | 行为 |
|---|---|---|---|---|---|
| 1 | 挥拳 / 推搡 | 0 | 全无 | 头20 / 胸28 / 腹24 / 四肢36（现值） | 独行，仇恨 5 |
| 2 | +踹膝（带跛足 debuff 版） | 10 | 无 | 头30 / 胸40 / 腹32 / 四肢50 | 速度 +1 |
| 3 | +锁喉（扣气专属技） | 20 | 招架率 0.1、卸力 0.2 | 头40 / 胸60 / 腹48 / 四肢70 | 成对出现 |
| 4 | 全招 + 招牌「街头霸王」（强制先手后遗症） | 30 | +护体 30% + 内功减伤 0.15 | 头50 / 胸80 / 腹64 / 四肢90 | 成队 2-3、脱战回血 |

2. **可辨识性验收**：同一敌人的 stage 1 与 stage 4 保留可识别的共同视觉锚点（剪影 / 肢体特征 / 出场方式），玩家凭记忆即可认出是同一个敌人——这是「同一个敌人跨 16 层」设计成立的前提（反超对照仅依赖玩家记忆，不再有额外载体）。
3. **经验阶梯验收**：stage 1 敌人对中期玩家经验收益 ≈ 0；stage 4 经验价值与该档独有材料档位匹配。
4. **公平性验收**：玩家在 1-12 层（或经情报）见过完整版的每一招；13-16 层无「凭空出现」的新招。
