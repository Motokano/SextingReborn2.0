# 狩猎与畜牧产出链 v1

> 定位：完整产出链设计草案。首版已实现兔肉与牛羊猪鸡的取肉／活捉种源分支，以及兔骨、牛羊猪鸡血皮骨、猪脂和牛角的捕获后处理。兔皮、后续物种与新增配方仍是建议。毒囊暂缓，不为它新增独立事件；下表毒物路线仅作后续候选。详见 [首版记录](hunting-implementation-v1.md)。
> 数据基线：当前 `data/items.json`、`data/livestock-species.json`；关联 [狩猎规则](hunting-system.md)、[野兔事件](hunting-event-rabbit.md)、[畜牧已确认规则](31-livestock-confirmed-decisions.md)。

## 1. 分工与边界

| 链路 | 特色 | 共用部分 |
|------|------|----------|
| 狩猎 | 野味、野生特有部位、野外种源与个体特性 | 相同动物口径下的血、皮、骨、脂肪和部分肉 |
| 畜牧 | 奶、蛋、羊毛、可持续产出、标准分割肉和丰富内脏、种群繁殖选育 | 与狩猎复用相同物品，不为获取方式重复造物品 |
| 加工 | 将两路原料制成料理、皮革、纺织品、工具或药材 | 成品属于相应加工技能，不属于直接狩猎或活体采收 |

- “特色产物”表示本版的生产分工；不等于必须通过某玩法才能通关。特色菜、装备和强化提供可选路线，基础通关方案无需全部收集。
- 狩猎的新种源有明确作用；畜牧不会产出全部野味，首版只养现有牛、羊、猪、鸡，不自动扩展为全动物养殖。
- 牛、羊、猪可繁殖；鸡沿用现有“全为母鸡、无自然繁殖、靠幼鸡补群”规则，不被上一轮泛称的“建立后都能繁殖”覆盖。
- 保留旧设计中的商人幼崽渠道为可配置辅助来源，不因本轮确认狩猎供种自动删除；狩猎不是全局强制玩法。

## 2. 完整循环

制造捕网／套索／石砾投枪，准备诱饵 → 活动前进食与补水 → 狩猎点开启活动 → 事件准备与捕捉 → 下列互斥结果之一：

1. **猎获食材目标**：取肉／保留整禽等主产物，选择额外处理获得皮、血、骨或特殊部位 → 带出 → 烹饪、制造、纺织、制药。
2. **活捉种源目标**：带回幼崽个体 → 放入适配牧区或鸡笼 → 成长 → 奶蛋毛／抽血／屠宰／繁殖（鸡除外）。
3. **失败或退出**：已消耗体力和捕具不退回；按活动规则结束并进入点位冷却。

同一动物不能既作为活幼崽入牧场，又领取其肉、血、皮。事件若存在多只动物，应分别记录目标，不无条件发全套奖励。

狩猎活动内禁食，休息使用已有生存规则。主产物与额外处理的成本分别预览；下述处理环节为本稿建议，结束与冷却应在处理完成或明确放弃后结算。

### 14种已有狩猎材料覆盖核对

兔肉、野猪肉、鹿肉、鹿舌、驼鹿蹄、山羊、整只火鸡、火鸡肉、乳鸽、兽肉块、兽骨、兽角、猛禽羽毛、毒囊均有对应目标。

- 田螺与水产归钓鱼，不再列入狩猎。
- 兽肉块作为无独立肉品的猎物主肉，或明确加工转换的目标，不与同一份兔肉／鹿肉等重复发放。
- 整只火鸡与分切火鸡肉、整只山羊肉料与羊肉均互斥；已有整件物品的固定质量必须参与换算，不能一只猎物同时发整件和全套分切。
- 狩猎现场仅做有限处理；本稿建议把丰富内脏与多种标准肉块留给牧场屠宰，形成投入和产物差异，不意味着野生动物没有这些部位。

## 4. 幼崽进入畜牧

| 捕获目标 | 入牧场物种 | 养成特色产物 | 后续种群来源 |
|----------|------------|--------------|--------------|
| 牛类幼崽 | `cattle` | 水牛奶、牛肉及多种内脏 | 合格成年公母繁殖；狩猎补入个体 |
| 羊类幼崽 | `sheep` | 羊毛、羊排羊腿及内脏 | 合格成年公母繁殖；狩猎补入个体 |
| 猪类幼崽 | `pig` | 猪排猪肉、丰富内脏、脂肪 | 合格成年公母繁殖；狩猎补入个体 |
| 幼鸡 | `chicken` | 鸡蛋、鸡腿鸡胸及内脏 | 持续捕获幼鸡或商人辅助供给；无繁殖 |

幼崽是动物个体，保存物种、年龄、体重、性别（鸡按现行规则）、健康及 Perk；不以普通肉料编号代替。捕获后固定结果，不因反复查看或入牧场重抽特性。

幼崽捕获可作为专门分支，选择捕幼崽会放弃同一目标的屠宰收益。野外新个体可补充种源和特性，但不保证优于繁殖个体；不能把“野生”做成隐性品质等级。

出生参数、携带形式、运输占用、入场容量与暂存处理待实现设计；牧场满员时不得静默删除幼崽。保留原牧场资格、营养、成长和繁殖门槛。

## 5. 血、皮、骨、脂肪的共用口径

### 血：先复用四种，不新增通用兽血

野牛→牛血 `hus_beef_blood`；野羊→羊血 `hus_mutton_blood`；野猪→猪血 `hus_pork_blood`；野鸡→鸡血 `hus_chicken_blood`。

狩猎通过猎获后放血获得；畜牧牛羊猪已有活体抽血与屠宰，鸡仅屠宰。新狩猎来源接入时再更新来源标记，暂保留 `hus_` 编号，避免复制同物。鹿血、兔血无独立配方需求时不新增。

建议放血需要容器并消耗处理体力，产生固定规格血液物品；容器是否计入成品包装、额外消耗及成本另定。烹饪血制品可作为后续配方；不得声称现有制药配方已经使用这些血。

### 皮：普通皮共用，野生毛皮形成特色

- 已有牛皮 `hus_beef_hide`、羊皮 `hus_mutton_hide`、猪皮 `hus_pork_rind`、鸡皮 `hus_chicken_skin`。此前“没有皮”的结论仅针对通用兽皮，不应误解为畜牧没有皮类产物。
- 同口径猎物复用上述皮；猪皮、鸡皮优先为食用皮，牛羊皮用于皮革，不统一混成一种兽皮。
- **拟新增兔皮**：带毛材料，方向为保暖衬料；不与通用“小兽皮”重复建项。
- **拟新增鹿皮**：柔软皮料，方向为轻便皮具；不宣称它在全部用途上优于牛羊皮。
- 精制皮革 `leather_fine` 当前来源为地牢；牛羊皮鞣制路线为拟补充配方，不在本次静默改变来源。

### 骨、角、脂肪

- 牛羊猪鸡优先复用已有物种骨；其他合适猎物用兽骨 `hunt_bone_common`。物种骨与兽骨不可为同一份组织重复结算。
- 牛角与泛称兽角分别用于对应目标，提供配方替代的具体规则后再接入，不按名字自动互换。
- 野猪肥膘复用猪板油 `hus_pig_lard`；提炼猪油、腌熏萨洛和熏腊肉属于加工环节。
- 现有牧场直接产猪油 `hus_pork_lard` 是数据现状，与理想“脂肪→炼油”层级不完全一致；本稿记录此差异，后续统一加工链时另改，不能偷偷取消已有产出。

这些是设计链路，不据物品标签假定配方已实现。原料的“可用于”描述不构成可执行配方。

## 7. 本版范围与实施清单

1. 保留14种狩猎材料，补逐猎物分配与互斥产出规则；共享血皮骨脂肪沿用现有物品ID。
2. 仅提出兔皮、鹿皮两种新原料；具体加工配方明确后再入表。捕网、套索和诱饵另列消耗品配置，石砾投枪已是消耗品。
3. 接入四种幼崽捕获及牧场入场，沿用动物数据结构，不新增鹿、兔、火鸡、鸽、猛禽、毒物养殖。
4. 狩猎特色不等于每个目标同时出肉、血、皮、骨、角、幼崽全套。按事件选择、体力预算与可用质量确定产出，不给活捉奖励后再发同一动物材料。
5. 奶、蛋、羊毛本版由畜牧生产，不在狩猎事件安排挤奶、捡蛋、剪毛来替代。
6. 鸭、鸽、鹌鹑的畜牧物品，以及部分精细分割和加工品，虽然已存在物品条目，但不在当前四物种产出配置内；不宣称已可养殖。纳入后续扩展，不用狩猎临时补齐来掩盖缺口。
7. 数量、重量、体力、成功率、刷新冷却、携带与运输、处理资格、道具配方、共享来源标签均待后续配置与验证。
