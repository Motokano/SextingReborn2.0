# 60 · 人形棋子画风与精细度标准

2026-09-15：用户明确评价一档地痞比此前林经理精细，完全符合预期，要求以后设计其他棋子沿用这一质量标准。本文是新增、重绘人形棋子的优先标准；与旧文档冲突时以本文为准。

## 1. 必须使用的视觉基准

- 第一参考：[一档地痞原始定稿](../../reference/street-thugs-v1/tier-1.png)。用于画风、比例、造型完整度与细节层次。
- 游戏素材参考：[一档透明站姿](../../assets/map/isometric/street-thug-v1/standing.png)。用于透明边缘、底座与实际显示比例。
- 同系列变化参考：[二档](../../reference/street-thugs-v1/tier-2.png)、[三档](../../reference/street-thugs-v1/tier-3.png)、[四档](../../reference/street-thugs-v1/tier-4.png)。用于研究服装、年龄、神态和站姿如何区分人物。

每次生成前必须实际查看第一参考，并作为图像参考传入生成工具。不能只靠“手绘、精细、卡通”等文字复述，不能只参考上一个新生成角色导致风格逐次漂移。原图的棋盘格属于背景，不是画风的一部分。

林经理、旧v4锥形棋身和骨架校准示意人均不作为后续新图的精细度或结构模板。已有角色保持现状，用户要求重绘时再按本标准升级；本次标准制定不授权自动替换旧角色。

## 2. 固定的画风与结构

- 沿用地痞定稿的卡通头身比例、完整四肢、简化但有体积的手脚、略俯视三分之四角度。不要回退成无手脚的锥形棋身，也不要改成写实人体或另一套大头玩偶比例。
- 深色外轮廓清楚，内部线条有轻重。脸、手、衣服和鞋均有明确形状，缩小后轮廓仍然干净。
- 有手绘色块与体积明暗：额头、脸颊、肩臂和衣物有受光面与暗面；避免只有一块平涂色，也避免光滑塑料、金属模型般的高光。
- 保留宽薄深灰椭圆实体底座。双脚与底座真实接触，不悬浮，不更换成岩石场景或装饰台座。
- 统一左上来光。运行时地面投影单独绘制，沿用合并底座占地和人物轮廓的贴合方案。

## 3. “精细”必须体现在哪里

| 部位 | 应有的表达 | 应避免的退化 |
|---|---|---|
| 头发 | 大发块形成轮廓，少量发束和方向明暗 | 一整块头盔形黑色、杂乱细发丝 |
| 面部 | 简洁眉眼与可辨神态，肤色有体积 | 默认所有人无五官、靠堆皱纹表现年龄 |
| 衣服 | 领口、袖口、下摆厚度，以及随身体受力的少量褶皱 | 贴在身体上的平面色块、全身均匀噪点 |
| 手臂与手 | 卡通体积，清楚的手势、手腕和袖口衔接 | 过度写实肌肉、糊成球的手、错指或多指 |
| 裤鞋 | 膝部和裤脚褶皱、鞋面与鞋底分层 | 两根无结构裤管、脚与底座融成一块 |
| 配饰 | 一至三个有身份意义的重点，材质能区分 | 为显精细堆满首饰、缝线、纹身和武器 |

标准是形状、材质和明暗的完成度，不是细节数量。地痞的灰背心、绷带、肤色和挑衅表情是角色身份，不是所有人物必须复制的元素。

## 4. 新角色输入与表演

用户提供身份或气质即可开始设计；尽量落实为发型、脸部特征、肤色、服饰、配饰五项。缺少的信息可以依据身份提出或补全，不强制用户填表。

在固定风格内，通过眉眼、下巴、肩膀、重心及手的位置表达个性。老练感优先通过稳定、节制的动作与观察人的神情表达；不要仅靠长胡子、变老、加疤或增大体格。职业、性别、年龄与性格可以变化，不能把所有人物做成地痞换衣服。

## 5. 出图与验收流程

1. 阅读本标准并查看地痞原始定稿；明确当前角色的身份和重点识别特征。
2. 使用内置 imagegen，带入已认可地痞作为画风与比例参考。每个新角色始终保留这一参考；其他图片注明只参考服饰或身份，不取代画风基准。
3. 先做完整单人站立概念，画面包括完整底座；检查比例、手脚、神态、衣物体积和轮廓是否达到参考完成度。仅出概念时不要擅自接入游戏。
4. 用户认可的图保存为版本化原图，不覆盖定稿。游戏用透明版本单独保存，并记录来源与提取提示；生成式去背景可能有重绘差异，不宣称无损。
5. 接入前检查真实alpha，排除画上去的棋盘格和残留背景。测量可见轮廓及底座接地点，不用图片矩形下边缘替代脚底。
6. 在144px格宽检查。普通站姿参考底座46px、可见高度约70–74px；保持原画比例，不能分别拉伸宽高。大图与实际游戏尺寸都应清楚，不能只看大图宣布通过。
7. 阴影从底座边缘连续向右下伸出；本体和投影共同服从可见性。确认实际运行目录，并验证本次绑定及相关回归。

敌人默认范围仍是站立、死亡倒地两种；普通NPC只站立，主角保留现有128状态。分阶段任务仅完成用户当前要求的状态，并如实记录剩余状态；禁止恢复骨骼拆装。肢体损毁不能直接当作死亡。

## 6. 可复用生成提示骨架

以下为画风约束，需补上当前角色说明；最终提示与输出来源随素材归档。

> 以附带的一档地痞定稿作为画风、头身比例、线条和细节完成度的直接参考，设计同一游戏的新人物棋子。保持其手绘卡通质感、清晰深色外轮廓、完整四肢、简化而有体积的手脚、略俯视三分之四角度与宽薄深灰椭圆底座。角色身份与外观：[填写]。神态与站姿：[填写]。头发有成组发块，眉眼简洁可辨，皮肤有受光与暗面；衣服有领口袖口厚度和自然褶皱；裤脚、鞋面与鞋底分层。细节有重点，缩小到游戏尺寸仍能辨认。左上光源，完整人物及底座入画，脚踩实底座，无文字、无多余角色或场景。参考中的灰背心、绷带和地痞神情不应套给新角色。游戏素材要求真实透明背景，不画棋盘格，不烘焙独立地面投影。不要退化成平涂占位图、锥形棋身或光滑塑料模型，不以堆碎纹理替代造型。

生成模型有随机性，提示词不能保证每次一次达标；必须对照参考检查，有偏差就针对性修改后再交付。
