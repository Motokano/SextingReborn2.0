# 三十九、手套与出招装备改造体系（设计正本）

> **状态**：手套核心已定稿；改造件强化（通货做装）、特殊装备为**后续扩展**（本文只定骨架与预留接口）。
> **前置**：模块化防具见 [37](37-equipment-modular-armor.md)，数据契约见 [38](38-equipment-data-contract.md)。

## 1. 定位

- **手套 = 徒手流的"武器"**：纯进攻/技能向，**不做防护**（手被击中照样损毁/骨折，防护是防具的事）。
- 对称结构：
  - **兵器流 → 武器**（`weapon_attack_power`）；
  - **徒手流 → 手套**（影响徒手技能）。
- 手套左右手各一槽（`glove_left` / `glove_right`），独立装备；徒手攻击**只看当前出招手**的手套。

## 2. 核心机制：两层标签 + 分形态系数

### 2.1 两层标签

| 层级 | 标签 | 作用 | 现状 |
|------|------|------|------|
| **功能标签**（`limb_tags`） | `挥拳` / `踢击` | 肢体"能不能出这类招"；手套带"挥拳"→ 手部肢体能用拳类招式 | 现有 `required_limb_tags` 机制 |
| **形态标签**（`form`） | `拳` / `掌` / `戳`（手）；`踢`（腿） | 招式"这一击是什么"，决定伤害形态 | **新增** |

- 功能标签管**能否释放**，形态标签管**加成哪个**，两层各管各的。
- 形态 → 伤害类型映射：**拳 / 掌 = 钝击、戳 = 戳刺**（形态是徒手内部子分类，最终落到伤害类型结算）。

### 2.2 分形态系数表（`form_coefs`）

手套不再是单一 `skill_coef`，而是按形态给系数：

```jsonc
{
  "form_coefs": { "拳": 1.3, "掌": 1.0, "戳": 0.8, "踢": 1.0 }
}
```

- **裸手默认**（没手套）：拳 / 掌 / 戳三种形态天然可用，系数**全部 = 1.0**（自然基准）。
- **戴手套**：各形态系数「跟着手套属性走」——`form_coefs` 覆盖裸手的 1.0；手套**未声明的形态回退 1.0**（保持裸手基准）。
- 手套不是"解锁形态"，而是"改写形态系数"：`form_coefs` 管**加成多少**（可弱化，通常不禁用），`move_tags`（改造件）管**能否使用**（移除标签 = 禁用该形态）。
- 徒手伤害公式中，手套系数从"单一 T"变为"按出手招式的 `form` 查 `form_coefs`"：
  - `D_徒手 = B_fist(筋骨) × form_coefs[招式.form] × F_技能 × F_呼吸法 × F_出力 × 环境 × 实战`
- 例：拳击手套 `拳 1.3 / 戳 0.8`——打摆拳（拳）吃 1.3，打刺拳（戳）吃 0.8，手套 = 流派选择器。

## 3. 打造流程（三阶段）

```
① 选手套大类（工装手套 / 露指手套 / 机车皮手套 …）
     → 决定基础属性 + 功能标签（limb_tags）+ 形态系数表（form_coefs）
② 锻造「手套框架」（材料决定底子，走 life_forging / life_weaving 等工艺）
③ 装「改造件」（进攻向强化，见 §4）
```

- 手套大类由**材料 + 工艺**决定底子（钢→指虎、兽皮→皮手套、硅叶→特殊处理），维度跟着材料走。

## 4. 改造件系统（骨架，后续细化）

- **出招装备（武器 / 手套 / 鞋）共用**的进攻向改造，与防具模块化对称、方向相反：
  - 防具模块 = 防御向（减伤 / 抗晕 / 盾）；
  - 改造件 = 进攻向（伤害类型改写 / 动作标签 / 特殊效果 / 命中速度）。
- **转换单向约束（强制）**：改造件若含伤害/形态转换词条，必须先声明 `from → to`（转换什么），且**任意顺向可跨级、严禁反向**：
  - **伤害类型**（顺序 钝击 → 劈砍 → 戳刺，`08`）：钝→劈、劈→戳、钝→戳（跨级）允许；劈→钝、戳→劈、戳→钝 禁止。
  - **形态**（顺序 拳 → 掌 → 戳）：拳→掌、掌→戳、拳→戳 允许；掌→拳、戳→掌、戳→拳 禁止。
  - 目的：防止来回转换形成循环、导致伤害无限膨胀。
- **两个转换维度的区别与结算顺序（强制）**：
  - **形态转换（`form_convert`）**：改**形态** → 连带改①手套系数（吃 `form_coefs[新形态]`）②伤害类型（形态映射：拳/掌=钝击、戳=戳刺）。本质是"换打法"。
  - **伤害类型转换（`damage_type_convert`）**：**只改伤害类型**（钝/劈/戳），形态与系数**不变**。本质是"换伤害结算"。
  - **结算顺序**：先形态转换（定形态 + 系数 + 基础伤害类型）→ 再伤害类型转换（在该伤害类型上做单向转换）。
  - 例：拳击手套（拳 1.3/戳 0.8）打"刺拳"（form=拳）——形态转换 拳→戳 → 系数吃 0.8、伤害变戳刺；仅伤害转换 钝→戳 → 伤害变戳刺但系数仍吃 1.3。
- 结构复用防具模块那套（**槽位 + 声明式效果 + 数量限制**），落在 `life_enchant` 改造技能。
- **改造件强化（后续）**：流放之路式"通货上词缀"——改造件有前缀/后缀词缀，用通货（硅叶等）上词缀/重骰/洗数值；符合"稀缺 + 不确定 + 归零"基调。
- **特殊装备（后续）**：自带特别效果的"名器"，无改造槽位、不可做装，类似流放"传说橙装"；效果不限（规则级皆可），获取 = 大部分掉落 + 小部分特殊配方。

## 5. 数据契约（摘要，详细见 38）

- **手套模板**：`limb_tags[]`（功能标签）+ `form_coefs{}`（形态系数表，键=拳/掌/戳/踢）+ 可选 `damage_type`/`move_tags`/`special_effect`（改造件能力）。
- **招式**：新增 `form`（拳/掌/戳/踢），映射伤害类型（戳→戳刺）。
- **改造件**：独立物品，结构对齐模块（`install_slots` / `occupies` / `max_per_armor` 等），方向为进攻向 effect。
- **开放接口**：复用 37 §10 的 modifier / 声明式效果 / 来源标记——改造件强化、特殊装备都走"加配置 / 加 handler"，不拆核心。

## 6. 鞋子与步法（`shoe` 接 `footwork`）

### 6.1 定位

- **鞋子 = 脚部出招武器 + 步法载体**（区别于手套的纯进攻）。
- **对称**：手套 = 手部（拳/掌/戳，纯进攻）；鞋子 = 腿部（踢）+ 步法（走位，进攻 + 身法）。

### 6.2 脚部形态（对称手部拳/掌/戳）

| 形态 | 动作 | 招式 |
|------|------|------|
| **踹** | 直线踹击（脚掌/脚跟） | 正蹬（现有） |
| **扫** | 横向摆扫（脚背/小腿） | 鞭腿（现有） |
| **踏** | 向下蹬踏（脚底） | 蹬踏（未来） |

- `form_coefs = {踹 / 扫 / 踏}`，裸脚默认 1.0（自然基准）。

### 6.3 鞋子大类（功能分类，六条赛道无王者）

| 品类 | 功能赛道 | 移动体力消耗 | 步法侧重 | 踹/扫/踏 | 特殊 |
|------|----------|--------------|----------|----------|------|
| **草鞋** | 极致轻便 | **−30%** | 弱 | 0.9 / 0.9 / 0.9 | — |
| **布鞋** | 轻便耐用 | **−15%** | 弱 | 1.0 / 1.0 / 1.0 | — |
| **运动鞋** | 跑动 / 减震 | **−15%** | **闪避**（速度） | 1.0 / 1.1 / 1.0 | — |
| **钉鞋** | 抓地 / 转向 | 0% | **闪避**（转向） | 1.0 / 1.0 / 1.1 | **踢击命中触发流血** |
| **雨靴** | 防水 | 0% | 中性 | 1.0 / 1.0 / 1.0 | 泥泞 / 雨天移动不减 |
| **重靴** | 重稳 / 防护 | **+20%** | **招架**（招架率/卸力） | 1.2 / 1.0 / 1.1 | — |

- 六条功能赛道、各有场景价值、无全面王者；玩家按"怎么打 / 怎么走"选鞋。
- **移动体力消耗**是鞋子的功能维度之一（对"每格 1 体力"的修正，`05` 5.5.4）：轻鞋减少移动体力消耗（跑图省力），重靴增加（重而费体力）。
- **钉鞋默认带流血**：踢击命中触发"流血"异常状态（机制规划中，见 `15-todo`「中毒、流血、灼烧」；与 `活力`降出血概率、止血布止血同体系）。

### 6.4 步法维度

- 鞋子放大步法的**固定效果**（见 `11-skills` 8.3.4）：
  - **身法动作**：影响动作强度 / CD（重靴动作强但 CD 长，轻鞋动作弱但 CD 短）；
  - **招架侧 / 闪避侧**：加成步法的招架率 / 卸力 / 速度；
  - **移动体力消耗**：`move_cost_mod`（负值 = 减少移动体力消耗，正值 = 增加）。

### 6.5 数据字段

- `form_coefs`（脚部形态系数）、`footwork_coef`（步法加成）、`move_cost_mod`（移动体力消耗修正，负值 = 减少）、可选 `special_effect`（如钉鞋流血）。大类自带，改造件可调整。

### 6.6 左右分装（取低）

- 手套 / 鞋子为**左右独立装备**（`glove_left`/`glove_right`、`shoe_left`/`shoe_right` 各自独立物品，可左右混搭）。
- **`form_coefs` 左右独立**：左脚踢读左脚鞋、右脚踢读右脚鞋（各管各的出招）。
- **全身共享维度取低**：`move_cost_mod`（移动体力）、`footwork_coef`（步法）左右混搭时**取更差的那只**决定全身——"一只重靴拖累全身移动"，自然鼓励左右成对。
