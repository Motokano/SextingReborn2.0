# 制药效果混用与叠加规则

状态：用户已确认本轮设计；尚未按本文统一改写运行时。镇痛与续力已有取最高值基础，不代表其余效果已经接入。

## 已确认规则

- 同类具体效果取已起效来源中的最高有效值，不相加，不因口服、吸入、注射等途径不同而允许叠加。
- 不同效果可并存。例如镇痛、负重上限和抗眩晕分别生效，复方仍有组合价值。
- 多效果药按具体状态分别选值，不整瓶覆盖。精力恢复、心情恢复等分别比较，因此可由不同药品提供最高效果。
- 外敷按目标部位分别判断。同一部位的同类恢复取最高值，不同部位可同时治疗。
- 不同药品来源独立保留起止时间。强来源结束后，尚有效的弱来源继续发挥效果；被压过的来源不暂停倒计时、不补偿未生效时间。
- 每次成功用药仍完整结算本次消耗、依赖和毒性，不因效果未超过当前值而豁免。

## 与续药规则衔接

同一种药再次成功使用按续药文档刷新原窗口，不累计剩余时长；不同药品来源各自计时。新来源尚未起效时不参与最高值选择。口服准备后注射强化，注射结束时可回到仍有效的口服效果。

参见[重复用药与持续时间刷新](47-pharmacy-redosing.md)。不能仅以共享同一个buff模板判断是否为同一种药；实际来源身份须在实现时明确记录。

## 具体效果比较口径

| 效果 | 分组与比较 |
|---|---|
| 镇痛 | 已起效的忽略疼痛比例取最高 |
| 续力 | 负重上限增加量取最高 |
| 醒神 | 抗眩晕增量取最高 |
| 生存状态恢复 | 按各具体状态分别取最高有效恢复速率，不把多个来源的同项恢复相加 |
| 战斗收益倍率 | 同一收益字段取最高有利倍率，不连乘 |
| 药物提供的属性增益 | 同一属性的同类增益取最高 |
| 外敷恢复 | 目标部位与具体效果共同分组，组内取最高 |

“最高”指效果最强，而非不分方向地对带符号数字取数学最大值。例如降低疲劳时，较大的疲劳减少量才是更强效果。相反方向的惩罚不能因本规则被当作弱增益删除；本文不重设独立副作用规则。

恢复预算归一化、免疫等既定修正后再比较有效速率。若使用分数累计器，选择规则必须在实际发放前生效，不能让暂时被压过的来源积累一笔恢复后在强药结束时补发。延长恢复持续时间仍遵守既定总预算约束。

## 范围与部署验证

本规则针对制药来源，不把食物、装备、技能等非制药增益擅自纳入统一最高值过滤。依赖、毒性和相冲代价继续按各自已定规则结算。

部署至少验证：同类跨途径不相加、不同效果并存、多状态恢复分别选值、不同部位独立、起效等待、强药到期回退、弱来源计时不中止、同药续服刷新且逐次结算成本。当前无正式存档，不新增旧存档迁移工程。
