# 51. 棋子形象与落地表现规范

> 后续明确修订：独立手脚、卡通七部位与损毁共用姿势以[52号规范](52-pawn-body-modules-and-poses.md)为准。下文v4固定结构与无独立手脚属于既有静态版本基准，不限制本轮用户授权的模块化改造。

状态：用户确认，2026-09-14。后续新增或重做的玩家、NPC、敌人人形棋子统一遵循本规范。

## 1. 已确认基准

以玩家通勤装 **v4** 为外形及游戏内比例基准：[透明素材](../../assets/map/isometric/player-office-pawn-v4.png)。v3、大头版、金色几何占位版和早期原型不再作为新棋子的美术基准。

![已确认的通勤装棋子 v4](../../assets/map/isometric/player-office-pawn-v4.png)

这是“给抽象棋子穿衣服、加配饰”的体系。保留小头、修长锥形棋身、宽而薄的椭圆底座，不画完整写实人体，不添加独立手脚或大头Q版比例。身份通过衣服、发型、帽子和少量配饰表达，不靠增加细节密度。

## 2. 比例与视角

沿用 C / 45° 菱形棋盘，角色直立，固定三分之四视角；不要把人物整体随地面压扁。

| 项目 | 当前已确认基准 | 后续制作原则 |
|---|---|---|
| 地块屏幕横向宽度 | 144px | 比例标尺，其他缩放按格宽同步调整 |
| 棋子实际可见高度 | 72px | 约为格宽的 1/2，按有内容的轮廓计算 |
| 底座实际可见宽度 | 约39px | 约为格宽的27%，保持宽薄，脚下仍有空地 |
| 棋身顶部 / 底座下缘 | 格中心上64px / 下8px | 以底座接地位置校准，不以图片框底边猜测 |
| 头部与躯干 | 以v4为准，小头、长锥身 | 避免头部重新放大；不将生成提示词中的理想百分比当作已验收硬数值 |

头部可以像参考棋盘一样稍微伸进后方格子的画面。“绝不越过菱形上顶点”的早期约束已被本版替代；仍应避免明显侵占邻格、遮住邻近棋子和交互信息。此前54px显小、96px显大，不作为默认尺寸。不要只改变图片框尺寸而忽略图内透明留白。

## 3. 衣着与识别

### 新NPC的固定框架与可变字段（用户补充确认）

以后设计新的NPC，只需提供以下五项：**发型、脸部特征、肤色、服饰、配饰**。未指定的项沿用简洁默认表达，不自行添加改变角色设定的细节。

固定使用已确认的v4结构框架：小头与修长锥形棋身的比例、宽薄椭圆底座、固定视角、相对格子的显示比例及落地投影方式。不能因为NPC身份、服装或脸部描述而改成另一种人体结构、大头比例、独立四肢或不同底座体系。发型和配饰可以产生必要的局部轮廓差异，但不得破坏共同骨架或明显扩大占格尺寸。

脸部特征允许按描述作简洁表达，例如眉眼、胡须、疤痕等；这些是面部表面的特征，不是重新设计头型与头身比例。此前“无五官浅色脸”是主角v4的默认表现，不再作为所有NPC的强制要求；NPC肤色按描述设置。

交付时使用“v4固定棋子框架 + 五项外观描述”作为输入，整体风格和结构不需要每次重新定义。只有用户明确要求改变共同框架时，才修订本规范。

描述模板：`NPC名称：…；发型：…；脸部特征：…；肤色：…；服饰：…；配饰：…。沿用v4固定棋子框架。`

### 角色衣着与风格

- 玩家是21世纪上班族。当前基准为短黑发、无五官浅色脸、浅灰针织衫、浅蓝衬衫领与下摆、深色下装；不是默认穿军装或背野外行囊的幸存者。
- 其他角色按各自身份改变服装颜色、帽子、发型和少量必要配饰，保留同一棋子轮廓语言。不要把主角的通勤装强制套给全部角色。
- 使用低饱和色、清晰深色轮廓、轻手绘质感。缩小到游戏实际尺寸时，先能辨认轮廓和主要服装色块，再考虑细节。
- 新素材只表达外观；不因此默认新增装备随穿戴换装、性别变体或游戏规则。

## 4. 阴影与落地

- 棋子与阴影分开绘制。透明素材不得烘焙地块、背景或地面投影。
- 底座下仅保留窄薄、低透明度的接触暗部，不能用大黑圆、光环或与底座分离的椭圆冒充投影。
- 地面投影使用棋子自身的透明轮廓，包含头部与身体形状；以底座为支点，按地面透视压扁并斜向延伸，根部较实、远端较淡，边缘适度柔化。
- 当前用户认可的是固定左上来光、向屏幕右下方投射的短影。保持统一方向；移动或转向不应让影子脱离底座。尚未实现随时间或局部光源变化的动态光照，不宣称已有该功能。
- 当前实现参考：轮廓mask使用与本体同一PNG，矩阵 `matrix(1, 0, -.48, -.24, 0, 0)`；支点在底部上3px，接触暗部约36×4px。这些是本版实现参数，换尺寸后应保持视觉比例，不机械复制像素。
- 饥饿浅色弧线属于状态特效，不属于阴影。不可为了调整阴影顺手移除或重做该特效。
- 本体、底座、影子均遵循地图可见性与遮挡规则，不能通过影子泄露不可见角色。

## 5. 素材交付与验收

1. 使用真正带透明通道的PNG；检查透明区域，不能把画出来的灰白棋盘当成透明背景。
2. 测量非透明轮廓的包围盒，按其尺寸设置实际显示比例与脚底锚点。可裁切或通过渲染参数消除留白，不能留下悬浮间隙。
3. 素材文件使用版本名，保留用户已认可的版本。新角色优先参考v4素材及本规范，而非只凭文字重建风格。
4. 必须在实际运行的游戏、正常缩放与真实地块中检查：72/144比例、底座接地、影子方向、相邻棋子的可读性。大图预览不能替代游戏内验收。
5. 记录最终素材、生成提示词（如使用生成工具）、可见轮廓范围与加载位置。角色本体和投影使用同一资产，避免换图后仍显示旧影子。

建议生成描述：沿用v4固定抽象桌游棋子框架，小头、修长锥形身体、宽而薄的椭圆底座；固定三分之四视角，低饱和手绘与深色轮廓；仅按角色描述改变发型、脸部特征、肤色、服饰、配饰，脸部特征简洁可读；无独立手脚；真正透明背景，无地块、无文字、无地面阴影；严格保持v4整体结构与比例。
