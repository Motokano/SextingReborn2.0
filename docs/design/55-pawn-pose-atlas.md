# 共用棋子姿势图册 v1

2026-09-14，按用户要求绘制全部七部位正常/损毁组合，供外观审核。

入口：[128 状态图册](../../assets/map/isometric/pose-atlas-v1/index.html)。16 张原图 L00–L15，每张 4 列 × 2 行，覆盖 D000–D127。网页可按四肢组合、头胸腹状态、编号筛选，点击单格打开对应完整大图。

## 编号与复用

- 四肢位序：左臂、右臂、左腿、右腿。1 表示损毁，组合值为 0–15。
- 每页头胸腹位序：头 1、胸 2、腹 4，按 0–7 排列，上排 0–3、下排 4–7。
- 状态编号 = 四肢组合值 × 8 + 头胸腹组合值。左右按角色自身。
- 头胸腹损毁保留实体，显示局部伤效；四肢损毁移除对应完整模块。没有可用腿时按可用手保持撑坐或侧卧。
- 主角与普通 NPC 共用姿势数据，外观仅替换五项；特殊 Boss 可独立制作。

正本仍为 [shared-pose-map-v2.json](../../assets/map/isometric/concepts/shared-pose-map-v2.json)。图册 manifest.json 保存每格编号、数据状态、所在页和行列；generation-record.json 保存原始绘制说明、修正说明和来源图片路径。16 张最终原图已复制进项目，不依赖临时生成目录。
