## 主动位移：箭步

用户确认的要点：主动位移、6个世界tick冷却、自身视野内4格敌人、冲至目标面前、中间不得穿越阻挡、自动寻路；箭步为免费赠送的额外位移。取消此前的资源费用与独占行动候选，位移不占原有攻击机会。以下落点与AI细节为补全提案。

| 项目 | 设计 |
| --- | --- |
| 类型 | 主动位移，基本步法体系的敌人专用动作，不自动加入玩家技能表 |
| 目标 | 施术者自己当前真正看见的敌对单位，不凭同伴共享或最后已知位置隔墙锁定 |
| 目标距离 | 八方向格距不超过4格；已经有合法相邻近战位置时不使用 |
| 落点 | 目标八方向相邻的可站立空格，落地后须具备合法近战通路与视线；不能与目标重叠 |
| 路线 | 在当前真实碰撞图上自行寻找通往合法落点的最短路径，允许拐弯；目标距离上限为4格。本轮补全建议：实际路径也最多4步，每次正交或斜向跨到一个相邻格计1步，超出则不发动 |
| 身体条件 | 双腿可用且当前允许自主移动；眩晕、禁移、疼痛禁移或任一腿失能时不能发动 |
| 冷却 | 成功发动的世界tick为T，下次最早T+6；不按动画、反击或速度追加次数倒计时 |
| 资源费用 | 0气力、0底气，无其他资源费用；不以气力／底气余额作为发动条件 |
| 行动关系 | 免费额外位移，无准备轮，不额外推进世界tick，不占原本攻击机会；落地后当tick仍有正常攻击机会时可以出招，攻击照常判定资格和扣费 |
| 自身效果 | 只位移，不附加伤害、减益、击退或额外攻击次数 |

路径检查复用当前八方向行走规则：所有途经格与终点可走，墙、关闭的门、实体家具、不可走地形、单位占格均不能穿过；斜走要求两侧正交格也都可通行。可见但中间有矮障碍时，可以绕开后到达；目标本身被墙或关门遮住时不能发动，不能把“会寻路”解释成无视视野。落点按最短路径优先，等距优先目标来向侧，最后使用稳定的格子顺序，不主动绕背寻找额外收益。

发动前先确认存在完整合法路径。无可用落点、路径被封、目标不可见或冷却未结束时不发动、不进入冷却，继续原本的行动流程。提交前再次检查目标位置、视野、腿部资格及全路径；若条件失效则取消这次位移，不占用普通行动、不进入冷却。成功提交只记录冷却并完成位移，不支付资源；真实位移与演出共用同一条路径，不能只在画面上移动而保留旧占格。箭步检查不得借用普通攻击的气力／底气不足判定。

箭步在自身正常AI处理时触发，成功后因冷却不能在同tick或速度追加中重复使用。落地面朝目标，立即继续正常近战选招：本tick尚有攻击机会则可以攻击，已经用掉机会则不能因箭步刷新。落地已贴近时不再叠一次普通追击移动。位移结束不继续占用双腿的攻击／招架资格，不新增无敌或控制免疫；后续攻防按普通规则处理。冷却随世界tick自然流逝，按实例存档；脱战、回位、读档不将其清零。

用户查看第一版预览后确认“可以，就这一版”。本节的蹬地、疾冲、刹步和接摆拳视觉已定稿，独立预览已制作，尚未接入真实战斗。在现有144px棋格、125%人物尺寸下，清楚表现老练打手用腿部力量突然贴近；沿用已认可的粒子与完整棋子表现方式。免费、6 tick冷却、目标4格、自身视野和无准备轮等已定玩法保持。此次确认不将下面实际路径最多4步的独立玩法建议自动转为定稿。

### 路径建议

新增建议参数 `maxPathSteps = 4`，独立于已定 `targetRange = 4`。目标用八方向格距判定；路径步数按正交／斜向跨相邻格各1步统计，不含起点、包含终点。先筛出具备合法近战通路的目标邻格，再选择不超过4步的最短可走路线；无合格路线则走普通追击流程，不扣资源、不进入冷却。

例如目标在直线4格外，通常冲3步到其面前；小障碍绕行后4步到达仍可用，需要5步以上则不用。允许依现有通行规则绕过低矮障碍，关闭门、墙、实体家具和单位不允许穿越，斜向两侧正交格均需可通行。该上限用于解决近距离目标却绕很远冲锋的问题，是本轮建议，不能标记为用户已经确认。

多个敌人在同tick行动时按既有稳定顺序逐个重查路径与占格，先到者占用终点后，后到者选择另一合法邻格或取消箭步；不重叠、不推走同伴，不刷新攻击次数。仅有同伴共享视野时不能锁定箭步。双腿资格、眩晕和禁移在提交前重查；已开始调息时遵循调息锁定，不能借免费位移跳过锁定。

### 画风与落地

- 主色用灰褐尘土（如 `#a79c7d`、`#c8af87`），少量暗灰碎粒；残影取原酒红短袖棋子的低透明度轮廓。粒子成簇、有粗细层次，避免纤细线条勾出腿形或长时间遮住角色。
- 最多两道残影，持续约70～100ms，沿实际走过的位置保留朝向与原画长宽比；完整主棋子始终可辨。无需新增跑步图或恢复骨骼拆装，不旋转整张PNG把底座歪斜到地面外。

- 转弯使用路径经过的相邻格中心连线，按累计屏幕距离插值。不得把多段路线替换成起终点直线，也不能为了平滑曲线切入障碍占格。像素尺度随棋格与既有人物倍率统一换算。

调息替代该tick自然底气恢复，不重复叠加；气力恢复仍独立。普通攻击合法出招即付费，挥空或被招架仍消耗；先手废肢导致取消不付费，也不重新选招。速度追加攻击逐招付费、不能重复回气。底气400忽略恢复可支持40次常规攻击，头目500与单招14可支持35次；免费箭步不改变这个攻击预算。因此不能继续把第三档描述为必定续航更短，强度差距主要来自伤害、部位耐久、速度及头目的膝撞与催气。箭步本身不计为耗气：只有箭步、没有其他耗气动作的tick照常回50气力；箭步后若实际攻击耗气，则不触发该tick无耗气恢复。箭步不额外生成tick或重复结算恢复。

普通地图移动最多每tick一格，箭步作为额外免费位移可在当tick走完合法路径并保留原有攻击机会。真实视野、同伴共享、丢失目标、回位与疼痛采用共同规则，箭步锁定仍须自身直接看见目标。回位及驻点疗伤仍为每tick全身合计8点，按头、胸、腹、左手、右手、左脚、右脚分配；重见玩家停止疗伤。气力不足与调息不治疗肢体。伤势、资源、护体、箭步冷却与AI状态按实例保存，不因重新交战恢复满状态。

## 条件选招

先处理眩晕、禁移、已进入调息等行动锁定条件。尚不能近战时，自身看见目标、目标在4格内、箭步冷却完成且有完整合法路径，就优先免费箭步贴近；不要求攻击所需资源充足，也不预扣普通攻击费用。否则按原规则步行追击或搜索。已经具备相邻近战位置时，不用箭步绕位，也不为了等冷却原地发呆。箭步成功后，在本tick剩余正常攻击机会内再检查攻击资源与条件；无攻击资源时不能因为免费位移而免费攻击。

进入近战后，先过滤身体、状态、资源与距离，再按以下次序取一招：

1. 玩家身后是实际阻挡地形，且没有失衡：推搡。
2. 玩家没有眼花：戳眼。
3. 玩家没有跛足：踹膝。
4. 摆拳。
5. 身体残缺导致上述不可用时，按推搡、戳眼、踹膝尝试余下合法动作；全无则等待。

不主动重复叠满减益；只剩某一招时可使用该招。选招不读玩家未来操作。计划锁定后必要肢体失能则取消本次攻击，不临时换招。该候选替代73号第三档的固定循环提案，但需要用户确认后接入。

## 计算记录与验证边界

使用工作区实际 `CombatSkills.getBasePower` 与 `getParryValues` 计算：100级两门攻击功夫成长倍率均1.25，熟练加成0.05；徒手基础为20.60×0.7=14.42，原始伤害为14.42×1.30×招式系数。速度为1×(1+18.54×0.005)+10。招架与卸力使用100级步法成长值，乘(1+17.51×0.005)后各加固定0.05。

100级呼吸法理论底气容量为100×(1+18.54×0.01)=118.54，实例上限按用户指定单独配置为400，普通攻击费用仍固定10；不将理论容量自动覆盖模板容量，也不随容量提高招式费用。自然恢复0.12+18.54×0.02=0.4908，按一位小数步长为0.5；调息沿用原公式，ceil(ceil(400×0.05)×(1+18.54×0.02))=28。箭步的6 tick冷却与4格目标范围分别配置，不借用催气次数或伤害倍率。

与头目相比，常态伤害约77.4%，多数部位耐久约75%（左手为93.75%），速度约84.6%，没有头目专属膝撞和1.8倍催气爆发。招架率仅下降约0.94个百分点，这是现行步法曲线的结果，不能据等级100／120直接同比缩小招架率。

以上为静态数值试算，未接入实战或验证胜率。后续应重点比较玩家80／100／120级步法、不同防具、拆右手／拆腿、单体与多人情形，不能把100级敌人直接解释为玩家100级就能稳定获胜。

箭步接入后应检查：空地4格贴近、5格拒绝、自身不可见但同伴共享时拒绝、绕开可见矮障碍、关闭门／墙／单位阻挡、斜角不穿越、无空落点拒绝、腿废与眩晕取消、提交前目标移动重检；资源为0且未被其他状态禁移时仍能箭步、位移不扣资源、不推进tick、不刷新已用攻击机会、成功后可使用当tick原本的攻击机会且攻击正常扣费；只位移可正常回气、位移后实际攻击则不触发无耗气恢复；T+5不能再用／T+6可用，冷却与400底气上限存读档保留。当前没有将设计检查项当作已通过的运行测试。
