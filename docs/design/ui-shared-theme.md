# 游戏共用 UI 主题

当前决定：只保留主界面的新布局、sewing 哑光配色、小圆角与紧凑角色名片；其他系统窗口恢复原有 ui-refined 主题。普通入口不显示美术对比工具。

主界面新增样式仅作用于 HUD、快捷栏、日志及其菜单，变量也限定在这些容器中，不能向背包、战斗、生产设施或其他弹窗继承。

## 复用方式

- css/game-theme-layout.css、css/game-theme-matte.css：仅主界面布局与哑光细节；js/game-theme-navigation.js 提供主界面导航图标。
- css/game-theme.css：配色、织纹、铜色标题带、主界面比例、Buff 和日志样式。
- css/game-theme-systems.css：现有系统的外框、列表、详情、控件与状态适配。
- js/game-theme.js：装饰真实 Buff 文本及日志阅读筛选，不生成虚构游戏信息。
- 新系统容器使用 game-ui，内层使用 game-panel、game-panel-header、game-card；复用 --ui-surface、--ui-deep、--ui-accent、--ui-text、--ui-muted、--ui-border 和材质变量。结构、尺寸、显示条件由系统负责。
- 常规入口 /?no_reload；仅在需要回归对比时使用 /?ui_review=refined&no_reload。ui-theme-review 文件只负责可选工具条。

## 原有系统主题覆盖范围

主界面窗口、Buff、日志、快捷栏；背包与装备；战斗配置、技能总览、存档；料理、制药、堆肥；基地仓库与藏身处升级；农业、畜牧；工具台与修理；钓鱼、狩猎；角色创建、对话、NPC 交互、模块选择、物品提示和重置确认窗口。

保留实际地块、水域、作物、生态覆盖层与危险提示的语义配色。独立开发 Demo、调试工具和地图素材不属于游戏窗口主题。浏览器原生菜单与提示框受平台控制。

## 行为约束

不得用主题规则强制显示未知或隐藏内容；认知门控继续由原系统负责。保留现有事件、模块组成、名称和操作流程。快捷栏与日志独立布局，用户已保存的位置和尺寸仍优先。危险删除按钮保留红色。
