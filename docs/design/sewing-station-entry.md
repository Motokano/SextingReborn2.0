# 缝纫系统部署与验收

2026-10-01。用户确认棋子、界面和完整规则后要求完整部署。本目录的 8014 服务运行桌面项目，不复制到其他工作树。

## 正式入口

基地 `M0_Base_Inside_lv_1` 的 `(6,11)`，工具台左侧；从 `(6,12)` 等邻接格交互 `npc.station.sewing_base`。使用已认可透明棋子，144px格宽下可见宽64px、裁切 `[212,95,877,1033]`、锚点 `[661,1127]`，沿用设施投影。

皮尺→体重秤→人台→缝纫台，另装浸泡桶。材料点数沿用通用设施系统，备料完成后亲自施工，分别2/4/6/12/4 tick；中断保留施工进度。量具可在缝纫台建成前通过NPC使用。人台首次施工要求先测量。

缝纫台打开 `sewing-station.html`，调用父窗口 `SewingSystem`，不加载 `sewing-prototype.js`。五个菜单为制作、组装、改制、研究、硅叶处理；人台独立入口，桶与补料入口只放在硅叶页。选中信息固定展示，悬浮信息按实例认识过滤。没有累计tick标签，也不要求整页滚动。

## 业务与保存

入口菜单保留“查看缝纫台”、当前可推进的步骤与“离开”：皮尺→体重秤→首次测量→人台→缝纫台。查看沿用设施对话框，说明安装顺序、全部装好才能使用，以及浸泡桶可后装，并显示当前步骤；阅读不解锁、不消耗，读完返回菜单。完成装配后返回菜单并刷新步骤；建成后操作项为“使用缝纫台”。不展示后续禁用装配按钮。无法打开界面时保留菜单并显示原因。浸泡桶装配移入“硅叶处理”，关闭装配页返回缝纫界面；正在工作时须先完成或停止。回归：`node tools/test-sewing-menu.mjs` 调用真实 NPC 菜单，覆盖装配说明、分阶段入口、点击路由与失败反馈；`test-sewing-station.mjs` 覆盖浸泡桶装配与返回。

- `js/sewing-system.js`：结构、整数耗料、混填、材料加工、知识、随机系数、合身、温度、防御及亲自工作。任务逐tick扣体力/精力并推进世界；逐件完成才扣材料，已完成件即时保存，停止保留成果。制作整套最后组装六件。关闭或读档取消未完成工作，不离线推进。
- `data/sewing-item-texts.json` + `tools/build-sewing-catalog.mjs`：38个新增运行模板；正常物品构建脚本也复用此生成器。硅叶沿用已注册条目。`pocketable` 已进入模块化字段契约，新缝纫物品明确标记，旧物品保留兼容准入（旧装备不再塞入口袋）；其他历史材料的逐件容量标注仍可由物品表继续细化。
- 衣服实例 `sewing_parts` 保存六个真实子物品；部件 `sewing` 保存款式、部位、剪裁、尺寸、各层材料/比例/厚度/制作系数、已研究标记、永久硅叶系数与认识记录。接入原身份、复制、归属树、组合重量及保存通路；结构层不占防护改件槽。
- NPC持久标记保存知识、测量记录、人台尺寸、桶库存及独立采集点次数；施工沿用设施进度键。新档同步清理。
- 旧档一次性迁移：旧衣服身份与改件保留；补齐标准棉料部件，不赠送研究知识或硅叶处理。原弹挂/背心本体与内容物完整转回收纳，放不下的保留在当前位置地面。重复读档不重复迁移。
- 新生角色穿合身的标准棉料轻便套装，六件制作系数1，无硅叶处理、无改件。不附送版型/加工知识。
- 棉与麻各在南侧野外地图独立采集点，每点3次成功采集、每次1份。不加入种植。硅叶为100克/份，桶上限50份。
- `SewingSystem.generate({style})` / `generate({mixed:true})` 提供成款式/不成款式实例；混装保证至少两种结构来源。没有配置装备的战利品分布、概率、数量。

## 战斗与生存

分部位材料防护、硅叶防护和改件按剩余伤害乘算，防具层75%封顶后乘覆盖与合身度；盾量全局相加。激活消耗盾量基准经材料减耗和改件费用修正后的底气，战斗内呼吸50级可用，花1tick；未满可重新付完整费用补满，满盾与底气不足不扣资源、不推进时间。装备、改件变动解除盾。

温度修正接到现有舒适范围，不直接改体温；尺寸与男女版型按已确认规则给临时心情、防护发挥修正。心情保存基础值，穿戴修正不累积，脱下或性别变化即重新计算。人台仅存尺寸，剪裁在制作时选择。
