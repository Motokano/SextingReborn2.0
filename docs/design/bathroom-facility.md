# 卫生间设施

> **2026-11-01 补水接入**：用户要求给既有卫生间接入补水。正式菜单已增加“给水壶装水”，选择随身青竹／铁皮水壶装满，按真实物品实例保存水量并计入水重；下文以本次三项用途为准。普通容量200及青竹水源入壶量+60%沿[80号设计](80-water-flask-equipment.md)。后续已按80号第16节接入水壶槽与壶内饮用；粗陶和正式制作执行器仍待接入。

初版2026-10-26为饮水与洗澡；2026-11-01扩展水壶补水。所有用途都须先修复卫生间。

## 入口与修复

基地室内（14,14），设施NPC为`npc.station.bathroom_base`，全天出现。相邻且斜向通路未被墙角阻挡时可操作。显式关闭饮水、肮脏状态的NPC拒绝判定，因此缺水或脏污时仍可修复、使用；昏迷、眩晕、战斗等其他限制照常。

首次只显示“修复卫生间”，标题栏提供关闭按钮；修复使用既有选材界面。首版需求为土石8、金属6、机件2，分别修补排水槽、接管线、更换阀门接头。数值是实现时采用的可调初值，尚未完成经济平衡验收。玩家端只显示实物数量和文字，不显示内部点数。

修复进度及`bathroom_station_unlocked`随现有NPC存档持久化；旧档未修复时默认关闭，新角色清除进度。修好后没有额外进入条件或重复材料费用。

## 三个用途

| 操作 | 首版耗时 | 效果 |
|---|---|---|
| 饮水 | 1 tick，10分钟 | 饮水度补至配置上限，立即清除脱水状态和累计脱水死亡计时 |
| 洗澡 | 3 tick，30分钟 | 完成后肮脏度降至0，移除脏污状态，沿用现有清爽状态及其心情效果 |
| 给水壶装水 | 每只1 tick，10分钟 | 选择一只随身水壶，完成后补至自身容量；不直接恢复角色饮水 |

时长保存在NPC的`bathroom.drink_ticks`、`bathroom.shower_ticks`和`bathroom.refill_ticks`中；当前为可调整初值。饮水在推进时间前先补水，避免抵达脱水死亡最后一刻仍被动作耗时杀死，结束时再次补足。洗澡和装水期间按正常世界tick结算饥渴、体力、疲劳等，完成后才洗净或写入水壶存水，不额外增加心情或直接恢复饮水。洗澡、装水后的饮水度因此可能略低于操作前。

已经喝足或已经干净时对应按钮禁用，不消耗时间。未带水壶或随身水壶全满时，装水入口禁用并说明原因。进入选择页显示每只壶的语言认识名称、所在容器和当前存水／容量；同名壶通过容器格位区分，点击绑定实例ID而非模板或旧格位。满壶按钮禁用，缺少选择或目标已离身也不扣时间。

动作每tick重新检查死亡、昏迷、位置和战斗；中断保留已经过去的时间，未完成的洗澡不奖励清洁。完整动作使用现有原子存档结算，保存失败恢复动作前状态和时间。开始使用时停止其他自动行动，避免同一角色同时执行两套时间推进。

## 水壶存水与边界

- 选择口袋、背心、背包或独立水壶槽中的水壶。仓库、地面、载具和装配树内物件不远程装水。按80号第16节，饮用需先装备，装水不要求装备。
- 家中水源沿现有充足供给，每次装满一只，不收费、不赠送水壶。青竹倍率1.6、铁皮倍率1；满壶上限仍为200，青竹空壶装满对应取水125，已存190时只需6.25。没有新增家中有限水源库存或“剩余水量”计数器。
- 正式数据源 `data/water-flask-storage.json` 只补容量200、新壶存水0、水重0.005 kg／点和型号取水倍率；构建到普通物品与模块化目录。两款空壶自重仍沿正式目录0.7 kg，未套用80号第14节的青竹0.4 kg候选。粗陶未注册，本轮不开放铁皮快饮或粗陶持续恢复。
- 容量／初值／水重归 `structure.liquid_storage`，取水倍率归 `equipment.water_flask`；当前存水保存在实例 `attribute_state.structure.liquid_storage={version:1,water:…}`。新建或缺少该组的旧壶按空壶初始化一次；0值和已有水量保持，不导入独立试玩存档。
- 补水只修改选中实例的存水，保留实例ID、词条、改造、冷却与未知兼容字段。未知版本、越界水量、非法模板或多只堆叠状态拒绝装水，不擅自修复或清除原记录。时间推进后重新定位实例，已死亡丢失、存入仓库或移到地面的壶不补水、不重建。
- 存水信息模块显示当前水量与容量，型号特殊效果不在这次信息模块中公开；名称仍走语言认识规则。水重经65号组合重量入口计入一次，再沿现有背包减重计算负重。满水比空壶重1 kg。
- 使用 `SaveSystem.runAtomic` 保存水量与动作时间。存档构建对物品状态做深复制，避免修改当前水量污染动作前的回退快照。失败回退后通过实例ID重取对象；不能继续持有回退前的旧对象写入。
- 共用纯取水计划已验证有限40点源对青竹入壶64、铁皮40，但未连接正式地牢水源；日后有限水源必须把扣源与入壶放进同一事务。

- `tools/test-device-pawns.mjs`：透明PNG、源图裁切、接地点、比例、设施映射、隐蔽与未知状态、共用阴影及加载失败回退。
