# 装置材料解锁接入记录

2026-09-26，依据用户批准的 [材料点数清单](facility-unlock-point-list.md) 实施。

## 接入范围

- 烹饪台、制药台、制肥桶初修共用选材及结算；灶台供水替换旧对话献祭。旧对话不再扣材料。
- 仓库 16 个升级节点改用分类点数备料。基础仓库免费；路线发现、前置、剧情条件、施工 tick 与体力消耗保持原规则。备料完成后另行开始施工，不重复扣料。
- 原黄历标注格（居住点 7,11）改为工具台设施 NPC，日历、温度计分别解锁，没有本体费用或顺序依赖。地图暂用简易装置绘制，并非正式美术定稿。
- 日历解锁后恢复 HUD 年/日显示，原时钟保留。温度计解锁后在天气栏自动显示所在地图环境温度，取整至摄氏度；切图和 tick 更新，不需逐次测量。内部真实温度仍供系统读取，未改变计算精度。
- 湿度无运行时数据与玩法，按钮明确未开放，不收取材料。

## 认知与交互

使用原物品显示接口，未知材料保持外观名称。普通设施未掌握用途时不列入候选；玩家可读旧灶台说明或在各项目界面主动查看修补说明，记录用途，不写入物品鉴定状态。说明本身显示的材料名称同样受认知约束。仓库与工具台直接列出当前适用的材料，不要求先读说明，也不因此写入全局用途知识或鉴定状态。

所有项目隐藏需求、贡献、进度数值及百分比；材料数量以整数滑条选择，只显示实际物品件数和状态描述。核对提交直接结算，无第二次确认。

修复进度按项目独立保存。结算优先选择满足本类缺口且超额最少的整件组合，平手选件数更少者。不够时保留本次有效投入；多余整件留在原容器；已消耗整件的多余贡献不找零、不进入公共余额。

仓库可使用随身与仓内库存，遵守优先扣仓设置；封签仓内物品不纳入，携带附属部件的物品不拆作普通材料。羊毛不适合当前绑扎项目，暂不接受。普通设施使用随身材料。

## 存档与实现

共用 `FacilityUnlock`，项目配置见 `js/facility-unlock-config.js`，仓库需求沿用 `data/warehouse-upgrades.json` 的节点配置。原 `CookingRepair` / `CookingRepairPanel` 保留适配入口。

普通设施进度保存在 NPC 状态中，仓库备料进度保存在仓库自身的 `material_progress` 中，和既有存档共同持久化。仓库备料随仓库保留，不受角色用途知识重置影响。保留旧修复标记、厨房供水状态、仓库已完成升级及在建任务。新建角色清除新项目进度及观察工具解锁；读档不会重新收取费用。失败时恢复库存、仓库、标记以及厨房供水状态。

## 验证记录

### 工具台统一页面（2026-09-26）

NPC 菜单统一使用“使用工具台”入口。左侧列出日历、温度计、湿度计及装配状态，右侧直接呈现所选工具的材料滑条与交付汇总。日历与温度计仍独立解锁、独立保存投入，沿用原 observation 解锁标记，兼容已有存档；只使用随身材料。装好后显示持续生效的用途，日期与温度继续自动显示在 HUD。湿度计仅显示尚未开放，不收取材料。

隔离验收页验证统一 NPC 入口、日历与温度计在同页依次装配、状态更新和温度 HUD 生效；验收使用模拟保存，不代表正式存档往返测试。实现为 `js/toolbench-panel.js` 与 `css/toolbench-panel.css`。

### 农场与牧场长期清理（2026-09-26）

正式入口对未恢复设施显示“恢复农场 / 恢复牧场”。各自累计清理 1000 tick，每 tick 基础消耗 3 体力，使用真实生存动作结算；天气修正、疲劳、饥渴与被动消耗照常生效，因此总实际体力消耗不只基础 3000。每次劳动推进真实世界时间，调度间隔沿用游戏挂机速度。暂停、关闭、页面隐藏或体力不足时停工，读档后必须主动继续。进度只用描述呈现，不显示累计 tick 或百分比。

农场清理入口、水源口与操作位置，保留完整灌溉拼图和未开垦田地；牧场清理轴心与机械臂活动范围，保留四区牧草。清理完成后转入共用材料修复：农场土石 6、木作 4；牧场金属 8、木作 8、机件 4。未修复前关闭生产和动物安置入口，完成后开放既有管理系统，不追加初次电力费。

实现为 `js/facility-labor.js` 与 `js/facility-labor-panel.js`。NPC 存档字段 `facility_labor:<id>`、`facility_cleaned:<id>`、`facility_restored:<id>` 分别记录劳动、清理完成与材料修复完成；`facility_labor_version` 标记迁移。旧存档已开垦、种植、安装模块或安置动物的设施保留开放，尚未使用的设施进入清理流程。保存失败则停工，保留本次内存中的已付劳动与世界变化，提示重试保存，不单独退款或倒退时间。

`tools/test-facility-labor.mjs` 验证真实体力、疲劳与时间推进，体力不足、保存失败、序列化恢复、完成边界、项目隔离和旧设施迁移。隔离验收页 `tools/facility-labor-acceptance.html` 使用真实 NPC 与生存模块，验证入口及自动停工；其保存接口是替身，不等同正式浏览器存档往返验收。演示加速、补体力按钮未接入正式游戏。

- `tools/test-facility-unlock.mjs`：实际物品栏与仓库模块，项目隔离、分次投入与恢复、供水回滚、观测工具独立性、仓库混合供料与封签保护、原施工流程、旧存档标志及旧对话移除。
