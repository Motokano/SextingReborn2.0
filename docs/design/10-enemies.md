## 八（附）、敌人属性与构成（精简自主角）

敌人不沿用主角的完整属性与技能栏，仅保留参与战斗结算所需的数据；与主角共用同一套命中、招架、减伤链与部位规则，但在数值来源上做精简与直接配置。

### 敌人保留与主角一致的部分

- **肢体方案**：与玩家相同，采用**头、胸、腹、左手、右手、左脚、右脚**七部位；命中部位权重、伤害类型微调系数 \(M_{\text{部位,类型}}\)、部位效果（眩晕、骨折等）与「八、身体部位与状态效果」一致，便于同一套伤害与损毁逻辑复用。**损毁值上限默认与主角共用**，但**敌人可单独配置** `body_part_destroy_max`（脆皮化，见下「敌人『损毁即血』」节）。**设计时需声明**：敌人的**攻击技能也装备在肢体上**（如左手、右手、左脚、右脚）；**肢体被毁则该肢体上的技能无法使用**，与主角“损毁肢体无法出招”的规则一致。**已损毁部位再受击**时损毁增加值均分到其余未损毁部位，与 **09-body-parts.md** 规则相同。

### 敌人专用配置（与主角的差异）

- **速度**：**直接配置整数**。不按身手/玩家步法 hub/装备计算，每个敌人类型在配置表中给定一个**速度值** \(V\)，直接参与先手、连击与命中率公式（与玩家速度比 \(r = V_{\text{攻}}/\max(V_{\text{防}},\varepsilon)\) 等，见「七、命中、招架与伤害流程」）。

- **内功与身体减伤**：不采用主角的「柔韧 → 基础防御」动态公式。为敌人**直接设计**两类减伤系数，在配置表中为每种敌人设定：
  - **内功减伤**（可选）：可理解为“内气护体”的百分比减伤，在减伤链中为**独立一层**：**卸力 → 护体 → 内功减伤 → 身体减伤 → 伤害类型微调**（内功减伤**不**等价于主角的防具减伤或护体层，三者位置不同）。
  - **身体减伤系数**：直接配置一个**身体减伤百分比**（或等价系数），在减伤链中替代主角的「基础防御（柔韧）」一步；即玩家命中敌人后，在卸力、护体（若有）、内功减伤之后，再乘以该身体减伤系数，再乘伤害类型微调 \(M_{\text{部位,类型}}\)。

- **招架**：规则与主角一致（命中后先判定招架，成功则本次不造成伤害；失败则先按卸力比例硬减伤，再进入护体→内功/防具→身体减伤→伤害类型微调）。**敌人招架不享受柔韧加成**：仅使用**基础招架几率**与**基础卸力比例**，不再乘以 \((1 + \text{系数} \times \text{柔韧})\)。两值在敌人配置表中直接给出，可设 0 表示不招架。  
- **与主角共用机制（已定）**：**招架相关 Buff**、**tick 末位移**、**后遗症 `effect_type`**（如驱散）等，**可与主角共用同一模板**（`data/buffs.json` / `post-effects.json` 中 **`mechanic_shared_with_enemy: true`** 语义）；敌人侧在攻击/受击上下文中挂载等价 **`post_effect_ids`** 或调用 **`melee_hit_enemy_defender`** 管线即可，无需复制一套独立 id（除非单条声明例外）。

- **攻击动作**：**单独为敌人设计**。敌人不使用主角的技能树与招式池；每种敌人类型在配置表中拥有自己的**攻击动作列表**（含普攻与可选技能），每条动作**装备在指定肢体上**（见上“肢体方案”），肢体损毁则无法使用该肢上的动作。**威力**：可为每条动作**直接指定一个数字范围**（如威力最小值与最大值）；**攻击时在该范围内随机取一值作为本次威力**，再参与伤害公式，即单次伤害在范围内浮动。

- **原始伤害公式（已定）**：敌人**不吃技能侧乘区**。敌人本击的**原始伤害 = 威力随机值 ×（暴击系数，若该动作/敌人配置了暴击）×（环境增伤，若配置）**，随后**直接进入减伤链**（命中 roll → 招架/卸力 → 护体 → 内功减伤 → 身体减伤 → 伤害类型微调）。敌人原始伤害**不乘**成数乘区 \(F_{\text{出力}}\)、不乘实战经验增伤、不乘招式熟练度/呼吸法威力等 \(W_{\text{coef}}\) 技能侧乘区；未配置暴击或环境字段时对应乘区按 1 处理。

- **气力条**：敌人**仅设计一条气力条**（与主角 **气力值** 概念同源、实现上为简化版战斗资源）。气力上限、每回合自然恢复量（或每 N 回合恢复）在敌人配置表中设定；释放需消耗气力的攻击动作时从该条扣除，不足则不可使用该动作。敌人**不沿用**主角的底气上限/行气/完整呼吸法体系；若某敌人需“护体”等，用上条**护体**与**内功减伤**等字段表达，而非照搬 `diqi` 规则。

- **护体**：**是否具备护体、护体减伤比例与护体容量**均可**按敌人具体设定**。若该敌人配置了护体，则与主角的底气护体在同一减伤链位置生效（卸力之后、内功/身体减伤之前——主角侧该层现为「激活盾」，见 **[37-equipment-modular-armor.md](37-equipment-modular-armor.md)**），护体被击破前按配置的减伤比例与容量结算；未配置则无护体层。

### 敌人掉落池

- **设计时提前定义**：每种敌人的**掉落池**在设计该敌人时**提前定义**，明确该敌人死亡后可掉落的**物品有哪些**。
- **每项物品的爆率**：掉落池中**每一项物品的爆率均需详细声明**（如概率、权重或等价规则）；实现时按该爆率在击杀该敌人时进行掉落判定。爆率的具体含义（独立概率、互斥多选一、权重抽样等）在配置表结构或全局规则中统一约定。
- **物品来源**：掉落池中的物品**在物品表中定义**；敌人配置中通过**物品 ID**（或等价引用）指向物品表内的条目，不重复定义物品属性。物品表见项目内物品/配置相关文档。

### 敌人不包含的内容

- 无生存属性：无饱食、饮水、体力、精力、心情、定力、性能力、性别、营养、体温、体重等。
- 无基础属性与衍生：无筋骨/柔韧/呼吸/身手/专注及由此衍生的负重、学习效率等。
- 无技能栏：无生存/生活/战斗/特殊四条技能栏；仅有上述“攻击动作列表”与气力条。
- 无装备系统：无多槽位装备与负重；内功/身体减伤、招架、速度等均在敌人配置表中直接给出。

### 实现约定（配置字段建议）

- 敌人类型表（或等价配置）建议字段：`speed`（速度，整数）、`parry_rate`（基础招架几率）、`parry_damage_reduce`（基础卸力比例）、`inner_damage_reduce`（内功减伤，如 0～1）、`body_damage_reduce`（身体减伤系数，如 0～1）、`qi_li_max`（气力上限，可与实现字段名 `enemy_qi_li_max` 等对齐）、`qi_li_regen_per_turn`（每回合气力恢复）；`has_shield`（是否有护体）、`shield_damage_reduce`（护体减伤比例）、`shield_capacity`（护体容量）；`body_part_destroy_max`（**可选**：七部位损毁上限，脆皮化「损毁即血」；未配置时与主角共用上限）；攻击动作列表（每条动作需指定**装备肢体**、**威力范围**（如 `power_min`/`power_max`，攻击时在范围内随机取整或浮点）、伤害类型、**气力消耗**、范围等）；**掉落池**（`loot_table` 或等价）：列表项为（**物品 ID**，**爆率**），物品 ID 引用物品表，爆率按全局约定填写（如 0～1 独立概率、或权重值等），设计时须为每项掉落明确声明爆率。
- **实现状态（2026-05）**：**攻击动作列表**（`actions[]`：`id` / `name_key` / `limb` / `power_min` / `power_max` / `damage_type` / `qi_cost` / 可选 `hit_part_weights`）与**敌人气力条**（`qi_li_max` / `qi_li_regen_per_turn`，每次还击前按回合恢复、动作扣气、气力不足的动作不可选）已接线（`combat-enemies.js` `pickEnemyAction` / `sampleHitPartForAction` / 气力追踪；`combat-melee-resolve.js` `resolveEnemyVsPlayerAttack` 消费；未配 `actions` 或全部动作气力不足时回退 `attack_damage_*` 通用还击）。**敌人 AI v1 已接线**（主动追击/攻击/脱战回巢，见下方「敌人 AI」节）。**敌人「损毁即血」已接线**（`body_part_destroy_max` + 实例损毁状态 + 死亡队列 + 场景移除 + 肢体失能日志，见下「敌人『损毁即血』」节；肢体损毁联动已进 `pickEnemyAction` 与 `updateEnemyAI`）。**未接线**：掉落池、护体、气力按实例持久化（当前按 `enemy_id` 共享近似）。具体示例见下「敌人示例：地痞」。

### 敌人 AI（v1，已实现）

- **驱动**：每个世界 tick 一次（`scene-app.js` `tickEnemiesAfterWorldTick` 挂于 `patchSurvivalTickForWorldSystemsOnce`）；决策逻辑在 `combat-enemies.js` `updateEnemyAI`（纯逻辑，可单测），场景落地（改 `map.enemies` 坐标、脏格重绘、走玩家受击管线）在 scene-app。
- **追击**：玩家进入 **`aggro_radius`**（默认 5 格，切比雪夫距离）→ 敌人每 **`move_interval_ticks`**（默认 1）向玩家走 1 步（**BFS 最短路径**，8 邻域；避开障碍、玩家格、其它敌人格、NPC 格、传送门格；贴墙/凹角可绕行）。
- **攻击**：贴脸（距离 ≤ 1）→ **每 tick 攻击一次**（走**完整玩家受击管线** `melee_hit_player_defender`：命中 roll → CombatParry 肢位招架 → 卸力 → 后遗症 → 底气护体 → 最终伤害，与还击同一套结算）。**去重**：若该敌人**本玩家动作内已经反击过**（玩家攻击它时的交换反击，`scene-app.js` `enemyCounterAttackFlags`），AI 不再补刀——敌人**每玩家动作恰好行动 1 次**（你攻击它 → 反击算这一击；你做别的 → AI 主动打），无冷却数字、不叠加。
- **脱战**：距离 > **`leash_radius`**（默认 8）→ 脱战，走回出生点；回到出生点后待机（不巡逻）。
- **不参与**：`can_attack === false` 的敌人（训练木桩）不追击不攻击。
- **已知边界（v1）**：无视线遮挡判定（直线距离即仇恨）；无巡逻游荡；敌人移动会真实改写地图坐标（渲染/点击/攻击全链路一致）；同一 tick 先结算移动后结算攻击（贴脸当回合即可出手）；贴脸时原地待机（不绕圈，等下一个未反击的 tick 出手）；AI 攻击不校验玩家是否处于创建/剧情锁阶段（野外遭遇前玩家通常已完成创建）。

### 敌人「损毁即血」（v1，已实现）

敌人**无独立 HP**：七部位损毁即血量。每次命中 → 命中部位损毁 +Q（Q = 本次最终伤害，走 **09-body-parts「损毁写入」规则**：未损毁部位全加封顶、已损毁部位均分到未损毁部位、全毁则 Q 作废）。

- **死亡判定**：**致命区（头/胸/腹）任一损毁满 = 死亡**；或**七部位全毁 = 死亡**（兜底——打已毁部位时伤害均分，自然流向致命区，"磨死"路径存在）。
- **失能（不致死）**：**手毁**（左/右手任一条损毁满）→ 该肢攻击动作不可用（`pickEnemyAction` 过滤）；**腿毁**（左/右脚任一条损毁满）→ 敌人不再移动（`updateEnemyAI`：追击/回巢全停，原地待机只保留攻击）。
- **部位上限**：默认与主角共用（头 50/胸 100/腹 80/四肢 100——即打不死）；配置 **`body_part_destroy_max`** 后脆皮化，普通敌人据此可被杀。`limbs_invulnerable`（木桩）跳过损毁。
- **死亡判定位置**：玩家对敌人攻击的伤害结算后（管线 `damage_stub` 与同速 `finalizeSimultaneousStrike` 的损毁写入点，`combat-pipeline.js` `applyDestroyToDefender`）。玩家先手分支中若本击将敌人打死，**跳过该敌人本交换的还击段**（07「先击杀即避免再挨对方本击」）；同速/敌先分支按原结构结算（同速允许同归）。
- **死亡落地**：`combat-enemies.js` 记死亡队列（实例键 `mapId|i{index}`），场景 `attackEnemy` 结算后 `drainEnemyKillQueue`：移除地图 `enemies[]` 实例 + 坐标脏格重绘 + 日志 `combat.log.enemy_killed`；**肢体失能日志**（部位被打满瞬间）经 `drainEnemyLimbLossQueue` 输出（手/躯干 `combat.log.enemy_limb_destroyed`、腿 `combat.log.enemy_limb_destroyed_leg`）。
- **实例状态**：损毁/死亡按 `mapId|i{index}` 运行时键（与 AI 状态同键体系）——同地图内持续（打残后拉开再回来仍是残躯），地图重载/刷新页面后重建。**未配置 `body_part_destroy_max` 的敌人不参与死亡判定**（木桩/陪练保持打不坏）。
- **策略语义（招式 = 部位策略）**：玩家招式命中部位由 `hit_part_weights` 决定（如「流氓散手」戳眼偏头 60% / 踹膝偏腿 35%+35% / 推搡偏胸腹 40%+30%），因此**选招即选部位**——戳眼爆头速杀、踹膝断腿控场、推搡磨躯干稳定致死。

### 敌人示例：「地痞」（`enemy.street_thug`）

作为**最简单的敌人**（首个敌对单位）示例，与 `11-skills` 8.3.6「流氓散手」同源定位——玩家新学的野路子拳脚，正好用来收拾这些街头混混。

- **定位**：玩家离开基地后的第一个练手对象。无招架、无减伤、无特殊机制，纯粹的「挨打+还手」，用于熟悉命中/招架/减伤链节奏。
- **配置**（`data/combat-enemies.json` → `enemy.street_thug`）：

| 字段 | 值 | 说明 |
|------|-----|------|
| `speed` | 2 | 玩家初始战斗速度约 1.05（身手 10 × 步法基础 1）时，玩家命中约 46%、地痞命中约 86%；地痞伤害低（2～6），前期可打赢 |
| `body_part_destroy_max` | 头 20 / 胸 28 / 腹 24 / 四肢 36 | 「损毁即血」部位上限（见下节）；玩家新角色每招命中损毁约 7～8.4（流氓散手 1 级、筋骨 10）：戳眼爆头约 3 拳命中死、推搡磨躯干约 4 拳、踹膝断腿约 5 拳废 |
| `parry_rate` / `parry_damage_reduce` | 0 / 0 | 不招架 |
| `inner_damage_reduce` / `body_damage_reduce` | 0 / 0 | 无任何减伤 |
| `can_attack` | `true` | 会还手（区别于训练木桩） |
| `qi_li_max` / `qi_li_regen_per_turn` | 0 / 0 | 气力条（本敌全招式零气耗，0 即可；气力系统已接线） |
| `aggro_radius` / `leash_radius` | 5 / 8 | 仇恨 5 格、脱战 8 格（敌人 AI v1） |
| `move_interval_ticks` | 1 | 每 tick 走 1 步；贴脸攻击无冷却（每 tick 一次，反击去重） |
| `actions` | 见下「招式表」 | 攻击动作列表（已实现）；未配置或气力不足时回退 `attack_damage_*` 通用还击 |

- **招式表（攻击动作列表，与「流氓散手」同源的低配版）**：

| 动作 id | 名称（ui key） | 装备肢体 | 威力范围 | 伤害类型 | 气耗 | 命中部位权重（规范部位空间） |
|---------|---------------|---------|---------|----------|------|------------------------------|
| `thug_punch` | 挥拳（`enemy.action.thug_punch`） | `rhand` | 2～4 | 钝击 | 0 | 头 10 / 胸 50 / 腹 20 / 四肢各 5 |
| `thug_knee` | 踹膝（`enemy.action.thug_knee`） | `rfoot` | 3～6 | 钝击 | 0 | 腿各 35 / 腹 20 / 胸 10 |
| `thug_shove` | 推搡（`enemy.action.thug_shove`） | `lhand` | 2～3 | 钝击 | 0 | 胸 40 / 腹 30 / 臂各 10 / 腿各 5 |

  - 每次还击在**气力可负担**的动作中随机选一条；命中部位按该动作权重抽样（权重键为**规范部位空间** `head/chest/abdomen/left_arm/right_arm/left_leg/right_leg`，与 CombatParry / `mapHitPartToModifierKey` 一致；实现兼容旧运行时键 `belly/lhand/rfoot` 等），影响玩家**承担招架的肢体**（躯干受击取 lhand→rhand→lfoot→rfoot 首条未损毁肢，见 `08`）。比玩家版弱一档（玩家踹膝带跛足 debuff、推搡带击退，地痞版为裸伤害），保持练手靶子定位。
  - **肢体损毁联动已实现**（损毁即血）：动作装备肢体损毁则该动作不可用（玩家打断地痞的手 → 它不能推搡/挥拳），形成部位打击正反馈；腿毁 → 地痞不再移动。
