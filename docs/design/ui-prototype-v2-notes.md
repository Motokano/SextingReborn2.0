# 主界面美术对比 v3（待验收）

用户否定了独立场景和虚构面板。本版停止 v2 的“旅人、眼前、习得”等演示，直接在 index.html 的实际游戏 DOM 上增加可选主题。原 ui-prototype.html 入口转到真实游戏对比页。

启动：npm run dev；打开 /?ui_review=refined&no_reload。

- 原版／美化版只切换 body 的 ui-refined 类，不重新加载，不改名称、内容、认知、存档、窗口布局或事件处理。
- 正常游戏 URL 未带 ui_review 时，不加载主题或对比工具。
- css/ui-theme-review.css 集中共用配色和外框规则，适配真实状态卡、自由窗口、时间、快捷动作、腰带、游戏日志，以及已有背包、技能、生产容器。
- 不新增系统、不模拟解锁、不强制显示隐藏内容。当前角色未解锁的界面继续由游戏原来的代码控制。
- 复用正式 UIWindows。23 项现有窗口检查通过。浏览器已检查实际地图页面及原版／美化版切换；尚未对所有系统的全部状态做视觉验收。
- 正式采用前需由用户在其实际进度下评审；验收后整合主题并移除试作切换器。
