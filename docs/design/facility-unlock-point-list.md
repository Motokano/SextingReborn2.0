2026-09-26，用户确认后接入首轮运行时配置。实现与验收见 [装置解锁接入记录](facility-unlock-implementation.md)。

范围：先覆盖灶台、制药台、制肥桶、拟新增的工具台，以及现有仓库升级节点。其他装置另行梳理，不把此表当成全游戏解锁全集。

## 规则

- 游戏内隐藏需求、贡献、缺额、累计点数及百分比，只显示认知允许的实物名称、件数和修复描述。
- 同类别可替代，类别之间不能抵扣。每行需求是该项目自身的增量成本，不含前置项目。
- 未使用的整件材料保留在原容器；实际消耗单件内的余量不返还碎片、不结转公共余额。
- 除湿度计外，下表需求已接入。当前为首轮数值，尚未完成掉落与经济平衡验收。
- 床、基础仓库等默认开放的功能保持原样，不因引入点数而新增门槛。
