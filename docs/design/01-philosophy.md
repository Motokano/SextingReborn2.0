# 一、整体设计哲学

- **世界观**：灵感来自电影《Kampfansage - Der letzte Schüler》。在一连串自然灾害与经济崩溃之后，世界秩序崩坏，国家与城市体系瓦解，军阀与各路势力凭借暴力行使权力，科技沉沦，冷兵器与武术重新成为解决冲突与获取资源的主要手段。主角原本只是 2026 年的一名普通都市人，因意外穿越到这个破碎世界，被迫从零开始学习生存与武术，一边在军阀割据、武馆残余与民间武装之间周旋，一边探索这个时代的规则与秘密，寻找回到原本世界的道路。
- **0 教学、0 引导**：无弹窗、无任务提示、也不做“藏在世界里的教学”；规则只通过行为与结果体现。
- **认知论：知道的就是知道，不知道的就是不知道**：游戏**从不向玩家宣告“存在什么”**——凡未通过任务、NPC 传闻、食谱残页、贸易情报、地牢掉落等**世界内途径**得知的东西，玩家在 UI 与面板上永远看不到（无图鉴剧透、无成就列表剧透、无剪影占位）。**知道本身是奖励**：发现“世界上存在某道传说菜”和做出它一样是里程碑；每层“知道”（存在→原料→工艺→成品）都是成长的一部分。可错过的信息是**特性**（重玩价值），但每个关键信息至少要保证一条**世界内可达的线索链**。
- **成长基调：极为缓慢且痛苦（有意为之）**：属性/技能成长以周、月计，靠长期积累而非爆发。痛苦的三根支柱：**稀缺**（好食物/资源极难获得）、**不确定**（升级为概率结算、永不 100%）、**归零风险**（死亡清空随身物品并扣技能等级）。玩家围绕“活下去→吃得更好→慢慢变强”的苦行式循环行动。**该基调不视为缺陷**，后续任何数值调整都须保持“缓慢 + 痛苦”的底色（见 `05` 5.4、`24` 24.5a）。
- **痛苦与回报成对设计（对冲原则）**：每个痛苦阶梯的顶端必须立一个足够大的奖杯。玩家承受的缓慢、不确定与稀缺，必须在峰值处兑现为强烈的成就感——**路径越苦，峰值必须越高**（顿悟式直升、临时质变、排他的永久收益、仪式感）。否则“痛苦”会滑向“劝退”。回报峰值设计见 `24` 24.5a E。
- **高风险、高惩罚**：从一开始就使用完整死亡惩罚，不刻意对早期地牢放宽。
- **战斗非强制**：所有战斗（含最终 Boss）都可绕；进入地牢的首要目标是**生存并撤离**，而非清怪或通关。
- **无“必备物品”**：生产、料理、药品、改造等均为可选增强，玩家可完全不依赖生产硬打地牢。
