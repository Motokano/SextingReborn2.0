# 技能装配界面定稿与接入

2026-10-17，用户确认 B 版及最后一轮肌肉列表，授权实装。探索问题是四肢配置应按肢体、横向对照还是出手顺序组织；最终选择四肢对照表，减少说明和层级，沿用现有深绿面板、铜色边框、凹槽与颗粒材质。

## 定稿

- 招式：顶栏只保留标题和分页；呼吸法与步法集中在表格上方。四肢各一行，展示顺位、技能、主招式、熟练度和变式；点击对应单元格直接编辑。出手顺序默认收起交换按钮。
- 肌群：按头颈、躯干、左右臂和左右腿筛选；总览只显示肌群、解锁进度和大型被动，底部汇总真实加成。
- 肌肉：双列肌肉格，每页八项；解锁数与进度集中于顶部，名称与属性分行。已解锁格使用凹槽和勾选；被动入口、分页放在底部。左右肢体省略重复后缀，中轴肌群保留左右名称。长列表保留四行高度；窄屏单列。

## 正式落点

`ui/src/features/CombatPanel.svelte` 负责显示，`ui/src/runtime/combat-panel.js` 从 CombatSkills、CombatVariants、InventoryEquipment、Muscles 读取配置和进度，所有修改通过现有业务 API 执行。材质放在 `css/combat-loadout.css`，仅作用于技能装配及其子弹窗。

默认入口通过 `runtime/combat-mount.js` 单独挂载，独立构建为 `assets/ui/combat-loadout.js`，不依赖其他未完成的 HUD 迁移。完整 Svelte 模式通过 panels 组合挂载同一组件，独立入口检测到已有所有者后退出。SceneApp.combatApi 保留打开、关闭与时间规则。

沿用当前前置技能 `special_meridian_studies`（界面名称「解剖学」）的一级门槛。肌群全通、适用范围、空槽和同被动全局唯一由 Muscles 校验；肌肉解锁和装配进入原存档字段。没有导入预览的示例等级、解锁数据或被动；没有增加资源扣费或熟练度前置规则。切换呼吸法仍消耗一回合。变式读取实际表，当前表为空时展示空状态。

子弹窗绑定肢体、技能和会话；提交前重新验证候选、槽位及权限，避免旧选择覆盖已变化的配置。复用弹窗输入管理，Escape 逐层关闭，解锁后焦点保留在原肌肉格。

原型 A/C、方案切换器和示例状态已删除；旧原型 HTML 仅保留跳转，避免已分享地址失效。
