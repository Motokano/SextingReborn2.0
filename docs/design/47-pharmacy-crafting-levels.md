# 制药推荐等级与良品率

状态：用户已确认原则；等级不足惩罚已定为每级5个百分点，运行时硬门槛尚未修改。本文替代此前制药工艺/配方以技能等级完全禁止开工的设计。

## 工艺与配方

原工艺、配方等级转为推荐等级，低于推荐等级仍允许尝试，差距越大成功率越低；达到推荐等级后进入正常成功率范围。相应制药台、工具、材料和其他非等级开工条件仍须满足。

仅按玩家当前技能与本工序推荐等级的差距计算不足惩罚，不因材料高级或上游由低级工艺加工而重复扣减。若工艺与配方都配置等级，实施时统一为本次工序的有效推荐等级，避免两次处罚；具体取值与既有熟练度加成的组合待数值核对。

成功产出标准成品，不新增劣品、残次品或随机弱效版本。失败消耗本批投入及加工资源，产既有药渣。开工前显示实际成功率，让玩家能判断是否值得尝试；不得仅展示无技能修正的基础成功率。

购买或取得高级中间材料可以跳过上游提炼步骤；仅评估玩家实际执行的这一步工艺，不要求掌握完整上游技术。

## 自配注射液例外

自配注射液不参与随机良品率：配伍成立且满足开工条件就正常产出；配伍不成立按既定规则产药渣。技能等级影响可判断的信息，不改变相同配方的成立结果，也不额外掷一次配置失败。

## 数值核对（以文末5点定稿覆盖早期候选）

需要定义推荐等级差与成功率的关系、最低成功率以及与既有工艺熟练度的组合。复核多级加工的整链产出和预期成本，避免每步低概率相乘造成实际无法获得成品。本文未确认具体百分比，不将任何示例或默认公式视为定稿。

此前文档中的0/2/4/6/8/10等工艺或成品等级作为推荐等级候选，不再作为新版禁止制作的硬门槛；运行时仍保留旧实现，部署时须更新开工校验与制药台展示。信息分阶段解锁维持既定规则，不因加工等级改为软限制而自动解锁。

## 成功率数值定稿

用户最终选定每低于推荐等级1级扣5个百分点，替代7点和4点候选。保留每级增加0.5个百分点的现有加成；工艺与配方推荐等级取较高者，只计算一次等级差。

中性心情参考公式：成功率=clamp(工艺基础成功率+0.005×制药等级−0.05×max(0,有效推荐等级−制药等级),0.15,1)。15%为中性心情的下限口径；其他既有修正和满级行为部署时对照原流程核对，不在此轮新增或取消。自配注射液不适用随机成功率。

推荐10级、基础82%的结晶：0级32%、2级43%、5级59.5%、8级76%、10级87%。百分比扣减为百分点，非按原成功率乘95%。该数值已确认，尚未实装。
