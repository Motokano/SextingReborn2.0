# 52. 七部位棋子与共用损毁姿势

状态：设计规则已确认，2026-09-14；模块素材与运行时姿势系统尚未实现。

本文件是用户对[51号棋子美术规范](51-pawn-art-direction.md)的明确修订。涉及独立手脚、部位损毁、姿势及共用框架时，以本文件为准。v4仍是当前游戏已接入的静态素材；新卡通七部位参考图用于探索，具体造型比例尚待最终验收。

## 1. 共用范围

主角与普通NPC共用一套七部位结构、连接点、左右编号、正常姿势及损毁组合姿势。普通人形敌人沿用同一机制。新角色只提供发型、脸部特征、肤色、服饰、配饰，换对应外观层，不为每个角色重新生成整套受伤姿势图。

特殊Boss级NPC允许额外制作专用姿势集；仅作为明确的特殊角色需求，不因普通NPC身份不同就另建结构。专用姿势仍应正确表达其实际部位状态，不能借外观修改战斗规则。

## 2. 七部位与左右

对应现有系统的 head（头）、chest（胸）、abdomen（腹）、lhand/rhand（左右手）、lfoot/rfoot（左右脚）。视觉上“手”模块包含整条袖臂与手掌，“脚”模块包含对应腿与鞋；内部可继续分层，但不新增损毁部位或独立阈值。底座不属于身体部位。

左右始终指角色自身左右，绑定固定部位ID。近正面时角色左通常在画面右，不能按屏幕左右命名。镜像外观、转向、姿势变换不能交换逻辑ID。参考图的标签和动作不能作为左右映射的权威。

## 3. 损毁的视觉规则

| 部位 | 满值损毁时的表现 |
|---|---|
| 头 | 保留头部，用局部伤效、低垂或歪斜表达 |
| 胸 | 保留胸部，用局部伤效、塌缩或护胸姿态表达 |
| 腹 | 保留腹部，用局部伤效、屈腰或蜷缩表达 |
| 左右手 | 隐藏对应手臂模块，缺失处为干净的抽象拼装截面 |
| 左右脚 | 隐藏对应腿脚模块，并改变承重姿势 |

四肢缺失是抽象棋子的失能符号，不代表剧情上真实断肢，不增加截肢/再生机制。不画血肉；也不自动增加绷带、石膏或拐杖等治疗装备。头胸腹不能隐藏成空洞。部位恢复时跟随实际状态重现或解除伤效。

损毁判定复用[09号肢体系统](09-body-parts.md)与运行时配置/API，不另建数值上限或视觉触发阈值，不把眩晕、疼痛、死亡与头部损毁混为同一状态。

## 4. 共用姿势与特殊组合

先根据剩余手脚选择支撑姿势，再叠加头胸腹局部伤效。不是七张互斥全身伤图，多部位状态必须能够组合。

| 四肢损毁组合 | 共用姿势方向 |
|---|---|
| 无四肢损毁 | 正常站姿，允许叠加躯干伤态 |
| 单手 | 对应臂缺失，轻微重心调整 |
| 双手、双腿完整 | 双臂缺失，保留双腿支撑；不得出现护胸、护腹或撑地手 |
| 单腿、双手可用 | 剩余腿屈曲承重、身体降低，必要时可用手撑地 |
| 一手一腿 | 用剩余腿与手形成支撑；分别处理同侧/异侧和左右组合 |
| 单腿加双手 | 仅剩单腿，采用降低重心的蹲坐/侧坐，必要时让躯干靠底座支撑，不悬空站立 |
| 双腿、双手可用 | 坐倒在底座上，用可用手撑住身体 |
| 双腿加单手 | 坐倒，剩余手单侧撑地 |
| 双腿加双手 | 侧卧或伏倒在底座上 |

表中是已确认动作方向与支撑约束；角度、接触点和动画过渡留给实现校准。损毁的手不能护胸、护腹或撑地；缺失的腿不能承重。胸腹蜷缩不应破坏已选支撑，无法使用手时用躯干姿态表达。

所有姿势保持底座与占格位置稳定，躯干落在底座可支撑范围。姿势不会自行改变碰撞、移动消耗、攻击或其他行动规则。投影应使用当前已组合姿态和仍可见的部件，不能残留缺失肢体或旧站姿的影子；沿用已认可的地面投影风格与可见性限制。

## 5. 生产与验证要求

先完成一个可拼装标准角色，确认正常与损毁姿势、关节点、连接接缝、左右映射、层级遮挡和小尺寸可读性，再复用到新NPC。衣服跨胸腹的接缝及配饰归属需要按统一连接点处理。

应能遍历七部位的全部128种正常/损毁组合，验证部位显隐、头胸腹始终存在、剩余支撑肢体与姿势一致、恢复能正确重现。无需为128种组合分别生成整张图片。重点人工检查单腿四种一手一腿组合、双腿损毁及四肢全损毁。

使用与当前游戏相符的缩放检查；站姿相对地块的尺寸、手绘风格、透明素材、平滑缩放和落地原则继续参考51号规范。更卡通的新比例允许在本轮明确修订，但未经验收不把探索图当作已接入的最终标准。
