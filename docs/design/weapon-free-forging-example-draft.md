2026-10-13。用户认为逐格复制目标盘面太难，改为只统计部件的关键区域，允许玩家自己组织加工路线。新版先用B01直刃验证，现按要求扩充到全部83个部件，并加入三类目标：压低总分、控制区间、堆高总分。

[直接打开独立HTML试玩](../../tools/blade-forging-playtest.html)。仍使用同一个文件路径，刷新即可；单文件可离线分享。旧版精确盘面HTML另行保留，不代表当前方向。本文件与[原型说明](../../tools/blade-forging/NOTES.md)记录当前规则；材料潜力和正式武器属性未接入。

## 三类区域目标

所有目标仅统计金色高亮的有效格，而非整张盘面的总量。非计分格仍参与传分和热处理。对于压分任务，玩家可以用轻锤直接削减，也可以把多余分数敲到其他位置。跨部位部件合并统计多个部位，重叠格只计一次，不增加额外单区达标门槛。

| 类型 | 三星条件 | 完成度 |
|---|---|---|
| 堆高总分 | 区域总分 S ≥ 目标 L | min(100, floor(100 × S / L)) |
| 压低总分 | S ≤ 上限 U，包含边界 | max(0, 100 − ceil(100 × D / D₀)) |
| 控制区间 | L ≤ S ≤ U，包含两端 | max(0, 100 − ceil(100 × D / D₀)) |

压分差距 D = max(0, S − U)。控分差距 D = max(0, L − S, S − U)，即距最近合格边界的距离；D₀是同一部件初始盘面的差距。压分与控分初始完成度为0%，消除初始差距提升完成度；控分超过上界会重新掉分。区间内分布自由，不要求平均，也不追求中点。全部83件初始盘面均未获星，不会开炉直接完美。

用户指定星级：完成度60%起一星，80%起二星，100%三星完美；低于60%可以收工但无星。评价读取当前盘面，途中得到三星后继续加工可能掉星。落锤和热处理预览同时显示预计区域分数与完成度；减分在压分任务中可能是正向进展，不能一概视为惩罚。

此次任务分配为34件堆分、13件压分、36件控分。分数代表该任务的加工量，不自动等于硬度、威力或品质。具体初值与目标均为试玩配置，尚待玩家反馈调校。

## 操作、随机与轮廓

用户进一步指出压分任务缺乏直接减少点数的手段，提出将轻锤改为该格点数减半。当前试玩按向下取整实现，并保留每炉最多3次的限制；不触发留力、传力或聚料，也不消耗一次性特殊效果。预览和特效显示实际减少的分数。该变化替代旧版轻锤＋1。

| 操作 | 当前结算 |
|---|---|
| 轻锤 | 落点减半并向下取整，例如5→2、1→0；其他格不变，最多3次 |
| 大力锤 | 落点归零，原值分别加给上下左右的紧邻有效格；无单独次数上限 |
| 十字锤 | 落点归零，原值分别加给同一行、同一列全部其他有效格；最多1次，此位置之后不能再用任何锤法 |
| 淬火 | 所有有效格＋1，各炉1次 |
| 回火 | 保持全盘总量，平均分配给所有有效格；各炉1次 |

三种锤法共用6次锤击；轻锤与十字锤同时扣总额度和自身额度。工序均不强制使用，不必用完次数。三种锤法都不能敲0格，无效点击不扣次数。

回火每格先取整数平均值，余数按回火前格值从高到低逐格补1，同值按从上到下、每行从左到右排序。锁定格仍接分、计分和热处理；回火不解除禁敲，也不重置特殊格。

部件空白区域不是数值为0的格子：不能落锤、不接收传分、不计入回火分母。大力锤不跨空白；十字锤作用于整行整列的有效格，可以跨过轮廓空白。图形是锻造操作形状，不改变武器安装部位或耐久实例数量。

固定格每炉随机两个不同位置、两种不同效果，开局完整可见；重试本炉保留配置，换一炉重新抽取。当前保留三种效果：

- 留力：落点操作前≥6分时，大力锤/十字锤保留落点数值并正常传分；十字锤仍禁敲该位置。
- 传力：首次大力锤/十字锤向外传递双倍原值，随后失效；轻锤与热处理不消耗它。
- 聚料：直接收到其他格锤击传分时额外＋2；禁敲后仍可接收，不响应轻锤和热处理。

全部条件读取操作前状态，每个接收格只处理一次，不连锁。相同效果在不同目标下可能有利或不利，例如留力可能妨碍把计分格清空；不额外修改效果以迎合关卡目标。

## 每锤随机的临时机会

在每炉两个固定特殊格之外，每次有效轻锤、大力锤或十字锤结算后，随机刷新一个临时格。第一锤前没有临时格；三个类型独立随机，可以重复，不安排轮换，也不保证一炉全出现。同时最多一个，不累计。

| 临时效果 | 触发结果 |
|---|---|
| 余热 | 正常锤法及固定效果结算后，落点＋2 |
| 剥落 | 正常锤法及固定效果结算后，四个紧邻有效格各－1，最低为0 |
| 回流 | 正常锤法及固定效果结算后，落点与箭头指向的一个紧邻有效格交换数值 |

只有直接落锤才触发，轻锤也可触发。传分经过、淬火、回火都不触发。敲别处则放弃旧临时格，随后照常刷新。额外变化不再触发留力、传力、聚料或其他临时效果。回流只交换数值，不移动效果、禁敲标记或计分区域；交换目标可以是0格、固定特殊格或禁敲格。

刷新位置从正数、未禁敲且不带固定效果的有效格中随机选，回流方向从紧邻有效格中随机选并提前显示。剩余锤数为0或没有合适位置时不再生成。淬火、回火保留当前标记，即使均化后该格变0，也要等下一次有效落锤才刷新。

预览包含当前临时效果的完整结算，不提前展示下一轮机会。随机状态保存在炉况内，预览、无效点击、热处理与查看卡片不会消耗随机状态；撤销恢复同一状态，相同操作重做得到相同机会，重试同一炉也复用随机序列。换炉重新抽取。标记、名称、交换方向和触发后的实际净变化都有显示。

## 六种独立触发特效

- 留力：绿色六角护罩、内层护环和向心光线，突出落点数值被保住。
- 传力：紫色双重冲击环、两轮电弧和传分光轨，配合更明显的局部震动。
- 聚料：青色颗粒向接收格汇聚，出现吸附旋涡与＋2提示。
- 余热：橙色火舌向上喷出，火星与热浪环配合落点＋2提示。
- 剥落：有效邻格发冷光、飞出碎片，显示实际减少的分数。
- 回流：两端紫/青色光环，双向弧线交换，显示交换后的实际净变化。

额外效果完成后，新临时格会短暂亮起。数值浮字统一读取操作前后的净变化，避免回流后仍显示普通传分的假加分。固定效果的＋2等说明提示单独显示。锤头、冲击波与升星特效继续保留；特效不锁输入、不改规则，活跃粒子数量有上限。撤销、重开和切换清理特效；减少动态效果模式使用短暂边框提示。

## 交互与解锁

选择锤法后，点一次格子就敲一次；悬停、聚焦和特殊格卡片只预览。方向键沿行列跳到下一个有效格，Enter/空格落锤。非法操作不扣次数，不自动换锤法。撤销恢复盘面、次数、特殊格使用状态、禁敲状态与收工状态。

六章共83件，同阶段交错安排剑刃、前端、钝击侧、完整手柄、跨部位部件。收工达到一星便解锁下一件，不强制三星通关；图鉴可按章节、目标类型查看，未解锁部件展示目标但不能进入。已解锁部件可重玩冲星。

最佳星级与当前部件保存在本浏览器独立的试玩记录中。最佳星级仅在收工时更新，撤销收工不撤回已保存的记录或解锁。各部件本炉状态在本次页面内存中保留，切换后返回可继续；刷新重新抽炉，但保留解锁和最佳星级。复制HTML到别的设备不会携带浏览器记录。存储不可用时仍可在本次页面内游玩，并显示未保存提示。

计分格保留亮金色背景、预览色和锁定纹理。沿用锤头、火星、冲击波、十字光束、传分浮字、热流与升星效果；表现层不修改规则、不阻止连点。撤销、换部件和重开清理动画；减少动态效果设置下简化为短暂边框提示。页面不展示参考解入口。

## H01回火直通修正

H01原本柄首21分、全盘29分，直接回火后柄首变为13分，已经低于旧三星上限14分，因此不下锤即可三星。属于初始分布与目标配合失当，回火均化算法不变。

本次将上部8个非计分格从1改为2；底端两行仍分别为4/4/4、3/3/3，柄首初始仍为21分。三星上限从14降到12。新盘面全盘37分，回火后柄首18分、完成度33%，淬火以及两种热处理的组合也都不获星。

回火后六个柄首格均为3分，选择三个不同格轻锤、避开当前临时机会，即可稳定降到12分。固定特殊格不影响轻锤，临时机会每次只有一格，始终有可选落点，因此三星不依赖有利随机效果。玩家仍可自行利用临时效果另找路线。64种炉况的搜索均找到三星路线，所找到路线使用2–4锤，并非严格最少锤数。
