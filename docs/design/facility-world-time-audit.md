# 设施等待与世界时间检查（2026-11-04）

本次检查正式 `index.html` 的两套界面。判定标准是：每个已结算的设施等待 tick 必须经过 `Survival.advanceTick`，令 `GameTime.totalTicks` 增加 1（游戏时间十分钟），并执行同一轮世界结算。现实计时器只决定何时请求下一刻，不能自行替代世界时间。

## 发现与修复

1. **仓库整备施工漏推进世界时间。** 原来的两秒回调只调用 `HideoutWarehouse.tickConstructionTask`，扣体力、减少剩余施工刻数并保存；世界时钟和其他世界系统都没有前进。两套界面可复现“施工剩余 10→9，时钟仍为 09:00”。共用面板现在每次成功施工后调用一次 `Survival.advanceTick({source:'warehouse_construction'})`，随后保存；未施工、体力不足、暂停不额外耗时。回调同时复核邻格、前哨模式、失能和睡眠／训练等行动锁，陈旧计时器不再继续扣费施工。
2. **无效生存 tick 仍进入后置结算。** `Survival` 在已死亡时会直接返回，旧世界包装层仍然减少烹饪／制药倒计时并调用其他世界系统。现在调用前检查死亡状态，调用后比对世界 tick；世界时间没有前进便直接返回，不触发生产、生长等后置结算。正常致死的最后一个已支付 tick 仍按既有顺序结算。

仓库保持原保存失败语义：停工并保留本次内存里的施工、体力与世界变化，重试保存后再继续，不单独退款或倒退其中一个计数。睡眠和健身沿用其整笔保存／失败回退逻辑。未改变各动作的现实等待时长、基础费用或产出。

## 正式入口核对

| 范围 | 计时与世界入口 | 检查结论 |
| --- | --- | --- |
| 仓库整备／升级施工 | 共用面板计时器 → 施工 → `Survival.advanceTick` | 本次补齐；两套 UI、时钟显示、存档、暂停、保存失败和离格均有回归 |
| 农场／牧场恢复清理 | `FacilityLabor.work` → `Survival.advanceTick` | 每次劳动一刻；不另加世界费用 |
| 缝纫设施与量具装配 | `FacilityUnlock.work` → `Survival.advanceTick` | 原施工刻数与世界时间一致 |
| 缝纫、研究、浸泡、改造、背包制作等 | iframe 使用主游戏 `SewingSystem.step` → `Survival.advanceTick` | 共用工作入口；正式测量工作及既有缝纫回归通过 |
| 铸造、原矿加工、研究、维修、装拆 | `ForgingSystem.step` → `Survival.advanceTick` | 共用付费工作入口；加工每步验证真实世界时间；锻造棋盘选择本身保持不耗时 |
| 烹饪各工艺、制药与配药 | 主游戏计时器 → `Survival.advanceTick` → `tickCraftAfterWorldTick` | 每一刻请求世界时间后减少制作剩余刻数；开始制作不跳过等待 |
| 农场手动等待、自动等待及场内施工 | `tickAgriculturePanelWorldOnce` → 世界入口 → 农业后置结算 | 农业 `state.tick` 镜像世界时间；施工只在面板开放且未暂停时前进 |
| 牧场自动等待与生产 | 牧场计时器 → 世界入口 → `LivestockState.advanceTick` | 牧场内部推进仅由正式世界后置结算调用 |
| 制肥发酵与窗口操作 | 世界后置结算 → `CompostSystem.onWorldTick`；操作经世界入口 | 随其他设施耗时共同发酵，不另设独立生产时钟 |
| 床铺睡眠、普通休息与调息 | `BedSleep`／主游戏休息计时器 → 世界入口 | 睡眠逐秒一刻、48刻；开始不提前推进，暂停／读档／保存回退与原规则一致 |
| 健身训练 | `GymSystem` 每组三秒一刻 → 世界入口 | 两刻一组；其他计时请求被锁定；实测跨午夜及存档回退 |
| 卫生间饮水、洗浴、水壶装水 | `BathroomFacility.use` 的世界 tick 循环 | 既有动作耗时均推进世界时间；中断和保存失败回归通过 |

地牢恢复点／资料台等交互另经 `DungeonRuntime.completeTick` → `advance` → 同一 `Survival.advanceTick`，未发现设施自增时间分支。钓鱼／狩猎的正式宿主也使用该入口。这里只核对其接线，不宣称重新验收全部地牢、钓鱼或狩猎玩法。

独立历史试玩与工具仿真不作为正式世界时间验收：例如书籍阅读原型按一秒发放演示经验，仍未接正式阅读；不借本次检查替它确定阅读耗时或部署正式功能。

- `npm run test:pharmacy`、`npm run test:compost`；铸造正式集成、缝纫、仓库、清理、设施解锁、户外设施、普通体力恢复与疲劳回归。
