# 注射统一配置：药品目录迭代

2026-09-10，已按用户确认落地生产目录调整。本文件覆盖此前固定注射药生产路线；其他未实施的制药重整仍属提案。

## 当前路线

| 路线 | 终点与用途 |
|---|---|
| 原料 → 药汤、丸片、药膏、药烟 | 保留固定配方，直接使用 |
| 原料 → 基础药粉 → 精制/精炼药粉 | 为玩家提供配置成分；已有加工阶梯保留 |
| 药粉 + 溶媒 + 可选助溶剂 → 配置注射液 | 注射唯一新生产入口；支持单方和复方，实例保存各成分及份数 |

固定工艺配方从 68 条减为 57 条，固定现役成品从 30 件减为 19 件（口服 10、外敷 6、吸入 3）。移除 11 条固定注射配方，不新增统一封装配方绕过动态配置。药效族和注射强度模板继续供配置系统使用，不随旧成品退役删除。

注射强度由实际投入、浓度、助溶及现有配置规则结算；不承诺用旧固定配方的两项原料就能完全复刻旧成品。单方也使用动态注射液模板，配好后可携带，使用时保留战斗门禁、静止与器具要求。续力保持直接负重增益与 120 tick 注射基础窗口。

## 兼容与范围

- 11 件旧注射物品标记 `pharmacy_legacy=1`，保留 ID 和既有使用行为以兼容库存与旧存档，不再从固定制药配方产出，也不列入当前参考表成品目录。
- 构建器拒绝启用的固定注射产物配方，防止后续重建把双入口带回来。
- 制药参考表展示现役药品、药粉完整加工路线、57 条固定配方及动态注射各药效档位。
- 既有配药图鉴仍是使用后的组合记录。本轮未实现持久化的命名配方收藏、一键复配或按药效自动命名；这些属于接下来的配置体验改进，不能把图鉴已有记录描述成这些功能已经完成。
- 成瘾数值及独立致瘾属性尚未重整。新生产注射液统一走已有动态配置结算；旧成品兼容使用也未借此改写成瘾规则。
- 复苏、止血等原有消费者缺口不因统一配置而自动完成，参考表继续标注。

## 验证

制药冒烟覆盖无固定注射配方、旧模板保留、精炼药粉链保留、单方续力生成动态实例并从成分重建药效、禁止旧注射成品再次投料，以及已有复方、浓度、助溶、成瘾与保存成分逻辑。参考表生成器独立回放所有展示加工路线，核对投入、产出和余料。
