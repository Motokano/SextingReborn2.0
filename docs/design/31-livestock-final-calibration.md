## 校准结果

同步旋转仍为每 1000 tick 一次，动物与机械臂同步、区域固定。玩家自行准备初始布局；持续经营不要求每轮手动迁移、播种。羊的高草禁食门槛保持 0.8 m，牛吃到 0.4 m，羊吃到 0.1 m。猪承担松土，鸡承担清污，草地自然再生。

生产采用当期营养账：维护、储备补充、营养损伤恢复、成长、奶蛋毛及孕期支出各自记账。储备只能维护生存。自动采血的损伤也需营养修复，诊疗与被动回血不能免费补回。满体重的中档动物不额外产奶蛋毛。

充足档目标统一为维护需求的 2 倍，进入阈值为 1.9 倍，配合 60 tick 平滑避免抖动。降低之前牛羊猪过高的充足档目标，减少维持同样产出所需的额外投料；仍须逐项支付真实生产预算。

## 关键配置

营养单位记为 N；1 标准饲料单位为 10 N。维护量与生态吞吐乘体重负载 max(0.25, sqrt(体重 / 参考体重))。实际草料供给、可食高度、健康与供料吞吐仍会限制结果。

| 物种 | 参考体重 / 育肥上限（kg） | 基础维护 N/tick | 自动繁殖默认上限 | 单件奶蛋毛支出 / 基准生产时间 |
|---|---:|---:|---:|---|
| 牛 | 150 / 600 | 0.3 | 8 | 奶 8 N / 432 tick |
| 羊 | 20 / 80 | 0.18 | 12 | 毛 12 N / 4000 tick |
| 猪 | 30 / 120 | 0.15 | 16 | 无 |
| 鸡 | 2.5 / 2.5 | 0.00556 | 不繁殖 | 蛋 0.12 N / 288 tick |

繁殖上限可在动物页调整为 0—100；0 暂停新受孕。整窝幼崽在受孕时预留名额，已受孕不会因调低上限被取消，已有动物不会被删除。上限用于避免无人管理时无限扩群，不保证该规模在任意布局下都能养活。

父母快照、每只幼崽的性别与独立遗传结果在受孕时固定。孕期营养按“初生体重 × 最大常规窝数 × 成长营养成本 × 10% / 孕期”计费，供给不足会延长孕期。出生体重从母体扣除，初始饱腹储备从母体转移，不凭空生成动物质量或储备。

| 装置 | Lv1 → Lv5 |
|---|---|
| 饲料槽容量 | 100 / 150 / 225 / 325 / 450 单位 |
| 饲料槽共享供料吞吐 | 0.25 / 0.4 / 0.6 / 0.85 / 1.2 单位/tick |
| 鸡笼容量 | 5 / 7 / 9 / 12 / 15 只，尸体占位直至清除 |
| 松土爪 | 每 tick 降低 0.002 / 0.003 / 0.004 / 0.005 / 0.006 板结点 |
| 牧草管理臂 | 每 tick 降低 0.003 / 0.0045 / 0.006 / 0.008 / 0.01 板结点，另保留草地生长能力 |
| 清洁刷 | 每 1000 tick 最多清 1 / 1.5 / 2 / 2.5 / 3 污染点 |
| 拦粪网 | 本侧羊污染减少 10% / 15% / 20% / 25% / 30% |
| 诊疗臂 | 每 tick 服务 2 / 3 / 4 / 5 / 6 只，各恢复 0.01 / 0.02 / 0.03 / 0.05 / 0.08 HP |
| 屠宰轴心 | 肉回收系数 1 / 1.025 / 1.05 / 1.075 / 1.1，仍受总质量约束 |
| 仓储枢纽 | 50 / 80 / 120 / 160 / 200 件 |

满重猪每 tick 可降低 0.09 板结点，满重鸡每 tick 最多清 0.007 污染点。上述机械维护量按有效覆盖区结算，鸡的清污量在相邻两区共享；不能将装置覆盖次数当作额外鸡群吞吐。机械维护保留辅助意义，堆叠仍有槽位与大型设备电耗成本。

全部等级效果来自模块 JSON，升级不丢失既有能力；0 容量及 0 概率不会被默认值覆盖。自动采集重叠取最佳效果，单侧播种机、拦粪网、饲料槽只服务实际朝向。诊疗按伤势及轮候次序统一分配，每只动物每 tick 最多占一次诊疗名额。

普通拆卸退还建设、已完成升级及已支付的在建升级材料；饲料小数、加工中余量、排队原料和产物转入暂存，按原状态恢复一次。暂存最多 32 条资源记录，满额时拆卸整次失败；背包满时领取材料保留剩余。转回容量不足也不会部分转入。

联动作业臂、废热回收臂、气候调控塔继续下架；保留诊疗、精加工、牧草管理和仓储。新高级机制另行设计。

## 屠宰

牛羊猪需要轴心屠宰模块，鸡使用所属鸡笼；均不因手动屠宰扣电或要求搬运。年龄不直接禁止屠宰，必须达到能产出至少一件固定规格主肉的有效体重，过小幼崽没有产出资格。

健康系数为 0.2 + 0.8 × HP/100，连续作用于肉、内脏及皮骨预算。哺乳类基础质量占比分别为 50% / 8% / 12%；鸡为 60% / 16% / 16%，确保现有各类固定规格鸡肉、内脏与皮骨在健康满重时都能产出。品质和回收加成可能提高肉预算，但总预算始终归一到体重以内。主肉先按固定部位比例分配，再向下取整，不把每种肉都按整只动物重复结算。

## 验证证据

运行入口：npm run test:livestock；长期审计：npm run audit:livestock-final。原始结果在 [livestock-final-calibration.json](../reference/livestock-final-calibration.json)。

64 项畜牧回归检查及 3 组供电/投电检查通过。屠宰测试扫描 4 物种 × 3 类产肉 Perk × 6 个健康点 × 100 档体重，共 7200 组，检查固定规格、总质量守恒与健康连续性；另验证全部配置部位在健康满重时可达。

七组轮牧对照各 12000 tick，共 84000 tick。分区/混养使用相同 2 牛、2 羊、2 猪、5 鸡、同样槽位设备和原始满草开局。外部补料按实际消费计量：

| 情形 | 饲料单位 | 奶 / 毛 / 蛋 | 死亡 | 人工处理 |
|---|---:|---|---:|---|
| 分区 | 3301.59 | 54 / 4 / 205 | 0 | 0 |
| 混养 | 4543.06 | 54 / 4 / 205 | 0 | 0 |
| 无猪 | 3338.30 | 54 / 4 / 205 | 0 | 0 |
| 无猪、人工松土 | 439.28 | 54 / 4 / 205 | 0 | 226 次松土 |
| 无鸡、不清污 | 2472.63 | 32 / 2 / — | 6 | 0 |
| 无鸡、人工清污 | 3301.58 | 54 / 4 / — | 0 | 32 次清污 |
| 失衡地块恢复 | 3360.19 | 54 / 4 / 205 | 0 | 开头 1000 tick 内 44 次松土、26 次清污 |

等产出分区比混养节省 27.33% 外部饲料，差异来自草层和生态作用，没有独立“混养惩罚”。无猪人工松土组少了猪的饲养成本且付出持续劳动，其低饲料消耗不能当成无代价优势。无鸡死亡组消耗变少也不能当成效率提高。猪仍是自动松土的默认选择，允许玩家以持续人工或外部饲料承担不养猪的取舍。

合计 228000 tick、4650770 次动物营养账检查，最大账目误差小于 10⁻¹⁵ N；没有通过关闭寿命、重置健康或无限复制饲料来隐藏支出。补料作为外部输入累计，鸡的替换次数和屠宰操作也显式记录。

这些结果证明当前配置在上述对照和长期经营条件下可运行，并覆盖已发现的质量、营养、遗传、容量及重复结算漏洞，不等于穷举所有布局。种田产量、商人定价及狩猎概率不在这套模型内；现已提供带容量检查的动物补入接口，具体获取渠道后续接入。长期组需要批次补鸡，不代表永久无人照料的自动牧场。
