### 0. 硬性视觉约束（必须逐条遵守）

1. **与背包 UI、战斗技能 UI、农业面板保持同一套主题色与结构**——不得另起配色宇宙（禁止赛博霓虹、高饱和渐变墙、玻璃拟态泛滥、明亮田园/牧场插画风）。
2. **文本呈现为主**：信息密度偏高、可读性优先；装饰克制；用字重/间距/边框区分层级，而非大面积插画。
3. 面板气质：**暗褐炭底 + 暖金强调 + 琥珀橙选中态**；边框 **2px**、圆角 **8～10px**；卡片 **2px `#4d4d45` 描边**。
4. 字体：中文主界面 **Microsoft YaHei / PingFang SC**；标题区可混 **Noto Serif SC**（与战斗技能面板一致）。
5. 禁止：过度花哨装饰、强发光霓虹、与下列色板无关的「第三套主色」。

### 2. 产品背景（给交互用）

牧场是一座**大型十字型机械装置**，将范围分隔为 **4 个同质区域（Z1 左上 / Z2 右上 / Z3 右下 / Z4 左下）**，由 **4 根机械臂**（一号·上、二号·右、三号·下、四号·左）+ **1 根轴心柱**组成。**每 1000 tick（约 7 游戏天）装置顺时针旋转 90°**，动物随旋转**顺时针迁区**（Z1→Z2→Z3→Z4→Z1），旋转节奏玩家不可控制。

- **玩家可手动**：选择动物放入哪个区、跨区迁移动物、在臂/轴心上装配与升级模块、采集活体产物（挤奶/剪毛/抽血/收蛋）、屠宰、喂食、清扫、松土。
- **动物**：牛（水牛）/ 羊 / 猪 / 鸡，按**单只个体**管理，有性别、体重、饱腹、血量、怀孕、Perk 特质、产出冷却。
- **模块**：19 个，分第一层/第二层/轴心，装在臂的 5 个外侧面 + 内部空间、轴心 2 个位（位1 屠宰默认已装、位2 二选一）。占面与互斥规则见功能正本。
- **生态变量（每区）**：草高（0–1.5m）、土壤板结度（0–100）、污染度（0–100%）。**随畜牧技能等级，先解锁「阶段」，再解锁「精确数值」**（信息分级，见 §5）。

### 3. 必须设计的界面与状态

请产出 **静态高保真 mockup**（1920×1080 画布内嵌面板）+ **组件说明**，覆盖下列 **全部** 视图。

#### 3.1 主面板骨架（四个 Tab）

面板顶部为主 Tab（同 `.combat-main-tab`，active 橙下划线）：**总览 · 动物 · 模块 · 产出**。四个 Tab 共用 Header/Footer，中间内容区随 Tab 切换。

```
┌──────────────────────────────────────────────────────────────┐
│ Header: 标题「牧场」| 旋转倒计时「下次旋转 862 tick」| 畜牧 Lv.XX | ✕ │
├─────────┬────────────────────────────────────────────────────┤
│ 左轨     │  内容区（随 Tab 变化）                                │
│ (Tab/筛选)│  （总览=装置俯视图；动物=列表；模块=装配；产出=采集）  │
├─────────┴────────────────────────────────────────────────────┤
│ Footer: 9px 大写 hint（如「旋转不可控 · 动物随顺时针迁移」）      │
└──────────────────────────────────────────────────────────────┘
```

#### 3.2 Tab 1 · 总览（装置俯视图，**本面板的核心特色**）

**中央为十字装置俯视示意图**（非写实插画，是**结构示意**：线条 + 卡片）：

- **四象限 = 四区域**（Z1 左上 / Z2 右上 / Z3 右下 / Z4 左下），区域用 `#252520` 底 + `#4d4d45` 边。
- **四臂**从中心伸出（上/右/下/左），每臂标注**编号**（一号…四号）+ 已装模块的**小图标槽**（如鸡笼🐔、饲料槽、喷头等，用线条 icon，勿用写实）。
- **轴心**在中心：位1 屠宰模块（默认）+ 位2（仓储枢纽 / 气候塔，二选一或空）。
- **动物分布**：每个区域内用**物种线条 icon + ×数量**（如「🐄×2」），选中态橙边。**动物 icon 用物种辅助色**（面积 <5%）：牛=暖褐、羊=米白、猪=粉褐、鸡=土黄；线条统一描边 `#d3a060`。
- **生态模糊色（关键，随等级可见性）**：每个区域叠加一层**半透明生态色块/纹理**表示阶段（不显示数字，数字在详情/高等级才显示）：
  - 草高：绿深浅（秃=`#3a342e` 土色 → 茂盛=深绿 `rgba(90,140,70,0.28)`）；
  - 污染：污渍色（干净=无色 → 严重=`rgba(60,40,30,0.45)` 深褐斑）；
  - 板结：龟裂纹理（疏松=无 → 板结=细裂纹描边，`rgba(0,0,0,0.35)` 细线）。
  - 若畜牧等级**低于对应解锁阈值**，则该生态层**不可见**（完全无提示），仅动物状态暗示。
- **旋转方向指示**：轴心旁一个**顺时针弯箭头**（`#d3a060`）+ 「下次旋转 {n} tick」倒计时徽章（`#1a1512` 底、金边）。
- **点击交互**：点区域 → 右侧/浮层出「区域详情」（该区动物列表 + 生态阶段/数值）；点臂 → 「臂详情」（占面 + 已装模块）；点动物 icon → 跳动物 Tab 该个体。

#### 3.3 Tab 2 · 动物（列表 + 详情，三栏）

- **左轨**：物种筛选（全部 / 牛 / 羊 / 猪 / 鸡）+ 状态筛选（健康 / 患病 / 怀孕 / 幼体）。
- **中列**：动物个体列表（行卡，参照背包 `.bp-item-row`），每行展示：
  - 物种 icon + 编号（如「牛 #03」）+ 性别（♂/♀，`#8e8e8e`）；
  - 年龄阶段（幼体/成年）、体重（kg，阶段：轻/正常/育肥）；
  - **饱腹 / 血量**（`#6b6560` 阶段文字 → 等级解锁后显示数字，`#e0d7c6`）；
  - **怀孕标签**（`#ff8c00` 小徽章，仅畜牧 ≥30 级可见）；
  - **Perk**（`#8e8e8e` 无提示 → ≥50 级显示 Perk 名 → ≥90 级显示名+数值）；
  - 所在区域（Z1–Z4 角标）。
- **右列详情**（选中个体）：完整状态数值、Perk 列表、产出冷却（奶/毛/血/蛋 剩余 tick）、**操作按钮**：迁移（弹区域选择）、采集（挤奶/剪毛/抽血，冷却好才亮）、屠宰。
- **信息分级**必须在同一套 UI 里体现「未解锁=隐藏或占位」，并**用弱 hint 说明「畜牧等级提升可解锁更多信息」**（一句即可，不喧宾夺主）。

#### 3.4 Tab 3 · 模块（装配 + 升级）

- **左半**：十字装置简化示意（同总览的臂/轴心结构），点臂 → 展开该臂的 **6 个模块位**（内部 / 前端面 / 底面 / 上表面 / 顺时针侧面 / 逆时针侧面）+ 轴心 2 位。
- **模块位**（参照 `.combat-limb-slot`）：`8px 圆角`、`2px` 边框、**空位虚线/弱字「空」**、已装则显示模块名 + Lv。**内部空间互斥**（只能装 1 个占内部模块）用视觉提示（如已占内部 → 其他占内部模块灰显）。
- **右半**：模块库列表（19 个，按 第一层/第二层/轴心 分组），每卡：名 + 体量（小型/中型/大型/轴心）+ 一句话能力 + 占面（`内/前/底/上/侧`）。选中后下方**装配按钮**。
- **升级子面板**（选中已装模块后）：Lv1–5 效果表（`.tooltip-module` 风格 kv 行）+ **升级材料清单**（物品名×数量）+ 工程 `{n} tick × 5 体力/tick` + **开始升级**主按钮 + 进度条（填充 `#d3a060`）。

#### 3.5 Tab 4 · 产出（采集 + 屠宰）

- **活体采集**：可采集动物列表（冷却完毕的奶/蛋/毛/血），行卡显示「产出 × 数量 + 冷却剩余」，右侧「采集」按钮（冷却中灰显 + 倒计时）。
- **屠宰**：动物列表 → 选中后右侧**产出预览**（主肉/器官/副产物分类列出，复用背包品质色条）+ 「屠宰」按钮（消耗体力/时间）。**血量 < 阈值**的抽血按钮灰显并 hint「血量不足」。
- **尸体**：待清理尸体列表（病死/饿死，标死因），「清理」按钮。

#### 3.6 空态与异常

- **无动物**：动物 Tab 空态 + 「通过狩猎捕捉幼崽 / 商人购买获得」弱文案（引导但不过度）。
- **旋转瞬间**：Header 倒计时归零时可给一个**极轻的顺时针旋转动画示意**（可选，非必须），不打断操作。
- **生态高危**（污染 > 90% 或板结 100，且等级已解锁可见时）：区域色块加强，但不引入红色警报体系（用橙/深褐加深即可）。

### 4. 交互说明（须在交付文档中写明）

| 操作 | 行为 |
|------|------|
| 点区域（总览） | 查看该区动物 + 生态（阶段或数值，按等级） |
| 点臂/轴心（总览/模块） | 展开模块位 |
| 点动物 | 选中 → 详情 + 操作按钮 |
| 迁移 | 弹区域选择（Z1–Z4 四选一）→ 动物移区 |
| 采集 | 冷却完毕才可点；抽血受血量下限约束 |
| 装配模块 | 从模块库选 → 装到空位（校验占面/互斥，非法灰显） |
| 升级模块 | 材料够才可点；进行中显示进度条 |
| 屠宰 | 二次确认弹窗（预览产出） |

### 5. 信息分级（畜牧等级解锁，必须体现在 UI）

| 畜牧等级 | 解锁 |
|---------|------|
| < 10 | 仅动物阶段状态（饥饿/正常/饱足）；草高/板结/污染不可见 |
| 10 | 精确饱腹值 + 草高阶段 |
| 20 | 污染度阶段 |
| 30 | 怀孕标签 + 板结度阶段 |
| 40 | 草高精确值 |
| 50 | Perk 名 + 污染度精确值 |
| 60 | 板结度精确值 |
| 70 | 血量精确值 |
| 90 | 完整 Perk（名+数值） |

**要求**：设计须明确「每档信息在哪个组件、以什么形式出现（阶段文字 / 色块 / 精确数字）」，未解锁时如何隐藏或占位。
