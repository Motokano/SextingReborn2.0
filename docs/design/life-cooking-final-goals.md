## 烹饪技能：最终目标（终局料理生产线）

> 本文档用于把终局料理拆分为：原材料（Raw）→ 关键中间产物（Intermediates，粗粒度）→ 成品（Final），并按来源技能归类，作为烹饪技能的“最终目标”设计底稿。
>
> 约定：
> - **Raw**：直接采集/狩猎/种植/畜牧/挖矿/伐木获得的材料。
> - **Intermediates**：可作为“关键节点”的中间件（如：高汤、香料粉、酱汁基底、面条/薄饼组件、腌料等）；本稿采用粗粒度（每菜约 5～12 个）。
> - **Final**：成品料理或终局可交付成品。

### 统一命名词表（原材料）
> 目的：与 `data/items/materials_all.csv`（烹饪原料行）的 **`sn` 列**一致；同一原材料在正文只保留一种标准写法；别名与合并口径集中记在本节。

- **海盐**：标准名 `海盐`；若强调颗粒/浸泡强度，写作 `海盐（粗粒）`（对应物品表粗粒海盐条目）。
- **纯净软水**：物品表 `sn` 即此名；旧稿「矿泉水」「纯净水（软水）」一律并入 **纯净软水**（高汤、泡发、清洗等软水场景）。
- **猪板油 / 猪油**：**猪板油**为生肥膘原料；**猪油**为炼制成品油脂（二者在表中为不同 `sn`），勿混用同一词指代两者。
- **肥鸭腿 / 纯鸭油 / 油封鸭腿**：**肥鸭腿**、**纯鸭油**为 Raw；**油封鸭腿**为 Intermediate（Confit 成品工艺名，原料层仍写肥鸭腿 + 纯鸭油）。
- **家鸡 / 家猪（生物）**：表内无统称行；文档改写为具体 `sn`（如 **鸡肉**、**鸡骨**、**老母鸡**、**猪板油**、**猪蹄** 等），野猪等所获肥膘与畜牧猪板油合并为 **猪板油** 一条口径。
- **鸭（整禽）**：标准名 `鸭`；不写「完整鸭」等无 `sn` 支撑词；脱骨填馅语境仍称 **鸭**。
- **澄清黄油（Ghee）**：标准名 `澄清黄油（Ghee）`（含“酥油”写法统一到此）；若为摩洛哥发酵版本，写作 `发酵澄清黄油（Smen）`。
- **藏红花**：原材料统一写作 `藏红花`；中间产物统一写作 `藏红花浸液（Saffron Infusion）`（不再区分“浓缩液/浓缩汤”命名）。
- **白萝卜（white radish）**：标准名 `白萝卜`；物品 `id` **`herb_radish_white`**。工艺名「面取」等可保留括号说明，英文统一 **white radish**，不再用日语借词路径写食材名。
- **茴香 / 小茴香子**：叶/植株用途 **茴香**，`id` **`herb_fennel`**；种子 **小茴香子**，`id` **`herb_fennel_seed`**（同一植物不同部位，勿混用）。
- **白砂糖**：默认糖类，物品 `id` **`herb_sugar_white`**。正文泛称「糖」且无特殊说明时指 **白砂糖**；甘蔗粗糖（Piloncillo）、红糖、糖浆等须在句内显式写出。

### 料理线设计准则（以后所有料理线都按这个写）

#### 命名与口径
- **同物同名**：同一种原材料/中间产物在全文只允许一个标准名；别名只作为括号补充（例如 `澄清黄油（Ghee）`、`发酵澄清黄油（Smen）`）。  
- **Raw / Intermediate / Final 分层固定**：Raw 只写“直接获得”；Intermediate 只写“关键节点半成品”；Final 只写“可交付成品/料理本体”。  
- **时间相关必须显式**：凡是 `24h`、`3–5 天`、`数周陈化` 这类节点，必须写进对应的 Intermediate 条目（用于后续做“等待/计划性”玩法）。  

#### 技能归类规则
- **一条线只归一个来源技能**：每个 Raw 项只归到一个技能分类（挖矿/伐木/采集/种植/狩猎/捕捞钓鱼/畜牧）；不要出现同一项跨技能重复记。  
- **捕捞/钓鱼合并、狩猎独立**：水产统一进 `捕捞/钓鱼`；陆生野味与野外部位统一进 `狩猎`。  
- **“加工占位”必须标注**：暂时没落到技能或工作台的材料（如糖粉、白葡萄酒、橄榄油、面包屑、木鱼花加工等），统一写作“加工占位”，后续落表时再决定进烹饪/制造/贸易/专用工作台。  

#### 中间产物设计规则
- **优先抽象“可复用模块”**：能跨菜复用的中间产物（高汤、浸液、香料粉、发酵物、面皮、鱼浆等）优先设计成通用模块，避免每道菜各写一套同义词。  
- **明确失败产物/降级后果**：凡是高难节点（乳化、温控、脱骨、撇沫、去味浸泡），必须给出失败结果（如油水分离、浑汤、破损皮袋、焦黑残渣、异味沾染等），便于后续做品质与惩罚。  
- **“溶剂/载体”要点明**：如果某道菜靠“溶剂”驱动（如金汤/出汁/澄清黄油/椰浆），必须在 Intermediate 里点出它的定位（萃香/承载/上色/稀释/锁水）。  

#### 表达与可落表性
- **Raw 列表尽量可落物品表**：优先使用名词短语，避免把工艺写进 Raw；工艺写在 Intermediate 的“工艺要点”。  
- **Final 只保留 1 个主名**：料理最终产物只写一个展示名（中英名可括号），不要在 Final 里再分叉多个近义成品。

## 1. 墨西哥莫雷酱（Mole Poblano）

### 定位
- **类型**：复合酱汁 / 终局调味巅峰
- **核心关键词**：辣椒、巧克力、坚果、烟熏、长时炖煮、厚重油脂感

### 原材料（Raw｜按来源技能） 
- **挖矿**：海盐、石灰石
- **伐木**：肉桂皮、橡木/果木（柴火）
- **采集**：野山椒（用于制干辣椒）、牛至、百里香、月桂叶、可可果、香草荚
- **狩猎**：火鸡肉
- **种植**：玉米、番茄、绿番茄、大蕉、杏仁、花生、芝麻、南瓜籽、甘蔗（莫雷酱若用粗糖须显式写粗砂糖/红糖；默认甜味校色用白砂糖）
- **畜牧**：鸡肉、鸡骨、猪板油、猪蹄

### 关键中间产物（Intermediates｜粗粒度）
- **提炼猪油（Rendered Lard）**
  - 来自：猪板油（畜牧；狩猎野猪等所获肥膘与畜牧猪板油同一物品口径）
- **浓缩金汤/浓缩鸡高汤（Concentrated Chicken Stock）**
  - 来自：老母鸡、鸡骨、猪蹄、香料包、水（畜牧 + 采集 + 伐木供火）
- **石磨巧克力砖（Table Chocolate）**
  - 来自：可可豆、粗砂糖/红糖块（由甘蔗提炼）、肉桂粉、香草荚（采集 + 种植 + 伐木）
- **混合辣椒泥（Chili Paste）**
  - 来自：干辣椒（野山椒制干）、猪油、高汤（采集 + 猪油 + 高汤）
- **碱处理玉米团（Nixtamal Masa）**
  - 来自：干玉米、石灰石、水（种植 + 挖矿）
- **脱水玉米饼（Stale Tortillas）**
  - 来自：玉米团 + 火（伐木供火），烙饼后脱水（作为增稠组件前置）
- **炸香料坚果粉（Nut & Spice Medley）**
  - 来自：坚果 + 复合香料（种植/采集/伐木），经炸/烤后研磨
- **火烤蔬果浆（Charred Veggie Puree）**
  - 来自：番茄、绿番茄、蒜、洋葱、大蕉（炸）、葡萄干（来源占位：种植、贸易、加工），果木火烤（种植 + 伐木）

### 成品（Final）
- **墨西哥莫雷酱（Mole Poblano）**
  - 组装逻辑（粗粒度）：猪油承载风味 → 辣椒泥/坚果香料粉/巧克力砖/蔬果浆融合 → 以浓缩高汤调稀并长时炖煮 → 海盐校味 → 作为火鸡/禽肉等主菜的终局酱汁

### 可复用中间产物（跨菜通用候选）
- **提炼猪油**（通用油脂）
- **浓缩鸡高汤**（通用高汤底）
- **复合香料粉/坚果香料粉**（通用“香料混合物”系列）
- **火烤蔬果浆**（通用“烤蔬菜基底”系列）

### 定位
- **类型**：香料体系巅峰 / 复合咖喱酱汁
- **核心关键词**：高温油脂萃香、干粉香料包、湿酱长炒（Bhoona）、乳酸平衡

### 原材料（Raw｜按来源技能）
- **挖矿**：岩盐、黑盐
- **伐木**：肉桂皮（桂皮/决明皮类 Cassia Bark）、木屑（用于宫廷烟熏 Dhungar 燃料）
- **采集**：绿豆蔻、黑豆蔻、肉豆蔻、豆蔻皮（Nutmeg/Mace）、丁香、咖喱叶
- **狩猎**：鹿肉、野猪肉（Jungli Maas 支线可用的主肉）
- **种植**：姜黄、孜然、芫荽子、小茴香子、藏红花、洋葱、大蒜、生姜、克什米尔辣椒
- **畜牧**：水牛奶（制澄清黄油/酸奶）、羊肉、鸡肉（主肉蛋白）

### 关键中间产物（Intermediates｜粗粒度）
- **澄清黄油（Ghee）**
  - 来自：水牛奶 → 黄油 → 澄清黄油（畜牧）
  - 定位：高温“脂溶性萃取介质”
- **玛莎拉干粉（Garam Masala Powder）**
  - 来自：肉桂、肉豆蔻、豆蔻皮、绿豆蔻、黑豆蔻、丁香、孜然（按配方自采集、种植、伐木渠道获得）
  - 工艺要点：先烘焙（Toasting）后研磨；过火副产物为“焦黑残渣”（失败产物占位）
- **基础湿酱（Wet Masala Base）**
  - 来自：洋葱泥 + 生姜泥 + 大蒜泥 + 辣椒粉（种植）
  - 工艺要点：用澄清黄油长炒（Bhoona）到“褐化出油”
- **凝乳/酸奶（Curd/Yogurt）**
  - 来自：鲜奶 + 菌种 + 时间（畜牧）
  - 定位：酸度平衡、后期柔化肉纤维、压辣
- **（可选高级工序）木屑烟熏香（Dhungar Smoke Infusion）**
  - 来自：木屑（伐木）
  - 定位：宫廷级风味加成节点
- **（可选稀有加成）藏红花浸液（Saffron Infusion）**
  - 来自：藏红花 + 温水/乳（种植+畜牧）
  - 定位：颜色与顶级香气加成

### 成品（Final）
- **正宗玛莎拉咖喱（Authentic Curry）**
  - 组装逻辑（粗粒度）：澄清黄油萃香 → 干粉定调 → 湿酱塑形（粘稠度/“肉体”）→ 加入主肉（羊肉、鸡肉或丛林猎物）炖煮 → 后段酸奶、凝乳收口平衡 → 岩盐、黑盐校味 →（可选）木屑烟熏与藏红花终饰

### 可复用中间产物（跨菜通用候选）
- **澄清黄油（Ghee）**（通用高温油脂）
- **玛莎拉干粉**（通用“香料混合粉”体系）
- **基础湿酱（Bhoona 基底）**（通用“深炒葱蒜姜基底”）
- **酸奶/凝乳**（通用“酸度平衡与嫩化”组件）

## 3. 南洋娘惹叻沙（Nyonya Laksa）

### 定位
- **类型**：椰浆海鲜汤面 / 南洋复杂汤面
- **核心关键词**：椰浆、虾膏、香料糊、海鲜汤底、重口味鲜香

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐、石灰水（处理粗米粉/面条口感）
- **伐木**：椰子（取椰肉/椰水）、橡胶木/果木（长时文火燃料）
- **采集**：火炬姜花、叻沙叶、蓝姜、姜黄、香茅、石栗（Candlenut）
- **捕捞/钓鱼**：血蚶、海虾、小虾（虾膏与虾油来源）、鲣鱼；鲂鱼；白身鱼（任一）
- **种植**：红葱头 & 大蒜、大米（制叻沙面条）、黄瓜 & 豆芽、红辣椒
- **畜牧**：鸡蛋

### 关键中间产物（Intermediates｜粗粒度）
- **辣椒糊（Rempah）—— 核心香料模板**
  - 来自：红葱头、大蒜、蓝姜、黄姜、香茅、石栗、干辣椒、虾膏
  - 工艺：在研磨台磨成细腻香料泥，可复用到多种南洋料理
- **发酵虾膏（Belacan）—— 鲜味炸弹**
  - 来自：小虾（捕捞/狩猎）+ 海盐
  - 工艺：发酵桶中长时间日晒与微生物分解，带强烈异味 buff
- **鲜榨椰浆（Santan）—— 液体黄金**
  - 来自：椰子肉 + 纯净软水（伐木 + 挖矿水源）
  - 特性：高度易腐，需现榨现用的限时消耗品
- **浓缩虾头油（Prawn Oil）—— 汤底之魂**
  - 来自：虾头、虾壳（捕捞副产物）+ 猪油/植物油（油脂来源占位）
  - 工艺：小火煎炸至油脂变红，形成叻沙表层红油与核心鲜味

### 成品（Final）
- **南洋娘惹叻沙（Nyonya Laksa）**
  - 组装逻辑（粗粒度）：发酵虾膏 + 辣椒糊炒香 → 加入浓缩虾头油与鲜榨椰浆熬汤 → 以石灰水处理的大米粉制成的面条为载体 → 血蚶、鱼饼、白水蛋、黄瓜与豆芽入碗 → 火炬姜花与叻沙叶点睛调香

### 可复用中间产物（跨菜通用候选）
- **辣椒糊（Rempah）**（通用南洋香料泥模板）
- **发酵虾膏（Belacan）**（通用海鲜发酵增鲜组件）
- **鲜榨椰浆（Santan）**（通用椰浆基底）
- **浓缩虾头油（Prawn Oil）**（通用海鲜红油/鲜味油）

## 4. 佛跳墙（Buddha Jumps Over the Wall）

### 定位
- **类型**：中式坛烧海陆珍馐 / 史诗级干货转化料理
- **核心关键词**：干货深度泡发、多重底汤复合、长时微火坛烧、药膳增益

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐、纯净软水（高汤基底/清洗）、陶土（制作“绍兴酒坛”容器）
- **伐木**：果木炭（橄榄木/橙木/苹果木任一烧制，持续 10 小时以上微火；统一不区分具体果木）、桂皮（基础去腥香料）
- **种植**：八角（基础去腥香料）、老姜 & 大葱（焯水去腥消耗品）、糯米、小麦（酿酒原料）
- **采集**：花椒（基础去腥香料）、荷叶（封坛与清香）、花菇 & 冬笋（山珍干货）、人参 & 枸杞（药膳与最终 buff 核心）
- **狩猎/捕捞（深海）**：鲍鱼 / 海参 / 鱼唇（核心深海食材）、干贝、鱼胶（海洋珍品）
- **畜牧**：老母鸡、鸭（汤底鲜味）；猪蹄、猪肚、猪蹄筋（胶原增稠）；金华火腿（发酵咸鲜底味）；鸽蛋、鹌鹑蛋

### 关键中间产物（Intermediates｜粗粒度）
- **泡发干货组（Rehydrated Treasures）**
  - 来自：原始海产（海参/鲍鱼/鱼唇等）+ 纯净软水 + 时间
  - 工艺要点：泡发池中多日泡发/冷热交替；部分需用鸡汤反复煨煮
- **“三元”浓缩金汤（The Golden Broth）**
  - 来自：老母鸡、鸭、猪蹄、猪骨、火腿（畜牧）
  - 工艺要点：冲汤去沫 → 小火慢熬 8 小时以上至金黄粘稠；作为“溶剂”承载一切名贵食材
- **陈年绍兴黄酒（Aged Shaoxing Wine）**
  - 来自：糯米、麦曲、鉴湖水（原料占位：种植 + 水源）
  - 工艺要点：发酵坛封存陈化；定位为“激香介质”，成品不再额外加水
- **虎皮炸蛋（Deep-Fried Eggs）**
  - 来自：家鸡蛋 / 鸽蛋 / 鹌鹑蛋 + 猪油
  - 工艺要点：煮熟去壳 → 油炸至金黄起皱以便吸汤

### 成品（Final）
- **佛跳墙（Buddha Jumps Over the Wall）**
  - 组装逻辑（粗粒度）：泡发干货组 + 三元浓缩金汤 + 陈年黄酒入坛 → 荷叶封坛 → 果木炭长时微火坛烧 → 出坛前以盐与香料校味，药膳（人参/枸杞）决定最终增益定位

### 可复用中间产物（跨菜通用候选）
- **泡发干货组**（通用“干货泡发/等待”生产线模板）
- **浓缩金汤**（通用顶级复合高汤模板）
- **陈年黄酒**（通用发酵酒基底/激香介质）
- **虎皮炸蛋**（通用“吸汤蛋白配件”）

## 5. 法式马赛鱼汤（Bouillabaisse）

### 定位
- **类型**：地中海海鲜浓汤 / 高阶复合汤底料理
- **核心关键词**：先熬鱼骨汁再煮整鱼、藏红花金汤、乳化火候、Rouille 蘸酱联动 buff

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐（基础调味；亦用于腌制海鲜副产物）
- **伐木**：橄榄木（大火快煮与乳化关键火力）、软木塞（封装搭配用白葡萄酒）
- **采集**：藏红花（昂贵香料与金色汤头来源）、茴香（`herb_fennel`，去腥清凉香）、干橙皮（果香平衡鱼脂）
- **狩猎/捕捞**：蝎子鱼（Rascasse，核心入场券）、海鳗/鮟鱇鱼/鲂鱼等（至少 5～7 种鱼）、蜘蛛蟹/贻贝（增鲜维度）、鱼头、鱼骨、虾壳（用于熬鱼骨汁的副产物）
- **种植**：大蒜 & 韭葱（Leeks，基础香味蔬菜）、番茄（红色与酸度）、土豆（吸汁配菜）、辣椒（Cayenne，用于 Rouille）
- **畜牧/加工占位**：蛋黄（Rouille 乳化核心）、橄榄油（来自种植但需压榨加工，定位为精炼烹饪油脂）

### 关键中间产物（Intermediates｜粗粒度）
- **基础鱼骨汁（Fumet de Poisson）**
  - 来自：鱼头、鱼骨、虾壳、韭葱、洋葱、水（狩猎/捕捞 + 种植）
  - 工艺要点：先“粉碎/破碎”非核心鱼块与壳类副产物 → 慢熬出白色浓缩底液；决定汤底底色与等级
- **藏红花浸液（Saffron Infusion）**
  - 来自：藏红花 + 白葡萄酒（或温水）（采集 + 贸易/加工占位）
  - 工艺要点：提前数小时浸泡，浸液入锅才能快速出金橙色
- **辣味蛋黄酱（Rouille Sauce）—— 灵魂伴侣**
  - 来自：蛋黄、大蒜泥、橄榄油、辣椒粉、海盐、少许鱼汤（畜牧 + 种植 + 挖矿 + 鱼汤）
  - 工艺要点：高难搅拌乳化；失败则油水分离
- **大蒜面包片（Garlic Croutons）**
  - 来自：法棍面包 + 大蒜（面包来源占位：烹饪/加工链），烤至坚硬后以生蒜摩擦表面

### 成品（Final）
- **法式马赛鱼汤（Bouillabaisse）**
  - 组装逻辑（粗粒度）：先以鱼骨汁做“蓝图汤底” → 叠加番茄与香味蔬菜形成红汤基底 → 藏红花浸液上色增香 → 大火快煮下投整块鱼与壳类，靠橄榄木火力促乳化 → 土豆入锅吸汁 → 搭配 Rouille 与蒜香面包片触发高阶恢复/环境 buff

### 可复用中间产物（跨菜通用候选）
- **基础鱼骨汁**（通用海鲜汤底“蓝图”）
- **藏红花浸液**（通用顶级上色增香组件）
- **Rouille（乳化蘸酱）**（通用“高难乳化酱”模板）
- **蒜香面包片**（通用汤品配件）

## 6. 西班牙瓦伦西亚合锦饭（Paella Mixta）

### 定位
- **类型**：西班牙大锅饭 / 陆海合锦
- **核心关键词**：Sofrito 底酱、粳米吸汁、果木火香、藏红花唤醒、锅底焦香（Socarrat 占位）

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐（调味与煎制海鲜提鲜）、铁矿、铸铁（打造平底大锅 Paella Pan 的材料）
- **伐木**：橙木（传统果木火香）

- **预处理大白芸豆**
  - 来自：大白芸豆 + 纯净软水（种植 + 挖矿）
  - 工艺要点：12 小时泡发（时间管理节点）

### 成品（Final）
- **西班牙瓦伦西亚合锦饭（Paella Mixta）**
  - 组装逻辑（粗粒度）：平底锅中先成 Sofrito → 加入米与藏红花浸液/复合高汤控水吸汁（高汤为中间产物，原料来自鸡骨、海鲜残余等）→ 陆味（鸡/兔）与海味（虾/鱿鱼/青口贝）分段下锅 → 豆类与田螺补足口感与鲜味 → 橙木大火收汁形成锅底焦香（Socarrat 作为高阶成功判定占位）→ 迷迭香末段点香

### 可复用中间产物（跨菜通用候选）
- **Sofrito**（通用西式红酱基底）
- **藏红花浸液（Saffron Infusion）**（通用“唤醒藏红花”组件）
- **预泡豆类**（通用“豆类泡发/等待”模板）

## 7. 阿塞拜疆皇冠抓饭（Shah Plov）

### 定位
- **类型**：宫廷抓饭 / “饭中之王”
- **核心关键词**：半熟米控火、藏红花染色、澄清黄油溶剂、Lavash 外壳成“皇冠”

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐（煮饭盐水与调味）
- **伐木**：木炭（稳定高温让外壳均匀变脆）
- **采集**：藏红花、酸梅（干梅/梅干，占位为脱水加工）、山核桃
- **狩猎**：羊肉（岩羊等来源并入羊肉物品口径；羊腿、肉块）
- **种植**：长粒香米、杏干 & 葡萄干（果树 + 脱水加工占位）、洋葱、小麦（面粉原料）、板栗
- **畜牧**：澄清黄油（Yag/Ghee，消耗巨大）、酸奶、鸡蛋

### 关键中间产物（Intermediates｜粗粒度）
- **澄清黄油（Ghee/Yag）—— 高级溶剂**
  - 来自：羊奶或牛奶 → 黄油 → 澄清黄油（畜牧）
  - 工艺要点：加热去除乳固体，仅保留高纯脂肪；用于承载并均匀扩散藏红花色香
- **半熟黄金米（Parboiled Saffron Rice）**
  - 来自：长粒香米 + 藏红花浸液 + 海盐（种植 + 采集 + 挖矿）
  - 工艺要点：煮至六七分熟，精准计时；过头会碎，不够有硬芯
- **拉瓦什面皮/皇冠外壳（Lavash/Kazmag）**
  - 来自：小麦粉 + 酸奶 + 鸡蛋 + 澄清黄油（种植 + 畜牧）
  - 工艺要点：揉面台擀至极薄且有韧性；作为“皇冠骨架”锁水锁香并形成外壳脆层
- **干果肉类混合物（The Stuffing）**
  - 来自：羊肉块 + 炸洋葱 + 板栗 + 杏干 + 葡萄干（狩猎 + 种植 + 采集）
  - 工艺要点：黄油煎封羊肉后与干果混合，形成甜咸油脂馅心

### 成品（Final）
- **阿塞拜疆皇冠抓饭（Shah Plov）**
  - 组装逻辑（粗粒度）：Lavash 铺锅成壳 → 入半熟黄金米与馅心分层 → 大量澄清黄油浇淋并高温烘烤/焖烤 → 外壳成“皇冠”酥脆、内里米粒分明金黄

## 8. 三鸟转（Turducken）

### 定位
- **类型**：多层填馅整禽料理 / 结构转换型终局烤物

- **克里奥尔复合香粉（Creole Seasoning）**
  - 来自：红辣椒粉、大蒜粉、洋葱粉、黑胡椒、牛至、盐（种植/采集 + 挖矿）

## 10. 传统俄罗斯肉冻（Kholodets）

### 定位
- **类型**：天然胶冻冷盘 / 胶原物理料理
- **核心关键词**：长时去血浸泡、微火慢熬取胶、清汤撇沫、冷却凝固、蒜香冷调

  - 来自：煮烂的牛肉腱与蹄肉

### 成品（Final）
- **传统俄罗斯肉冻（Kholodets）**

  - 来自：牛骨 + 牛肉 + 烘烤洋葱/胡萝卜（畜牧 + 种植）
  - 工艺要点：炖煮至肉软汤浓；作为整锅红汤的基础溶剂

### 成品（Final）
- **传统罗宋汤（Borscht）**
  - 组装逻辑（粗粒度）：先成浓缩牛肉原汤 → 加入结构蔬菜与番茄慢炖 → 以甜菜发酵汁定酸并锁住深红色 → 关火前入萨洛大蒜泥点火 → 出锅点一勺酸奶油形成红白对比

## 14. 法式卡酥来砂锅（Cassoulet）

### 定位
- **类型**：慢炖肉豆砂锅 / 多日加工型终局主食
- **核心关键词**：白扁豆吸汁、油封鸭腿保存食品、猪皮胶质模块、表面面包糠反复焦壳

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐（腌制油封鸭与豆子预处理）
- **伐木**：橡木、榉木（5–8 小时极低温炭火）
- **采集**：百里香 & 月桂叶（Bouquet Garni 香料束）
- **狩猎（版本差异）**：兔肉（Carcassonne 风味分支占位）
- **畜牧（版本差异）**：羊肉（Carcassonne 风味分支占位）
- **种植**：大蒜（摩擦砂锅内壁基底香）、白扁豆（核心）、洋葱 & 胡萝卜（底汤清甜）、硬质小麦（做干面包丁）
- **畜牧**：油封鸭腿所需肥鸭腿与纯鸭油、图卢兹香肠、猪皮、猪腩、猪油（热量装甲与油脂来源）

### 关键中间产物（Intermediates｜粗粒度）
- **油封鸭腿（Duck Confit / Confit de Canard）—— 高阶畜牧保存品**
  - 来自：肥鸭腿 + 纯鸭油 + 海盐 + 大蒜（畜牧 + 挖矿 + 种植）
  - 工艺要点：约 90°C 油脂低温浸炸数小时 → 密封油脂中陈化数周；单独可作补给，入菜属性翻倍（占位）
- **香料猪皮卷（Processed Pork Rind）—— 胶质模块**
  - 来自：新鲜猪皮 + 香料包（畜牧 + 采集）
  - 工艺要点：焯水去油 → 卷起长熬至软烂如啫喱；决定底部油脂“粘稠度”
- **黄金面包糠（Herbed Breadcrumbs）—— 表面防御层**
  - 来自：陈年面包丁 + 研磨大蒜 + 香草碎（种植 + 采集/加工占位）
  - 定位：表面反复烤出焦脆外壳，锁住内部水分

### 成品（Final）
- **法式卡酥来砂锅（Cassoulet）**
  - 组装逻辑（粗粒度）：白扁豆预泡与慢煮吸汤 → 砂锅内壁蒜擦打底 → 入油封鸭腿、香肠、猪皮胶质模块与（可选）兔肉、羊肉分支 → 低温炭火长时慢炖 → 表面铺黄金面包糠多次烤裂再补形成终局焦壳

### 可复用中间产物（跨菜通用候选）
- **油封（Confit）工艺**（通用“低温油脂保存”模板）

## 15. 日本关东煮（顶级料亭版 Oden）

### 定位
- **类型**：复合高汤关东煮 / 极致“清澈出汁”体系
- **核心关键词**：一番出汁温控、食材前处理不浑汤、鱼浆深加工、木炭微沸

### 原材料（Raw｜按来源技能）
- **挖矿**：海盐、纯净软水（软水决定鲜味提取与汤底纯净度）
- **伐木**：木炭（由上述果木之外的木头烧制；稳定无味热源，维持微沸不浑浊）
- **采集**：真昆布（寒冷海域采集，晾晒三年以上）、香菇（干燥后鸟苷酸鲜味）
- **狩猎/捕捞（Fishing）**：鲣鱼（制木鱼花：发酵/烟熏/干燥加工占位）、白身鱼（鳕鱼、飞鱼等，做鱼浆制品）、墨鱼、章鱼（弹牙与海洋鲜味）
- **种植**：白萝卜（`herb_radish_white`，主角；英文 white radish）、魔芋（根茎加工占位）、黄芥末（芥末籽研磨蘸料）
- **畜牧**：牛蹄筋（长炖至透明胶质）、家鸡蛋（高品质）

### 关键中间产物（Intermediates｜粗粒度）
- **第一道出汁（Ichiban Dashi）—— 液体黄金**
  - 来自：真昆布 + 木鱼花 + 纯净软水（采集 + 捕捞/加工占位 + 挖矿）
  - 工艺要点：严控水温约 85°C；沸腾会出粘液、久泡会发苦；失败会导致后续食材“沾染异味”（占位）
- **“洗炼”白萝卜（Pre-treated white radish / 面取工艺）**
  - 来自：白萝卜 + 淘米水（种植 + 副产物占位）
  - 工艺要点：修边成圆柱并面取；先用淘米水煮至半透明去苦；修边完美可避免浑汤
- **手工鱼浆制品（Nerimono）**
  - 来自：白身鱼肉 + 海盐 + 蛋清 + 淀粉（捕捞 + 挖矿 + 畜牧 + 加工占位）
  - 形态占位：竹轮、牛蒡卷、半片（Hanpen）等；作为“深加工产品/属性来源”
- **处理过的魔芋（Blanched Konnyaku）**
  - 来自：魔芋块 + 盐搓（种植 + 挖矿）
  - 工艺要点：盐搓 + 焯水去石灰气；划十字纹以便入味

### 成品（Final）
- **日本关东煮（顶级料亭版 Oden）**
  - 组装逻辑（粗粒度）：先成一番出汁 → 木炭维持微沸 → 依序下入已前处理的白萝卜、魔芋、牛筋、鸡蛋、鱼浆制品与海鲜 → 长时温和入味，最终以黄芥末作为唯一解腻蘸料完成

### 可复用中间产物（跨菜通用候选）
- **一番出汁（温控高汤）**（通用“清澈高汤/温控失败惩罚”模板）
- **食材前处理不浑汤**（通用“前处理决定汤底等级”模板）
- **鱼浆深加工（Nerimono）**（通用“捕捞→研磨→成型”模板）
- **魔芋去味处理**（通用“盐搓焯水去异味”模板）
