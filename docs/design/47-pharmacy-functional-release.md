## 已确认处理

实际功能未接通的成品与专用制作分支暂不开放，保留设计，待消费者完成再启用。有其他有效用途的原料保留。制药台只开放可发挥实际作用的路线，不以占位buff冒充成品功能。

部署时若仅需简单接线即可完成，补接并验证；若需要扩建流血或濒死等完整机制，则暂缓，不为补齐目录扩展本轮范围。

## 本次核对结果

data/pharmacy-buff-matrix.json定义了pharmacy_bleeding_slow与pharmacy_revive，但搜索整个js目录未发现两种类型的显式消费者；针对战斗、buff和生存相关文件搜索流血/复苏也未找到可直接确认的接线。此证据支持将其列为发布前缺口，不宣称已运行测试证明全部相关机制不存在。

重点复核与暂缓对象：三七止血散、白芨止血膏以及复苏/凝血注射效果；相关白芨粉、三七粉及精制精炼线、强心粉与新增兽心替代线须检查所有下游。若唯一用途仍是未实现效果，则该专用制作分支一同暂缓；不能仅因所属药效族而直接删除原料或其其他用途。

自配注射液中，未完成消费者的效果不能充当“实际有效药效”通过开工校验，也不能展示为已生效收益。相关不可用成分入口按专用分支门槛处理，不允许玩家花资源购买一个占位效果。
