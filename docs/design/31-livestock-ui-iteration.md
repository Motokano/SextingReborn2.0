## 第二轮：动物与装置

- 动物按物种分组与筛选，显示数量、个体编号、日龄、育肥进度；需要照看的物种与个体优先，支持仅看健康、饱食或营养异常。筛选后自动选择可见动物，避免右侧详情与列表不一致。
- 繁殖设置、手动分区收进可展开区域，实时刷新保留展开状态。
- 模块按作业臂查看；从总览点击作业臂直接定位对应配置。四区示意高亮当前相邻区域，各模块单独注明作用对象；侧面朝向读取实际安装面。
- 轴心与作业臂显示各自适用的模块目录。空槽高亮使用状态引擎的 canBuildModule，尊重跨槽占用。
- 升级先对比当前和下一等级的真实效果、材料，再确认消耗。满级、正在升级时禁用入口；投料保留为直接操作。
- 浏览器检查新增物种/异常筛选、详情同步、设置展开状态、总览跳转作业臂、单侧朝向、升级预览不改变等级、轴心目录隔离、跨槽冲突和四页窄屏布局；桌面及窄屏截图已人工核看。完整畜牧回归通过。
