# 54. 头胸腹与缺肢姿势的完整组合

2026-09-14。补充[53号姿势设计](53-shared-pawn-pose-design.md)。组合设计数据已保存并校验，尚未完成模块骨架、接触点求解和游戏接入。

## P3/P4/P5如何叠加头胸腹损毁

头、胸、腹部件永远保留。局部伤效分别绑定对应部位；多部位损毁同时显示，不依赖单个全身红色滤镜。下表每行都包含相应部位的局部伤效，动作仅为补充。

| 上身损毁 | P3 双手撑坐 | P4 单手撑坐 | P5 无四肢侧卧 |
|---|---|---|---|
| 无 | 腹部落座，双手固定撑地 | 腹部落座，唯一手固定撑地 | 胸腹侧面落在底座，侧卧 |
| 头 | 头向胸前低垂，双手不动 | 头轻微低垂，身体不越出支撑侧 | 头局部内收，保持贴近底座，不抬起上身 |
| 胸 | 肩胸有限下沉，双手仍撑地 | 上身向可用手支撑侧轻靠，幅度小于P3 | 胸部局部收拢，不能让接触面离开底座 |
| 腹 | 坐姿腰部有限蜷缩，腹部底面不离座 | 腰部小幅收拢，唯一手不能改去护腹 | 腹部局部蜷缩，保持侧卧，不坐起 |
| 头＋胸 | 肩胸下沉、头随胸低垂 | 向撑手侧有限塌缩、头内收 | 头胸同时内收，仍为同侧接触 |
| 头＋腹 | 腰部收拢、头低垂；双手继续支撑 | 小幅屈腰低头，锁定撑手 | 腹部收拢、头轻内收，不能把侧卧变直立 |
| 胸＋腹 | 胸腹形成受限C形收拢，不挪动双手接触点 | 收拢幅度更小，身体靠支撑侧稳定落座 | 侧卧躯干小幅弯曲，胸腹接触面持续贴合 |
| 头＋胸＋腹 | 低头并有限蜷缩于双手之间，不能套用站立蹲姿T4 | 小幅蜷缩靠向唯一撑手，不能长出另一只手 | 侧卧收拢，三处伤效同时显示，不能站起或撑坐 |

P4左右两种撑手分别处理：姿势几何可镜像，但部位ID不交换，脸部特征、发型与单侧配饰不整图翻转。

## 支撑与伤态的优先关系

- 主动支撑只允许仍可用的手腿。P3的两手、P4的唯一手均被占用，不能护胸或抱腹；P5没有手，不能生成手部动作。
- 被动接触与主动支撑分开保存：胸腹即使损毁，其部件仍可被动躺靠在底座上。这不表示功能恢复，也不改变损毁规则。P3/P4保持腹部被动落座；P5保持胸腹侧面被动接触。
- 肩胸变化后须调整可用手臂的关节以维持手掌接触。关节无法满足时减小伤态角度，不移动撑手、不漂浮、不拉长手臂。胸腹旋转不能绕世界原点生硬叠加。
- 头胸腹同时损毁时使用受限组合，不把三处旋转无限相加。每个基础姿势有总躯干弯曲上限。
- 若某个伤态的姿态幅度受接触约束压到零，仍必须显示该部位局部伤效，保证损毁信息不丢失。
- 坐倒与侧卧高度自然降低，底座不移动；缺失肢体不投影，影子随最终姿态组合产生。

## 可直接复用的设计数据

新正本：[shared-pose-map-v2.json](../../assets/map/isometric/concepts/shared-pose-map-v2.json)。v1只含16个四肢映射及上身概述，作为历史记录保留；后续实现读取v2。

v2显式保存全部128个七部位正常/损毁组合，每项包含：

- 部位位序与完整损毁集合；角色自身左右，不混用屏幕左右。
- 基础姿势P/M、镜像几何标记、上身8选1变体编号。
- 可见/缺失部件、主动接触部位、被动接触部位、占用的手与空闲手动作。
- 头胸腹独立伤效、姿态模式、局部关节角目标与总躯干弯曲上限。
- 接触约束、恢复规则与最终轮廓投影要求。

P3有8个上身变体，P4左右各8个，P5有8个，共32个双腿缺失变体。全部组合均明确保存，不仅保存“可叠加”的文字。

位序为 `head,chest,abdomen,lhand,rhand,lfoot,rfoot`，某位为1表示该部位已损毁。真正的损毁判定由既有系统计算，不通过美术数据重新设定满值。

角度是供模块制作起步的调参值，不是用户验收过的精确动作，也不是医学参数。以局部关节坐标为准；接触约束优先于角目标。数据目前不包含完成验证的像素锚点/骨架长度，不能冒充现成动画资产。

角色外观与此数据分离：主角和普通NPC共用，换发型、脸部、肤色、服饰、配饰即可；特殊Boss可使用专用姿势集。恢复时从当前真实部位状态重新查询，不能残留历史缺失或伤效。
