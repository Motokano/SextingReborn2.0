# 58. 主角使用已确认图册外观

2026-09-14，修正57号记录中的误解。用户认可共用骨架的参数与姿势，并没有认可把校准示意人物作为主角外观。主角外观以用户再次提供的六姿势图及 `pose-atlas-v1/index.html` 完整图册为准：黑发、浅色简洁脸、灰毛衣、蓝衬衫领与下摆、深色裤鞋，卡通手绘比例。

## 外观与骨架分别保存

- `pose-atlas-v1/L00.png`–`L15.png`：原始完整图册，保留不改。
- `player-atlas-v1/L00.png`–`L15.png`：通过 imagegen 从图册制作的透明版本；不是逐像素无损抠图，可能存在局部细节差异。提取提示及输出来源记录在 `extraction-record.json`。
- `player-atlas-v1/manifest.json`：128个状态的图页、裁切框、底座宽度、接地锚点。只负责显示，不是骨骼数据。
- `rig-calibration-v1/skeleton.json`、`poses.json`：共用骨架参数与精确变换，独立保留。普通NPC复用这些参数；更换发型、脸部、肤色、服饰、配饰不能把校准示意外形当成主角定稿。
- `player-rig-v1`、`player-office-rig-v1` 是被用户否定的外观尝试，不再用于运行时。不能从图册或裁切参数反推覆盖骨架数据。

## 游戏接入

沿用 `js/player-pawn-rig.js` 的现有HUD接口，内部改为读取透明图册。按真实 CharacterAttributes 的部位损毁上限选图，恢复时重新选图。七位顺序为头、胸、腹、左臂、右臂、左腿、右腿，状态编号D000–D127。左右按角色自身定义，不镜像素材。

底座统一显示46px，保持新卡通图册自身比例，完整站姿约70px。底座下沿位于格中心下8px；坐姿、侧卧自然降低，不能把所有图拉伸成站姿高度。此46px是新版接入的显示值，替代旧v4的39px底座，不改骨架长度。

图片按实际不透明轮廓测量独立裁切框，避免等分排版造成邻图串入或底座截断。浏览器Canvas仅作高分辨率显示裁切，保留源PNG；本体与投影共用当前裁切轮廓。投影沿原先右下方向压扁，保留接触暗部、方向指示和饥饿提示。

`player-atlas-review.html` 提供与运行时同一绘制路径的128状态独立查看，不读写玩家存档。数值检查 `node tools/test-player-pawn-rig.mjs [游戏目录]` 覆盖真实部位阈值、恢复、128映射、RGBA与裁切范围、缓存、过期加载和失败回退。图册素材并非由精确骨架求解出的逐角度一致图，不据此宣称图册每个关节已经精确匹配保存矩阵。
