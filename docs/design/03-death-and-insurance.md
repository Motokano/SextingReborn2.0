# 三、死亡惩罚与装备快照（投保）

> **2026-11-02运行接入**：正式死亡、玩家选择复活、单句培养皿演出、藏身处恢复和地牢中断判死已接入两套UI，详见[82号接入记录](82-death-system-and-presentation.md)。已到账潜能保留，战斗技能按本页扣级；保存触发动作由`data/save-triggers.json`配置。下文投保及取回代码仍为后续设计，本轮没有实装保险。

> **2026-11-02 正式死亡规则确认与流程设计**：见[82 正式死亡系统与死亡演出草案](82-death-system-and-presentation.md)。用户已确认简短地狱过场实际为克隆人培养皿，从皿内只见液体、模糊人影和灯光，暂不解释克隆；玩家要害满损毁即死亡，已到账潜能保留且只丢未结算报酬。82号补齐结算、培养皿片段、复活、保存和敌人表现；流程已按82号接入记录实现，演出构图与首版恢复数值仍可调整。

- **玩家战斗死亡条件（2026-11-02确认）**：头、胸、腹任一部位损毁达到实际生效上限即死亡；四肢损毁继续按失能规则处理，眩晕和昏迷本身不等于死亡。要害满损毁后不增加濒死救援阶段。玩家运行已按82号接入。
- **地牢中途关闭（2026-11-02确认）**：玩家在地牢探险途中关闭游戏，再次打开时直接按正常死亡规则结算，不恢复原地继续探险。刷新、崩溃或系统关闭后重新加载同样处理；仅切后台且原会话仍在不判死。先结算并保存死亡，再等待玩家选择「回藏身处复活」，随后播放已定培养皿演出。正常撤离已保存不判死，已结算死亡不重复扣除或增加次数，保存失败停在处理界面重试。重启检查与补充实施边界见[82号第8节](82-death-system-and-presentation.md#8-保存与两套界面接入约定)，已按82号接入记录实现。
- **潜能（2026-11-02确认）**：已到账潜能全部保留，只取消未结算的探索报酬。资料台等兴趣点已成功发放的潜能同样保留，不清零、不减半；已用点位不回退。此条覆盖旧“潜能沿用死亡损失”的模糊描述，与当前正式地牢余额处理一致。
- **复活顺序（2026-11-02确认）**：死亡后先由玩家选择「回藏身处复活」，随后播放培养皿演出，台词结束后才在藏身处复活。唯一台词为「变...求...0000X号，...准」，编号读取包含本次死亡的玩家累计死亡次数，按五位补零显示。未选择不自动播放演出，台词结束后不再要求第二次复活确认；计数保存与防重复见[82号设计](82-death-system-and-presentation.md)。

- **死亡时**：身上**全部装备与物品**消失，包含**口袋、背包、载具**内一切物品；**拖拽态载具**及其内物品**一律消失**（不留在世界）。实现时须**清空绑定载具引用**（如 `bound_vehicle_id`）与 **inventory_vehicle**，避免复活后仍引用已消失载具。**每个已习得的战斗技能各扣 10% 当前等级**（向下取整、**至少 1 级**、不扣到 0 以下）；经历所谓“地狱”的培养皿内短暂感知后，在基地醒来；**藏身处账号仓库 `hideout_warehouse`** 与生产存货不受影响（见 [29-hideout-warehouse.md](29-hideout-warehouse.md)）。**死亡后不得重新发放新手套装**：新手套装（default_equipment）仅用于**新游戏**初始化角色时穿戴，死亡复活后装备栏为空，不自动补发任何默认装备。
- **复活后**：**心情回到正常程度**（如恢复至心情中心值）；**体力、底气、饱食、饮水等恢复至一半**（即恢复至各自上限的 50%，或实现约定等效规则）。**肢体重置为完好**（功能恢复），但**各部位损毁值恢复至该部位损毁上限的 50%**（损毁值 = 该部位损毁上限 × 50%）。**三类物品栏**（口袋、背包、载具）均为空，不保留任何物品。**（本条款已按82号接入死亡/复活链；损毁值本身已有「自然自愈 + 外敷活络药」两条恢复通道，见 [09-body-parts.md](09-body-parts.md)「损毁恢复」与 [47-pharmacy-system.md](47-pharmacy-system.md) §9.6。）**
- **永久积累资产豁免（已定）**：死亡**不损失**以下三样玩家的积累资产——① **属性经验池**（`attribute_experience`）；② **招式/技能熟练度**（`move_usage`）；③ **实战经验**（`combat_experience`）。它们都是努力成果的永久沉淀、永不回退，也是成长被刻意卡得极慢的原因（见 `01`、`24`）；死亡只惩罚**可再生资源**：随身物品、战斗技能等级（扣 10%）、食物储备。
- **水壶（2026-10-31确认，11-01接入）**：装备槽或随身容器中的水壶随死亡丢失，壶上词条、改造和剩余水一并消失，不补发初始壶；家中仓库存放的水壶和材料仍受原豁免规则保护，已学制作配方保留。正式水壶沿现有装备及随身物品死亡清除规则处理，独立试玩的重制不等同正式制作执行器。具体保存与重制见[80号水壶设计](80-water-flask-equipment.md)；投保归还范围另行接入。
- **背包（2026-11-01确认）**：用户要求与水壶相同，死亡失去随身背包；背包本体、词条、改造与包内物品一同消失，随身备用包同样丢失，不退改造材料、不补发。家中仓库备用包和材料、已学制作与改造方法保留。按既有消失口径处理，本轮未新增死亡地点可拾回的背包；投保范围另定。三款基础型号已获认可，词条与改造尚属提案，未接入新背包的正式死亡链，见[81号背包设计](81-backpack-equipment.md#8-实例保存与死亡丢失)。
- **投保**：下地牢前可付费对当前穿戴装备做一次快照；同一时间仅 1 个生效快照。
- **代码**：死亡后 NPC 给出一段 AES-256 加密代码（含玩家信息、地牢标识、快照装备等），玩家不可反推内容。
- **使用代码**：必须在同一地牢同一入口输入；进入后地牢仍完全随机，系统随机指定一房间生成可互动元素；需到达该房间并成功撤离才可从 NPC 取回装备（仅装备，消耗品不恢复）。
- **消耗**：一旦使用代码，不论成败，该玩家此代码即消耗；未到指定房间或死亡则失去机会。
- **共享**：同一代码可被多玩家使用；每人仅一次机会；成功则各自从 NPC 获得那套装备。
