### 6.2 战斗核心

- **节奏**：风来的西林式回合刻制——玩家每行动一次，所有敌人各行动一次。
- **方向与范围**：8 向移动与攻击；普攻为正前方 1 格单体。
- **输入触发（移动意图驱动）**：方向输入支持 8 向（含对角）。当玩家对某方向发出“尝试移动”输入时，先读取该方向目标格：若为敌人且在攻击范围内，则触发正常攻击流程（不进入敌人格）；若为可对话 NPC 且在交互范围内，则触发对话；都不满足时再按普通移动/阻挡处理。
- **耗回合**：移动一格 / 普攻 / 使用技能 / 使用道具 / 等待；不耗回合动作后续定义。
- **气劲**：技能消耗气劲；每回合自然恢复，可药品与特定行为恢复。
- **气力值（QiLi）**：战斗中使用的即时气力资源，角色与敌人都拥有（概念字段建议：`qi_li_current`/`qi_li_max`）。普通“使用技能”时会消耗气力值（与现有“气劲”并存），而当本回合不发生气力值消耗时，会在回合结算后自然回气；技能/道具也可以显式对气力值做恢复或增减，并夹紧到上限。

  - **消耗与并存口径**：气力值与“气劲”并存。普通技能可同时消耗气劲与气力值；而“出力大小(1～12成)”带来的额外消耗仍主要消耗气劲（以现有气劲/底气催发机制为准）。

  - **回合自然恢复（仅当不消耗）**：定义本回合是否发生过“气力值消耗”（即扣除 `qi_li_current` 的事件）。若本回合未发生气力值消耗，则在回合结算后恢复 `qi_li_max * qi_li_regen_pct_per_turn`（默认约 `25%`），并夹紧到 `qi_li_max`。
- **头顶显示（仅玩家 + 条件解锁敌人）**：该条为战斗反馈 HUD，不在左侧常驻面板显示。仅当 `inCombat=true` 且 `qi_li_current < qi_li_max` 时才渲染“血条样式”的气力条；并且仅当角色拥有特殊技能 `special_battle_sense` 且其等级 `>= 1` 时解锁显示玩家自身的头顶气力条。敌人同样拥有气力值：当玩家 `special_battle_sense >= 3` 时，敌人的头顶气力条也开始显示。
- **出力大小（1～12 成）**：伤害与消耗均与成数挂钩（\(F_{\text{出力}} = \text{成数}/10\)，实际消耗 = 基础消耗 × 成数/10）。**实现约定**：各攻击技能的出力相关配置（如默认成数、气劲/体力基础消耗）在**技能配置**中按技能/招式配置；玩家**打开技能栏并点击某攻击技能时**，可在 UI 中调整该技能的出力大小（1～12 成），该设定在发动该技能时生效。
- **速度与先手、连击**
  - **速度值**：战斗速度由装备的轻功提供 \(V_{\text{base}}\)（未装备轻功时为 1），身手每 +1 点使速度 +0.5%，与装备等加成相加；先算浮点再**向下取整**，用于先手、连击与命中率。速度**仅影响**战斗中的出手顺序与连击，不影响每回合可移动的格数。详见 5.7。
  - **先手判定**：每次主动攻击时，先比较双方速度（取整后的值），速度高者先出手。双方速度相同时，视为同时触发，同时开始计算减伤并结算伤害。
  - **连击**：若一方速度**大于等于**另一方两倍，则速度高者产生连击，本回合内连打两次；大于等于三倍则连打三次；大于等于四倍则连打四次（更高倍数可后续细化）。连击均视为**同一回合内**产生的动作；速度低的一方在对方连击全部打完后再还手一次，本回合仅此一次。
  - **连击判定与消耗**：连击的每一击均**单独**做命中、招架与伤害判定；每一击**单独扣除**一次气劲（及体力，若有），默认按正常消耗。可通过某些手段减免因连击产生的额外底气消耗（该接口为后续扩展预留）。

> 注：战斗中使用的所有属性（筋骨、柔韧、呼吸、身手、专注等）均为“先天 + 后天”的实际值。经脉与穴位系统通过增加底气上限与先天 / 后天五维，**间接**影响伤害、减伤、速度与学习等，但不改变本节的战斗流程与公式。详细规则见 `12-meridians-and-acupoints.md`。
