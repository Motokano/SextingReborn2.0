# 农业界面迭代（2026-09-11）

## 本轮已接入主游戏

- `index.html` 加载 `css/agriculture-overview.css` 和 `js/agriculture-overview.js`。
- 深色田园风格、CSS 土纹/水纹和简洁设施图标；桌面低高度窗口显示完整 11×11 地图。
- 生长、水流、养分、土壤四视图；供给来源与请求作物高亮；设备与作物之间可以点击跳转。
- 每 tick 供给快照、适宜区间、本季累计值、土壤实际生效情况、微量敏感提醒。
- 原始地块信息折叠展示，操作按已有功能分组折叠并保留展开状态。
- 播种、渠道和设施建设/拆除、客土等有元数据的操作提供悬停/键盘聚焦预览；不扣材料、不推进时间。尚不包含浓度步进、注入耗材操作的预览。
- 修正建好支撑建筑后播种入口消失的问题；缺支撑时，播种预览显示所需建筑。

## 数值依据

地图模块新增 `inspectSupply` 和 `previewChange`。前者在克隆地图上调用实际海藻精维护规则，返回设备—请求—渠格关系和作物供给。后者仅在克隆上落地操作。

供给量按当前布局和水量计算，不是最终收成预测。肥力包含当前生效的土壤缓释；淋溶等累计变化另行提示。成熟作物供给显示为零。旧季作物使用其实际旧定义。

## 已接入的供给规则

- 海藻精 A 面按请求作物适宜微量区间下限自动定量，显示目标、实际输出、总上限、剩余养分与估算续航。
- 瓮肥采用有限储量与玩家总释放设置，周围合格生长作物平均分配；显示余量、释放量和服务对象。
- 肥料与海藻精取消保质期，按实际输出扣储量；拆除预览显示将损失的剩余养分。
- 水池固定为 200/tick，升级、窃流、蓄水、溢流和随机供水控件已移除。

界面与运行时共用 `inspectSupply` 计算结果，不提前承诺未来产量。
