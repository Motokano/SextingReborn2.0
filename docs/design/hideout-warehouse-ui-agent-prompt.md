## --- PROMPT 开始 ---

你是本项目的 **UI 视觉设计 Agent**。请为一款 **末世冷兵器生存 RPG** 设计 **「藏身处账号仓库」** 全屏弹窗界面（`hideout_warehouse`）。你无法访问我们的代码仓库；以下文字与色值即为全部约束。

### 0. 硬性视觉约束（必须逐条遵守）

1. **与背包 UI、战斗技能 UI 主题色调保持一致**——不得另起一套全新配色宇宙（禁止赛博霓虹、高饱和渐变墙、玻璃拟态泛滥等与现有面板冲突的风格）。
2. **延续现有 UI 的文本呈现为主的风格**：信息密度偏高、可读性优先；装饰克制；标题/分区用字重与间距区分层级，而非大面积插画。
3. 面板气质：**暗褐炭底 + 暖金强调 + 琥珀橙选中态**；边框 **2px**、圆角 **8～10px**；卡片 **2px `#4d4d45` 描边**。
4. 字体：中文主界面 **Microsoft YaHei / PingFang SC**；标题区可混 **Noto Serif SC**（与战斗技能面板一致）。
5. 禁止：过度花哨装饰、强发光霓虹、与下列色板无关的「第三套主色」。

### 2. 产品背景（给交互用）

- **唯一玩家仓库** `hideout_warehouse`：藏身处账号级，**限格不限重**（不显示负重）。
- **默认开放**：新档即可使用，无需剧情解锁（NPC 对话后打开面板）。
- **基础 100 格**，材料升级终局 **700 格**；`stack_limit>1` 的物品在仓内可叠 `count`，其余 **1 格 1 实例**（装备、未鉴定物保留实例状态）。
- **入口**：设施 NPC 菜单 → 打开本面板（不是地图常驻按钮）。
- **死亡**：仓内物品不清；身上口袋/背心/背包/载具会清空（面板可提示「账号仓不受死亡影响」一句弱 hint，勿喧宾夺主）。

### 3. 必须设计的界面与状态

请产出 **静态高保真 mockup**（推荐 1920×1080 画布内嵌面板）+ **组件说明**，覆盖下列 **全部** 视图：

#### 3.1 主面板 · 藏身处（默认态）

**布局建议（对齐战斗技能三栏，但内容换为仓储）：**

```
┌─────────────────────────────────────────────────────────────┐
│ Header: 标题「藏身处仓库」| 已用 73/100 格 | 搜索 | 设置⚙ | 扩建 | ✕ │
├────────┬──────────────────┬─────────────────────────────────┤
│ 左轨   │  仓格网格区       │  右侧：选中物品详情              │
│ Tab/   │  (虚拟滚动网格)   │  名称 + 描述 + 属性模块块      │
│ 筛选   │  + 分页/跳页      │  操作：取出 / 锁定 / 星标        │
├────────┴──────────────────┴─────────────────────────────────┤
│ 底栏：人物侧栏（可折叠）— 口袋|背心|背包|载具 四容器快览 + 存入 │
└─────────────────────────────────────────────────────────────┘
```

**仓格网格（核心）：**

- 用 **小卡片格** 表现每个 slot（参考战斗技能 `.combat-move-node` / `.combat-limb-slot`：**方角 8px、2px 边框、编号角标**）。
- **空格**：虚线或 `#6b6560` 斜体「空」；**有物**：名称缩写或图标占位 + `×count`（可叠时）。
- **选中格**：橙边 + 光晕（与 `.combat-skill-item.selected` 一致）。
- **锁定格**（升级 U-E1）：小锁标 + 略降透明度，仍可见内容。
- **星标格**：角标 ★（金色，勿用新色系）。
- **易腐标**（模板可腐败）：小字「易腐」或沙漏 icon，弱警示色（可用现有橙/灰，勿引入红色警报体系 unless 与 `#ff8c00` 同族）。
- **100～700 格**：设计须体现 **虚拟滚动 / 分页**（页码条参考 `.combat-pager`）；展示「第 1/7 页 · 每页 100 格」类文案。

**左轨 Tab（升级后 U-G1 分栏视图）：**

- 默认：`全部`
- 升级后：`全部 | 材料 | 装备 | 易腐 | 已锁定 | 星标`（样式 = 战斗左轨 `.combat-cat-btn`）

**顶栏「扩建」：**

- 次要强调按钮（描边金/橙，非实心荧光）；点击后进入 **3.3 扩建面板**。

**底栏人物四容器：**

- 横向 **4 个容器条**（口袋/背心/背包/载具），每容器若干 **迷你格**；支持 **拖放 / 双击存入**（用箭头示意交互，文案写进说明）。
- 与背包 UI **分区明确**（上为仓、下为人），边框 `#4d4d45` 分隔。

**设置区（⚙，首版可折叠）：**

- 勾选：**优先从仓库扣料**（工料仓 U-F2）
- 勾选：**存入时自动合并同 id 可叠物**（默认开，灰显说明为基础能力）

#### 3.2 主面板 · 地牢「远驿」态（U-G2）

- 与 3.1 **同一面板骨架**，但：
  - Header 角标：**「远驿 · 仅可存入」**（琥珀色小 badge）
  - **禁用**所有「取出」「饱和取出」按钮（灰显 + disabled 样式）
  - 底栏人物区仍可用，**仅存入方向**箭头高亮
  - Footer hint：`本次地牢内有效，撤离后仅能在藏身处正常取物`

#### 3.3 扩建 / 升级面板（子层或侧滑）

- 从主面板「扩建」打开；**不要**换配色。
- **列表**：14 个升级节点卡片（参考 `.combat-skill-item` 行卡），每卡含：
  - 节点 id（如 U-A1）、名称、驱动标签（S/A/B/高级）
  - 前置条件、解锁能力一句话
  - **材料清单**（物品名 × 数量，多行文本）
  - 工程：`10 tick × 5 体力/tick` 类 meta
  - 状态：**可扩建 / 材料不足 / 前置未满足 / 已完成**
- 选中某节点后右侧或下方展开 **确认区**：材料对照（身上+仓内是否够）、**开始扩建** 主按钮。
- 扩建进行中：**进度条**（填充 `#d3a060`，底 `#1a1512`）+ 剩余 tick 文案。

| id | 名 | 要点 |

#### 3.4 冷藏已启用态（U-G3）

- Header 增加弱标识：**「冷藏中」** + 雪花 icon（线条 icon，单色 `#9ad0e8` 仅作冷色 **辅助**，面积 <5%，主色仍金/橙）。
- 易腐 Tab 或格子上标注「已暂停计时」。

#### 3.5 空态与异常

- **空仓**：网格区中央弱文案 + 示意「从下方人物栏存入」。
- **仓满**：存入按钮 disabled；顶栏 `100/100` 用橙强调。
- **搜索无结果**：列表区空态。

### 4. 交互说明（须在交付文档中写明）

| 操作 | 行为 |
|------|------|
| 单击仓格 | 选中 → 右侧详情 |
| 双击仓格（U-C1 后） | 快速取出 1（可叠物可选 1/全部 — 用小型 popover 示意） |
| 拖放 | 人物栏 ↔ 仓格 |
| 一键理仓（U-B1） | 顶栏或工具条按钮 |
| 估格整备（U-C2） | 「整包存入」+ 预览占格数弹窗 |
| 常备套（U-F1） | 独立小面板：3 组 loadout 切换（U-F3 后） |
| 封签（U-E1） | 详情区锁定/星标 toggle |

**不消耗 tick 的纯 UI 操作** vs **消耗 tick 的取出/存入** 可在 footer 用弱 hint 区分（与背包打开规则类似，一句即可）。
