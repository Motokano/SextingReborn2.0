# 单手武器跨部位部件草案

2026-10-12 数值修订：本页现行部件基础威力已按用户要求，与重量、筋骨门槛一起重配；最新门槛、重量、耐久及威力预算方法见[部件完整数值表](weapon-component-final-stats-draft.md)。按用户明确的筋骨最低10，轻型件最低要求统一为10，保留其较小基础威力；重件采用更高要求与基础威力，具体数值仍为本轮提案、未实装；原攻击属性、防御、速度、特色效果及损坏倍率保持。

2026-10-10。用户认可钝击侧首批设计后，开始讨论跨部位部件。本稿提出八种占位组合与三类位置联动buff，并按用户要求明确逐位置属性、基础威力和防御系数，以及整件共享数值。数值版按六阶段各三个方案安排，共18件；用户随后认可本批作为后续设计基础。数值继续保留试调状态，具体结算细则仍需与统一规则核对，未实装，不分配材料。

## 沿用的装配规则

跨部位部件仍是一个完整部件，声明其占用的全部攻击位置，以及每个位置各自的攻击功能和属性值。占用的位置不能再安装其他部件。武器仍须覆盖原型全部四个攻击位置才能使用。

角色仍逐位置出招；部件覆盖多个位置不代表一次出招同时使用所有位置。每次招式只读取当前攻击位置的声明数据。整件共用一条耐久，各位置读取同一耐久状态；耐久为0时，每个位置按其声明的归零效果处理，不直接等同空槽或整件消失。具体归零效果后续逐件设计。

速度修正属于实际部件实例，只计入整武器汇总一次，不随占用位置数量重复计算。使用门槛沿用部件要求与整武器降效规则。格挡资格沿用原型及明确解锁：本批覆盖的两侧可以格挡，前端不因与两侧连成一件便自动取得格挡资格；被选中时读取该位置自己的格挡、卸力系数。

## 三类联动buff提案

每件先取一个主要特色，不要求每种外形发明一套新规则。以下增幅仅用于表达首稿强度，尚未平衡。

| 模板 | 适用候选 | 效果提案 |
|---|---|---|
| 交替 | M01、M02 | 侧一实际出招后，强化下一次侧二攻击；侧二实际出招后，强化下一次侧一攻击。伤害+6% |
| 接续 | M03、M04、M06 | M03：侧一钝击→侧二劈；M04：侧一钝击→侧二刺；M06：侧二钝击→侧一劈。前者实际出招后，后者下一次攻击伤害+8% |
| 贯通 | M05、M07、M08 | 侧一、侧二各实际出招至少一次后，下一次前端攻击伤害+10%。M05前端为刺，M07前端为钝击，M08前端为刺 |

效果仅依赖本件对应位置的真实出招，不要求伤害类型在同一击混合结算，不附送额外攻击，不改变原循环顺序。前端强化可以服务于刺击，也可以服务于棍顶的钝击，具体由部件前端声明决定。

“贯通”拟按两个位置的完成标记处理，而不是出招次数总和：同一侧的速度连击或多次出招不能代替另一侧。两个标记齐全后生成一份前端强化，最多保留一份；使用前不额外积攒下一份，前端实际使用后清空本轮标记。具体状态细则仍属于提案。

交替、接续均拟为同来源最多一份待使用强化，不叠层；消耗在对应位置的第一次实际攻击上，不覆盖整串速度连击。未执行、被替换或取消的招式不提供完成标记，也不消耗强化；换掉来源部件后清除该部件的记录与待使用强化。不同部件的联动记录不混用。

这些都是部件buff，不是metaskill，不额外加入触发队列，也不放宽metaskill禁止触发另一个metaskill的规则。进入或离开徒手循环时的通用buff处理沿用现有规则，不在这里另设暂停或冷却机制。

## 取舍与后续范围

跨部位件减少了玩家能独立挑选部件的位置，换来一套明确的组合与联动。它不必在每个位置上都超过同阶段单位置件；后续应把各位置威力、格挡与卸力、速度、联动收益和共用耐久一起计入预算。

本轮不追加跨手柄的护框或占四位置的整件武器；这只是首批范围，不是禁止以后设计。逐位置威力、格挡和卸力系数，以及整件速度、相对耐久、buff增幅已补齐试值。后续仍需确定具体使用门槛、正式耐久单位与归零效果，并结合完整武器循环调平数值。材料仍留到铸造系统讨论。
