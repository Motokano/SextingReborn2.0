## 1. 重整结论与边界

保留玩家认可的成长路线：**粗制就能用 → 成型便于使用 → 精制减少杂质与体积负担 → 精炼形成高加工终点 → 合格成分可进一步配成注射药。** 原料、药粉、药液、丸、膏、烟、针都需要有明确位置，不能把所有粉末做成只等着进配药台的材料。

本轮不改变慢成长基调、知识发现规则、药物可选地位、仅能给自己用药，以及未知相冲不提前预告的原则。信息显示沿用已讨论的 [0/1/2/4/6 级方案](47-pharmacy-information-display.md)。不以 UI 隐藏缺失功能，也不以“先增加模板”计算玩法丰富度。

目前经源表核验：96 件物品、30 件固定成品、68 条配方、12 个族。主要问题如下：

| 问题 | 当前证据 | 新版处理 |
|---|---|---|
| 纯度与强度混淆 | `pure` 同时像“纯品”又是 ≥100 药效点的最高档；粗原料多放也能到该档 | 加工等级与强度分列；保留内部旧枚举兼容，玩家强度名称改“极效” |
| 固定与自由配药两套结果 | 固定成品手填 buff，动态配药按原料点数定档；10 处原始同族投入分档不同 | 统一贡献和剂型计算；固定配方是标准配比的保存版本 |
| 辅料角色混在一起 | 所有负毒性粉末归 `synergist`，运行时按该族份数增加药效 | 抵消、增效、助溶分开显式配置 |
| 精制抵消辅料收益倒退 | 护肝草粉抵消绝对值 40→24→16，容量 30→24→21 | 抵消能力不套“有害毒性减少”的精制公式 |
| 相同镇痛 buff 却描述更强 | 普通与精制镇痛针共用 potent buff，镇痛主体是布尔压制 | 合并常规入口；差别必须落在持续/负担/容量等真实参数 |
| 标准升级链撞方 | 两份原料的浓煎提神配方包含一份原料的普通配方；同工艺超集匹配随机抽取 | 浓煎改为基础药液的独立浓缩工序；不改其他生活系统的匹配规则 |
| 有模板无功能 | 止血、复苏关键消费者缺失 | 列入条件储备，功能完整后开放新版发现 |
| 原料有名字、日常用途少 | 多数品类围绕战斗、短时状态恢复 | 增补休养、劳作、行路、御寒、清暑、药后调理六种用途 |

## 2. 分类：四个问题分别回答

| 维度 | 回答的问题 | 值 |
|---|---|---|
| 用途 / 药效族 | 用来做什么？ | 提神、镇痛、补液、伤损恢复等；见 §3 |
| 加工等级 | 处理到了哪一步？ | 粗制、精制、精炼；成型是独立工序，不自动提纯 |
| 形态与途径 | 怎样带、怎样用？ | 药液/糖浆/丸→口服，粉/泥/膏→外敷，烟→吸入，注射液→注射 |
| 药效强度 | 这一份有多强？ | 弱效、常效、强效、极效；不用于推断纯度、安全或是否成瘾 |

名字优先让玩家知道用途和形态；只在有真实差别时加加工前缀。例如“精炼安神汤”属于高加工口服终点，不需要为了显得高级改成针。强度单独显示，避免堆成“精炼纯品强效药”。

药粉有两种身份：允许粗用的剂型成品，以及可继续加工的中间品。每种粉末显式声明允许用途；不因都叫“粉”就全部可吞、可敷、可配针。同一成分跨族作用必须有剂型适配记录，例如苦根草内服镇痛、外敷恢复不能再靠固定成品悄悄切换族。

## 3. 药效目录与效果边界

### 3.1 现有用途重新分工

以下数值是**常效、峰值系数 1 的首版试算基准**，用于建立一致规格，不直接覆盖游戏值。剂型、有效 tick、负担与总成本必须一起回归。族名称以本表为准，内部旧 ID 保留映射。

| 用途 | 主效果基准 | 明确不做 | 允许新版形态 |
|---|---|---|---|
| 提神 | 精力 +1.2/tick、体力 +0.3/tick、行动速度 ×1.08、专注 +2；口渴值 −0.2/tick 作为同屏负向作用 | 不包揽营养、全部疲劳与伤损恢复 | 药液、烟、针 |
| 续航 | 精力 +1.5/tick；糖类带来的营养只走一次消化结算 | 不加行动速度、不叠算食物恢复 | 糖浆/口服制剂 |
| 补液 | 口渴值 +2.5/tick | 不额外包揽提神、续力；不与原有饮水恢复重复记账 | 药液、针 |
| 安神 | 心情 +1.5/tick | 不凭空产出营养，不自动治伤或结算睡眠经验 | 药液、烟 |
| 镇痛 | 生效期间抑制疼痛 debuff；布尔效果不乘强度系数 | 不减少损毁、不使身体恢复完好，不把“更强”写成第二次关闭疼痛 | 丸、针 |
| 感悟（保留幻梦药名） | 潜能与实战经验收益各 ×1.15；专注 −2 作为同屏负向作用 | 不开视野、不显示未知地图，不提高永久成长概率到 100% | 药液、烟、动态针 |
| 醒神 | 眩晕抗性 +30%，总抗性按战斗系统上限裁切 | 不等于解除当前眩晕 | 药液、针 |
| 续力 | 常效注射负重上限 +5 kg（按剂型/强度缩放），已接入实际承载 | 不增加筋骨或背包格数；同类取最高值；口服 180 / 注射 120 tick | 药液、针 |
| 伤损恢复（原活络） | 指定部位损毁 −0.3/tick | 不恢复所有部位、不替代手术、不将恢复量写成移动速度 | 粉/泥/膏 |

数值效果强度系数暂沿用 0.5/1/1.5/1.9；倍率只缩放相对 1 的增减量，抗性百分比按量缩放并裁切，布尔效果不得套数值乘法。镇痛的高加工收益优先来自更低负担与更长有效窗口；不得通过纯文案制造无实际效果的升级。

### 3.2 条件储备

- **止血**：保留三七止血散、白芨止血膏、止血注射液的 ID 与设计位置。先实现流血的产生、持续、结束与对应消费者，再纳入新版可发现目录；局部外敷与系统性作用明确分开。
- **急救强心**：保留强心注射液。只允许意识尚存、能操作时使用；未来效果定位为短暂干预危急状态，不是死后复活，也不要求昏迷者自行注射。先定义与现有体力死亡/昏迷机制兼容的状态窗口，再定数值，不能仅填恢复百分比。
- “储备”影响未来内容投放，不删除旧档物品、清空旧配方知识或擅自替换为其他药。旧物品沿用旧版本规则，直到完成有版本的迁移。

### 3.3 六类新用途、八件首批成品

完整数值、配方、条件、代价见附表及 JSON；下表定义使用理由。

| 新用途 | 成品 | 为什么值得带 | 边界 |
|---|---|---|---|
| 休养 | 休养药泥、休养药膏 | 回家休息时更高效地恢复某个部位 | 只乘自然恢复量，不提前越过自然恢复宽限；活动时无额外恢复 |
| 劳作 | 耐劳药液、耐劳丸 | 连续采集/加工时节省体力 | 仅白名单生活行为，不加产量或经验，不减少燃料 |
| 行路 | 行路丸 | 长途返程减少普通移动体力成本 | 不减战斗步法成本，不增加格数/容量；基础移动没有成本时不投放此药 |
| 御寒 | 御寒药膏 | 延缓环境导致的失温 | 不直接升温、不豁免死亡阈值；全身防护型外敷与部位治疗分开 |
| 清暑 | 清暑药膏 | 延缓环境导致的升温 | 不直接降温、不补水；与御寒占同一防护槽 |
| 药后调理 | 药后调理液 | 休息期间加速已有药物毒性代谢 | 不清药瘾，不解所有毒；再次摄入药物毒性会终止该调理效果 |

这些新功能都需要消费者与反馈，不是仅靠现有矩阵加几行就能生效。前三类优先与真实行动/恢复成本联调；若行动本身没有相应成本或相关环境尚未配置，药品留在设计目录，不虚报完成。

## 4. 每种形态的长期价值

下列为新制剂的时间基准提案。**起效延迟与有效持续时间分别计数**；当前 buff 到期计时语义需统一适配，不能直接把“有效持续”写进旧 `durationTicks`。免疫修正只作用于明确允许的药效持续，不延长制作耗时、卫生状态或器具寿命。

| 形态 | 起效 / 有效 tick | 峰值系数 | 成本与长期价值 |
|---|---|---:|---|
| 粗药液 | 5 / 45 | 0.8 | 最低成型门槛；省工艺成本，体积大、保存短 |
| 浓缩药液 | 5 / 60 | 1.0 | 增加工序和投入，缩小体积；不是全属性无代价升级 |
| 药丸 | 8 / 90 | 0.65 | 慢起效、好携带、较长作用窗口，需要丸基与成型工序 |
| 糖浆 | 5 / 60 | 0.8 | 承载确有营养的口服成分；消化与药效不重复结算 |
| 外敷药粉 / 药泥 | 3 / 45 | 0.7 | 简陋条件可用，局部护理的低成本终点 |
| 药膏 | 3 / 90 | 0.7 | 多次局部使用，膏基换持久和携带便利；必须计算每次剂量 |
| 药烟 | 2 / 18 | 0.9 | 较快、短窗口、专属作用族；不机械补齐所有药烟 |
| 标准/精炼注射液 | 0 / 按药效族 20～50；储备模板保留 10 | 1.0 | 见[注射窗口定稿](47-injection-effect-windows.md)；保留静止、器具及统一战斗门禁 |

特定新功能使用规格表自己的数值与有效时长，不再乘一遍通用峰值，以免双重缩放。每条配置必须注明是“族基准”还是“已解析制剂效果”。粗制中间品直接使用映射到对应粗剂型，不能得到注射的时间参数。

**局部定稿更新**：注射窗口已按 [47-injection-effect-windows.md](47-injection-effect-windows.md) 定稿，由 Sol 完成运行时实现与回归；该文优先于本稿此前统一 10 tick 的提案。其他重整规则与数值仍维持本稿各自状态。

### 4.1 注射作为深加工终点

新版**标准注射配方**要求有效成分达到精制级且显式允许注射；精炼成分则提供更低杂质负担和更小容量占用。现有缺少精制中间品的标准针，由附表列出的三条精制链补齐。保留工艺现有技能与配件门槛；新增浓缩继承入门浸渍门槛与配件，成本另列下文，不擅改成长曲线。

自由配药仍允许低加工成分试配，但必须标为粗配注射液，继承较高杂质负担，不能因装进针具就变成“纯品”。混入低加工活性成分的实例不能获得标准/精炼品质标识；纯度判定取相关活性成分最低加工级。溶媒、助溶剂单独检验，不因其没有加工级把结果错误降为粗制。

固定配方标准化解决便利与可复现，自由配药解决组合选择；同成分、份数、工艺、角色与卫生条件必须得到相同结果。不能让固定针绕过毒性、成瘾、相冲或成盐预算。

### 5.3 原料替代与地域差异

同效替代原料必须在表中显式允许，并有可比较的来源成本、杂质负担或容量区别。不会让所有药材通用替代，也不会新增来源只是改名字。首发保留现有不同原料来源；新增六类先各落实一条地表采集与一条种植路线，再扩稀有替代物。

玩家投入的普通原料始终保留粗用、低阶成品或继续加工的出口。精炼的优势以单位携带量/配药容量/负担衡量，不能让廉价药失去经济理由。价格待原料实际产出及加工成本核算后给出，不靠“稀有”标签直接加倍。

## 6. 统一药效与负担结算

### 6.1 不再让一个正负数字决定所有角色

成分明确记录 `effect_contributions`、`toxicity_load`、`offset_capacity`、`synergy_strength`、`solubilizing_capacity`、`concentration_cost`、`addiction_profile`、`processing_grade` 与 `allowed_forms`。这是一组拟议字段；落地时需接 CSV 构建器和校验，不能直接加进 CSV 期待自动生效。

- 主药/功能成分贡献效果；是否成瘾由独立资料指定，不从“有毒”或“注射”自动推断。
- 抵消辅料只减小配制时的常规毒性负担；不能据此推导“吞下去能解除体内毒性”。药后调理是单独的已定义功能。
- 增效辅料只按明确能力放大允许的药效，不默认增幅所有条件机制。原骆驼蓬辅料可保留增效与抵消双角色，其余抵消辅料移除隐含增效。
- 助溶剂只提供助溶能力；溶媒只提供载体与配伍属性，不能因糖水/盐水名称自动送额外药效。确需兼具补液或营养时作为显式贡献记一次。
- 杂质毒性、成瘾负担、卫生额外毒性、隐性相冲分别结算和显示，不能让“精炼”抹去所有风险。

### 6.2 剂量、加工、强度守恒

1. 原料贡献按份数累计；先明确输入是原料、中间品还是已有成品，已有成品继续加工读取其实际剩余内容。
2. 精制提高单位体积集中度并减少杂质，同时损失部分总活性；首版试算粗→精制总活性回收 80%、精制→精炼 90%。两份合成一份时，新单份贡献分别为旧单份的 1.6 倍、1.8 倍，不能把回收率误当单份倍率。
3. 有害杂质按独立去除率计算；首版试算总杂质分别保留 30%、20%。负数抵消值先迁移成正数抵消能力，不能套这条公式。精制抵消材料单份能力随集中度提升，并验证单位容量收益不下降。
4. 同族贡献经允许的增效、沉淀与剂型适配后，按**每次剂量**分配。多件产出、多次药膏和复方均须有总份数账；不得一份投入复制为每次完整剂量再免费乘次数。
5. 强度阈值沿用配置 33/66/100，玩家最高档显示“极效”；强度与加工等级分别派生。固定成品、动态实例与 UI 预览读取同一份结果。
6. 浓缩提高单位体积贡献，首版试算总活性回收 90%；增加原料不能制造新药效族。每次药效、总可用次数、理论总量和总成本一并校验，避免最低档量化导致多分装凭空增加收益。

所有回收率与效力基准是新版平衡提案，旧档物品不会追溯重新计算。整数属性和低额每 tick 效果保留小数累计，不能让低档效果长期被取整吞掉。

### 6.3 同族与重复使用

新版提案：同族同作用目标只取一份有效效果；同档重复使用不叠效不免费刷新，强档替换弱档时采用新药自身时间，不继承累加剩余时间。不同部位的护理按“族 + 部位”分别管理，避免同一 buff ID 把第二部位堵住。御寒/清暑共用防护槽，不能互相叠加。

复方部分作用重复时，仍可加入其余作用，但在用药前列明不新增的作用及仍需承担的常规代价。隐性相冲不预告。生效阶段、起效延迟、药瘾压制都读同一生效判定，不出现药尚未起效就已压制的两套状态。

## 7. 迁移与实施顺序

### 第一批：统一旧系统，获得可信目录

接结构化加工/剂型/成分字段 → 统一固定和动态药效解析 → 统一负担与剂量账 → 修正辅料角色/精制 → 改造浓缩链与三条缺失精制链 → 合并重复新制作入口 → 接 0～1 级完整显示。完成后再重算价格与整条链收益，不能先声称数值已经平衡。

### 第二批：有功能再投放新药

按消费者接入休养/劳作 → 行路 → 环境防护（核验地图温度）→ 药后调理；每一类同步完成原料来源、配方、实例保存、效果结束、信息显示和条件回归。行路所需基础成本已查到：`move_stamina_base=1`，场景移动还计入鞋与超重修正；新药应进入这条成本链，不能另扣或另返体力。止血/强心独立等待其状态系统闭环。

### 存档与物品保护

- 保留全部旧物品 ID，停止新制作入口不等于删除物品模板。旧配方知识做旧 ID 到新入口映射，保留已知状态，不解锁未知配方。
- 新制剂实例记录版本、加工级、每次剂量、剩余次数和结算所需成分；具体值是在制作时冻结还是使用时按角色修正，需清楚分层：成分内容冻结，角色修正在使用时计算。
- 旧模板物品按 legacy-v1 使用既有解析器；旧动态实例缺版本时保留旧成分解释路径，不凭当前新表反算、返料或升级。新旧不同内容不能只按 item_id 合并堆叠。
- 真正迁移前先验证背包、仓库、交易、旧存档与已生效 buff；不得因显示重整清空库存或副作用。

## 8. 验收条件

- 全量覆盖 96 件旧物品、30 件固定药、68 条配方、12 个原族；有删除/合并就有明确去向，不靠名字猜迁移。
- 固定/动态在相同条件下药效、毒性、成瘾、成盐和已触发相冲一致；未知风险不被预览泄露。
- 浓煎的标准投料只命中目标升级配方；保留统一系统对任意超集投料的既有行为。
- 精制抵消辅料的单位容量能力不倒退；不同纯度与不同强度可独立组合，文案无“高剂量=纯品”的错误。
- 单份/多件/多次成品的有效成分总账守恒，部分用过的成品不能重新加工成满量；精制和浓缩没有资源循环套利。
- 每件启用药都有有效消费者、结束条件、可达配方和来源；游戏里不出现开发占位功能。
- 同族不同部位、重复使用、延迟生效、免疫修正、死亡与读档不会重复恢复、丢失代价或永久残留增益。
- 初级品在资源成本上有用途，丸膏烟针各有使用理由；新药不会替代食物、衣物、休息或整套非制药玩法。

本轮完成全量目录重整与迁移规格；运行时改造按上述批次执行。设计稿中的具体新规则和试算数值明确保持提案身份，不将用户对整理工作的授权写成对每项新数值的逐条裁决。
