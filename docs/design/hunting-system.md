# 狩猎活动设计

> 2026-09-15：首版已接入游戏，包含野兔、牛羊猪鸡种源事件、捕具制作、消耗、休息、结算、冷却及存读档。数值为试玩值；实现范围与验收见 [首版记录](hunting-implementation-v1.md)。

> 首场事件 [废园里的野兔](hunting-event-rabbit.md) 的思路已获认可：徒手、诱饵配捕网、套索配休息守候三条路线，准备成果影响捕捉和一次补捕；成本、概率和时长仍为草案，不扩展为所有猎物的统一规则。

## 一、已确认的活动结构

- **与畜牧互补（已确认）**：狩猎提供幼崽种源，畜牧负责养成与持续生产；狩猎和畜牧各有特色产物。逐物种、共用材料及加工出口见 [完整产出链 v1 草案](hunting-output-chain-v1.md)，具体分配仍待评审。

- 狩猎点散落在游戏中，玩家与可用点位互动，开启一次独立狩猎活动；不限定为地牢专属玩法。具体地图分布、首次出现或激活规则待定。
- 活动结束后，该点位进入冷却；冷却结束直接恢复可用，不再追加随机激活等待。
- 狩猎围绕事件决策、道具与成功率展开，区别于普通资源采收。准备选项也需要玩家付出体力。
- 玩家可在出发前准备捕猎道具、进食与补足饮水；道具可通过改善捕猎条件、减少行动消耗等方式帮助狩猎。具体效果尚未定案。
- **捕具改为消耗品（最新确认，替代损坏方案）**：每次有效使用消耗对应捕具，便于玩家按预计捕猎次数准备数量。首场捕网每次捕捉消耗1个，套索布置消耗1个；捕捉失败不返还，补捕另耗捕具。前置条件不满足、操作未执行时不扣除。此方案不再采用捕具损坏、耐久或维修机制。

## 二、活动内恢复（已确认）

- 狩猎过程中不能进食；活动结束后恢复日常操作。
- 玩家可以选择休息。休息推进游戏时间，沿用正常休息的体力恢复，并由现有生存系统结算饱食、消化与饮水等变化。
- 不另设狩猎专用的“固定饱食度／饮水兑换体力”公式，不重复扣除生存系统已经结算的消耗。
- 现有规则见 [生存属性](06-survival.md) §6.1.3：休息使用休息恢复基数及共用体力恢复公式。饮水目前不直接决定体力自然恢复量；本次不改变这项全局规则。
- 本次明确禁止的是进食；活动内主动饮水、药品及其他恢复物品是否可用仍待明确，不据此自动扩展禁用范围。

## 三、休息与猎物局势（已确认方向）

休息按当前事件情境影响猎物，操作前向玩家显示相应后果或风险：

| 情境 | 休息的影响方向 |
|------|----------------|
| 正在追赶猎物 | 可能失去踪迹 |
| 猎物尚未受惊 | 期间可能转移位置 |
| 已布好陷阱、正在守候 | 休息可以与等待兼容 |

具体时长、移动或丢失踪迹的触发条件与概率待定。休息不应统一视为必定失败，也不应默认冻结所有猎物状态。

## 四、候选玩法（尚未定案）

- 短事件链：发现线索 → 接近或布置 → 捕猎 → 必要时补救 → 结束；此前提出的每场 3～5 次选择只是建议。
- 道具可解锁专属选项、提高成功率、减轻失败损失或提供有限补救；不自动确定具体道具或消耗方式。
- 中途失败可改变警觉、成本与后续事件，避免每一步都必须成功才能获得猎物。
- 准备成果可记录为已知逃路、已放诱饵、已设陷阱等具体条件，影响后续选项。
- 此前举例的野兔、野猪事件及 45%／70%／85% 成功率均为说明性示例，不是配置或验收标准。

## 五、后续待定

### 本轮物品调整（数据与首版活动已更新）

- 田螺改归钓鱼，编号为 `fish_snail_land`。
- 熏腊肉、萨洛采用 `cook_bacon_smoked`、`cook_salo`，来源为烹饪；旧掉落池的物品引用同步更新，不据此认定为狩猎直接产物。
- 原 `hunt_` 编号的10种水产改用 `fish_` 前缀，来源保持钓鱼；同步来源CSV、物品主表、掉落池及工具中的引用。
- 石砾投枪改为 `consumable_javelin_stone`，分类为狩猎消耗品，来源为制造；每次有效投掷消耗1支，失败也消耗。移除战斗武器攻击字段。具体狩猎选项与效果待活动实现，不因数据更新宣称已接入。
- 移除皮甲背心 `armor_leather_vest_basic` 的物品主表及来源CSV条目。
- 血、皮仍在讨论，本轮不新增物品，不修改畜牧血液与精制皮革来源。

### 仍待设计

- 点位分布、首次激活、冷却时长与计时口径；楼层销毁、再次进入时的点位身份及冷却保存。
- 成功、失败、主动放弃、中断的结束判定及冷却处理细则。
- 事件数量、选择成本、准备收益、成功率公式、狩猎技能成长及失败补救次数。
- 猎物、捕具、诱饵、产物与活捉规则。
- 休息可用阶段、单次时长、猎物变化，以及活动内饮水／药品边界。
