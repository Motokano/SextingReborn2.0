# 制药依赖逐药数值草案

> 运行时已接入逐成分依赖、途径倍率、免疫减免与按最高已起效来源缓解；除四档镇痛丸与清毒丸外，其余逐成分数值仍是可调首版候选。

> 覆盖41种现役药粉、28件现役固定成品，以及按实际配置器校验的单粉注射示例。

> 依赖增量 = 成分口服基准 × 投入份数 × 途径系数（口服1／吸入2／注射3／外敷0）× 免疫减免。复方逐项相加，不按最高值收费；缓解阶段取已起效来源最高值。

> 精制品按相对基础粉的药效点比值作为首版有效剂量代理，不按毒性下降比例减免成瘾。以后独立剂量字段替代，不与药效强度档机械绑定。

> 缓解阶段按成分固定；增加份数或精炼不会自动提高缓解阶段。致瘾增量仍随份数相加。

> 复方每个来源分别计增量，再取已生效缓解最高值；同族药效必须记来源与失效时间，不能因共享buff而重复授予旧来源缓解。

> 助溶不足造成药效损失，不自动减少已摄入依赖负担；必须有实际主药效生效才有对应缓解。

> 依赖自然衰减、免疫增量减免与时长加成沿用现有配置；缓解不额外延时。

> 表内原料途径增量仅为模型，不代表所有粉都能直接吞服或吸入；现役可用成品与合法动态注射另表列出。

> 自然衰减 = 0.02 × (1 + 免疫等级 × 0.015)；免疫100使增量减半、窗口翻倍、衰减达到0.05/tick。数值沿用当前配置。

> 窗口净变化 = 本次增量 − 窗口内自然衰减。负数不是药物主动治疗，也不是无依赖者会获得负依赖；实际值限制在0～100。

> 固定药烟中的烟草载体单份另计吸入依赖+1，载体不增加缓解。外敷不增加依赖。

> 四档镇痛丸依赖与缓解为已确认值；其他粉剂数值仍需后续实测。

> 单粉示例是配置校验，不保证针具卫生安全；复苏、止血、增效消费者缺口仍单独标注。
