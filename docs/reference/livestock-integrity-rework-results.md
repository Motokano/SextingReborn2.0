# 畜牧内核修复与组合复测

日期：2026-09-12。

本轮保留同步旋转，完成资源结算、生产条件、装置接收范围与若干高级模块失效问题的修复。23 项内核回归检查通过。旧高级模块的新机制仍待下一阶段实现，当前不应标记为整个畜牧重设计完成。

原有三组畜牧供电检查、运行文件语法检查及本轮受控修改的空白差异检查也已通过。

## 修复前后

| 检查 | 修复前 | 修复后 |
|---|---|---|
| 出生体重屠宰 | 牛 4.5→28.3 kg，羊 0.6→8.4 kg，猪 0.9→10.25 kg，鸡 0.05→1.18 kg | 总产物质量受活体限制；当前整件规则下这些幼崽没有掉落 |
| 无饲料猪繁殖，8 个种子 | 两头增加至 5–21 头 | 各组仍为两头，不怀孕 |
| 两头牛抢同一份饲料 | 240/150 kg，反转数组后对调 | 均为 195 kg，与数组顺序无关 |
| 鸡有充分污染时，1000 tick | 饱腹从 80 降至约 64.4 | 维持 80，余量用于成长 |
| 真实面板加工投料 | 先扣作物，再调用不存在的接口 | 只扣一次，成功入队 |
| 满槽或无接收槽 | 可能消耗作物/队列而无产物 | 拒绝投料或保留待加工内容 |
| 精加工器接收槽 | 所占侧冲突，另一侧不能安装 | 可建另一侧槽并按实际范围供料 |
| 满仓自动收集 | 容量按类型计算，超量或丢产物 | 按件数限制，溢出排队领取 |
| 鸡笼/手动喂鸡 | 拆笼仍有效，点击免费加饱腹 | 有鸡不能拆，喂食扣真实饲料 |
| 回收 | 净污染变化掩盖清污；多臂处理不完整 | 记录实际清污并在回收臂间分享，鸡食不重复回收 |
| 尸体 | 无限持续污染，可形成永久回收原料 | 有限分解预算，鸡笼两区分享，读档不重置 |

屠宰整件规则的代价是低体重掉落过于粗糙；具体规则和下一步约束见 [内核修订](../design/31-livestock-integrity-rework.md)。

## 组合结果

18 种组合累计 272,000 tick，16 组运行 12,000 tick，另两组运行 40,000 tick。全部数值有限且在合法范围内。31 个旧定向探针中，目前只剩“两头牛不能把初始高草降到羊食用范围”的风险条件成立；这不等于系统只剩一个问题，探针没有覆盖所有排列和新高级机制。

| 组合 | 观察 | 含义 |
|---|---|---|
| 两头牛，初始高草 | 首次交接草高 0.976524 m | 羊的食用上限是 0.8 m，牛羊轮作有密度门槛 |
| 三头牛，初始高草 | 首次交接 0.400827 m | 第一次交接可用，不足以保证长期平衡 |
| 两猪，无供料 | 12,000 tick 后仍两头，合计 1.8 kg、饱腹 10 | 可保留翻土功能，失去生产和繁殖能力，并破坏草地 |
| 三羊五鸡，初始草高 0.5 m | 羊约 5994 tick 饿死；鸡在 12,000 tick 仍活着 | 鸡营养修复不等于羊的草地供应已经稳定 |
| 两牛三羊两猪五鸡，顺序轮作、持续供料 | 12,000 tick 无死亡，但羊合计仅 1.8 kg | 存活不能用作生产稳定指标，供料不能替代羊的草食条件 |
| 三牛一羊一猪五鸡，预处理草地、供料和清污 | 12,000 tick 牛合计约 1616.15 kg；40,000 tick 降至约 393.95 kg | 低密度也存在长期供草失衡 |
| 同上，40,000 tick | 鸡在 15,000 tick 自然死亡 | 寿命及补群属于维护边界，不能误判为清污算法故障 |

## 方法与限制

- 使用实际运行代码和数据，真实库存接口验证投料；面板检查调用真实处理函数但关闭渲染，未进行实际浏览器视觉验收。
- 组合夹具、旋转周期和随机种子沿用历史审计。猪牛羊是成年公畜，用于排除繁殖干扰；奶产出另用成年母牛单测。持续供料夹具每 tick 补满已建槽，属于理想外部供给，不代表作物经济可负担。
- 仓储、联动探针的奶牛夹具改为母牛，以免新的性别校验让检查失去效力。加工正向对照改用配置吞吐 0.5 单位/tick，并检查队列与加工余量守恒；历史结果文件保留原始断言口径。
- 23 项回归还包括病畜减产、产仔母体扣重、妊娠暂停、不同 Perk 的实际效果、多回收臂独立控制、不足一整次结算的供电、加工吞吐升级以及 JSON 读档继续运行。
- 本轮没有穷举全部布局、Perk 组合或非法存档；旧联动仍存在待替换的加成模型。数值合法不等于生产稳定，更不等于整体经济守恒。

证据：[历史审计](livestock-current-implementation-audit.md)、[修复后运行数据](livestock-runtime-after-integrity.json)、[历史原始数据](livestock-runtime-audit-results.json)。
