## 生产线最终产出菜品总览（15 道）

### 一、复合调味与香料的巅峰

1. 墨西哥莫雷酱（Mole Poblano）
   - **类型**：复合酱汁 / 料理底酱  
   - **复杂度**：约 30–50 种原料  
   - **核心要点**：多种干辣椒、熏辣椒、坚果、种子、香料（香菜籽、肉桂、丁香、茴香）、干果、苦巧克力、烤玉米饼粉等，强调“调味品的交响乐”。

2. 印度正宗玛莎拉 / 咖喱（Authentic Garam Masala / Curry）
   - **类型**：香料基底 / 咖喱菜系  
   - **复杂度**：约 20–40 种全粒香料  
   - **核心要点**：现场烘烤并研磨多种香料，控制烘焙程度与下锅顺序，构建多层次风味。

3. 南洋娘惹叻沙（Nyonya Laksa）
   - **类型**：汤面 / 椰奶辣汤  
   - **复杂度**：总材料常超 40 种  
   - **核心要点**：Rempah（辣椒糊）含香茅、蓝姜、黄姜、石栗、虾膏、紫葱头等 15–20 种植物，加上海鲜、肉类及大量装饰配菜。

---

### 二、“大锅饭”式的食材堆砌

4. 佛跳墙（闽菜）
   - **类型**：高档综合海味煲  
   - **复杂度**：20+ 类名贵干货  
   - **核心要点**：鲍鱼、海参、鱼唇、牦牛枪、蹄筋、花菇、墨鱼、瑶柱、鹌鹑蛋等，加上老母鸡、鸭肉、猪蹄、火腿等多种肉类熬制汤底。

5. 法式马赛鱼汤（Bouillabaisse）
   - **类型**：经典法式鱼汤  
   - **复杂度**：多种鱼类 + 复杂香料  
   - **核心要点**：至少 6–10 种地中海底栖鱼类，辅以贝类、甲壳类，使用藏红花、橙皮、茴香等香料，并搭配专门的蛋黄酱（Rouille）。

6. 西班牙瓦伦西亚合锦饭（Paella Mixta）
   - **类型**：西班牙大锅饭  
   - **复杂度**：陆海食材融合，多种配料  
   - **核心要点**：鸡肉、兔肉、豆类与大虾、青口、鱿鱼、蛤蜊等同锅；以藏红花、甜椒粉等为关键香料。

7. 阿塞拜疆 / 波斯抓饭（Shah Plov）
   - **类型**：宫廷抓饭 / “饭中之王”  
   - **复杂度**：多层次干果与肉类组合  
   - **核心要点**：长粒米、羊肉、干杏脯、黑梅干、栗子、核桃、葡萄干、大量洋葱与藏红花浸液，整体包裹在特制薄饼中。

### 三、极致的嵌套与叠加

8. 三鸟转（Turducken）
   - **类型**：多层填馅整禽料理  
   - **复杂度**：30+ 种成分  
   - **核心要点**：三种禽类层层嵌套，每层之间填入不同馅料（肉肠、面包丁、多种香草、坚果、蔬菜碎等）。

9. 摩洛哥鸽子馅饼（Bastilla）
   - **类型**：甜咸交织酥皮馅饼  
   - **复杂度**：多重口感与风味叠加  
   - **核心要点**：薄皮内为鸽子肉（或鸡肉）、大量洋葱、香料蛋液，再加上糖与肉桂调味的杏仁碎，融合咸、甜、香、脆。

10. 传统俄罗斯肉冻（Kholodets）
    - **类型**：天然胶冻冷盘  
    - **复杂度**：多部位胶原与多种蔬菜  
    - **核心要点**：猪蹄、牛蹄、鸡爪、猪皮等多种高胶原部位长时间熬煮，配根茎类蔬菜，自然冷却凝固。

### 四、现代与古典的“材料怪兽”

11. 罗宋汤（传统乌克兰版 Borscht）
    - **类型**：传统甜菜汤  
    - **复杂度**：辅料常超 20 项  
    - **核心要点**：甜菜、白菜、土豆、胡萝卜、洋葱、大蒜、番茄，搭配牛肉、猪肉或培根及烟熏肉，使用发酵甜菜汁、香叶、黑胡椒等调味。

12. 意大利传统炖肉（Bollito Misto）
    - **类型**：多部位混合炖肉  
    - **复杂度**：7 种肉 + 多种香料与蘸酱  
    - **核心要点**：牛腱、牛舌、牛头肉、填馅猪蹄、母鸡等一同炖煮，每种肉配独立香料包及蘸酱（绿酱、红酱、果酱等）。

13. 八宝葫芦鸭（苏菜）
    - **类型**：整鸭填馅菜肴  
    - **复杂度**：高密度干货与淀粉组合  
    - **核心要点**：鸭腹填入糯米、干贝、火腿、莲子、芡实、香菇、栗子、虾仁等“八宝”，辅以腌制与卤水配料。

14. 法式卡酥来砂锅（Cassoulet）
    - **类型**：慢炖肉豆砂锅  
    - **复杂度**：多种肉类 + 长时间工序  
    - **核心要点**：白扁豆、油封鸭腿、图卢兹香肠、猪皮、猪肘、羊肉等，与复杂肉汤共炖，制作周期往往需 3 天。

15. 日本关东煮（顶级料亭版 Oden）
    - **类型**：复合高汤关东煮  
    - **复杂度**：高汤与配料体系极其庞大  
    - **核心要点**：以昆布、鲣鱼干、干香菇、干贝等熬制复合高汤；各类“种”如鱼丸、竹轮、大根、魔芋、鸡蛋等有各自的前处理与制作逻辑。
