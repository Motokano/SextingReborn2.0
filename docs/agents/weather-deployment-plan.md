## 已核对的运行结构

- 当前工作目录为 `C:/Users/haoxian.huang/Desktop/work/Deepseek/SextingReborn2.0`。
- 页面入口为 `index.html`；当前加载 `js/game-time.js`、`js/survival.js`、`js/save-system.js` 等脚本。
- `npm run dev` 使用 `tools/serve-live.mjs`，默认端口8000，默认静态根为该项目根；可通过参数指定根目录。正式试玩前须确认实际服务根与修改目录一致，不能仅据脚本默认值判断正在运行的服务。
- 当前环境无法通过进程查询确认活动服务根，未宣称已完成运行目录验收。
- `Survival.advanceTick` 推进 `GameTime.advanceTicks(1)`；移动、睡眠、持续动作已有统一生存 tick 入口。天气不得另设现实时间计时器。
- `js/save-system.js` 收集世界时钟与生存状态，恢复时调用 `GameTime.reset`。天气进程应与快照一起恢复，不能读档重抽。
- `Survival.consumeStamina` 是需检查的动作扣费入口；落实倍率时还需排查动作预检查及绕过公共入口的调用，确保检查与实际扣费一致。
- `CharacterAttributes.getCombatSpeed` 返回缓存速度；温度惩罚需进入既有派生属性更新机制，不能只修改显示值。

## 接入顺序

1. 建立配置驱动的天气环境模块，提供地区天气、地图覆盖、有效气温及条件查询；保持玩家知识视图与内部数值查询分离。
2. 接世界 tick 与季节，落实持续天气、事件、渐变温度和离图进程；为可重复验证保留可控随机输入。
3. 接入完整存档、恢复、旧档缺失天气状态的初始化；不让旧档在导入时被随机重复初始化。
4. 替换玩家体温计算，修复内部精度、阈值不可达和固定春季问题；加入范围/速率/恢复来源与耐候判定。
5. 接入身体档位、速度修正、动作消耗与疲劳；保护已有移动储备豁免和统一休息转换。
6. 增加认知过滤后的天气与身体提示，不暂停动作、不新增惊醒、不公开精确温度；为未来测量行为保留入口，不凭空发放温度计或鉴定知识。
7. 接环境条件读取接口；敌人仅查询，不添加自动体温结算。农业、畜牧不改生产规则，防具属性等缝纫设计，具体功法与鱼种天气响应另定。
8. 完成验证后，在确认根目录的本地服务试玩，记录配置版本、实现范围和未接入内容。
